## 主要な新機能と実践活用

### `/skill-doctor` — 使われていないスキルとそのコンテキストコストを可視化(v2.1.261)

**読み込まれているスキルのうち実際には使われていないものと、そのスキルがコンテキスト上で占めているコストを表示する`/skill-doctor`が追加**されました。**これを参考に不要なスキルを整理(プルーニング)できます。**

```bash
/skill-doctor
# 読み込み済みスキルの一覧と各スキルのコンテキスト使用量、実際に呼び出されたかどうかが表示されます
```

**複数のプラグインやスキルを積み重ねて使っていると、実際にはほぼ使われないスキルが毎ターンのコンテキストを地味に食いつぶしがちですが、`/skill-doctor`でこうした項目を見つけて削除すれば、プロンプトキャッシュの効率とコンテキストの余裕を同時に確保**できます。[リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `bashOutputMaxChars`/`taskOutputMaxChars` — コマンド・バックグラウンドタスクの出力を最大128K文字までインライン受信(v2.1.261)

**コマンド実行やバックグラウンドタスクの出力が一定の長さを超えるとファイルに保存され要約だけがインラインで渡されていた従来の挙動に対し、インラインで受け取れる上限を最大128K文字まで自分で引き上げられる`bashOutputMaxChars`・`taskOutputMaxChars`設定が追加**されました。

```json
// settings.json
{
  "bashOutputMaxChars": 131072,
  "taskOutputMaxChars": 131072
}
```

**長いビルドログやテスト出力をファイル経由に迂回させずそのまま分析したい場合、この設定でインライン受信の上限を余裕を持って引き上げておけます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 開発者ワークフローティップス

### `--append-subagent-system-prompt-file` — コマンドライン長の制限なく長いサブエージェントプロンプトを渡す(v2.1.261)

**サブエージェントのシステムプロンプトに内容を追記する際、これまではコマンドライン引数でしか渡せずシェルの引数長制限に引っかかりやすかったところに、ファイルから読み込む`--append-subagent-system-prompt-file`オプションが追加**されました。

```bash
claude --append-subagent-system-prompt-file ./prompts/reviewer-guidelines.md
```

**チームのコードレビュー基準やアーキテクチャガイドラインのようにボリュームの大きいドキュメントをサブエージェントにまるごと渡したい場合、今後は別ファイルとして管理しつつコマンドライン引数の長さを気にせず渡せる**ようになりました。[リリースノート全文](https://github.com/anthropics/claude-code/releases)

### MCPは実際のプロダクションでどう使われているのか — Ask HNコメント総まとめ(9/4)

**MCPはリリース当初こそ大きな注目を集めたものの、実際のプロダクション活用事例には出会いにくいという問いに対し、実務者たちの回答が集まりました。** **社内運用診断、SaaS連携、音声エージェント、顧客向けチャットボットなどで、通常のAPIやCLIを直接連携するよりもツール探索と統合コストを抑える用途としてMCPが使われている**というのが要点です。

**Claude Code向けのMCPサーバーを新たに設計しているなら、汎用的なAPIラッパーを目指すよりも、こうした具体的な運用・カスタマーサポートのシナリオに合わせてツールの範囲を絞り込むほうが実戦でうまくいく、という参考事例**として読めます。[GeekNews](https://news.hada.io/topic?id=33224)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.261**(9/4)の項目です。

- **`/status`・`claude doctor`に、組織ポリシーが読み込まれなかった理由を示す「Organization policy」の行が追加**されます。例えばプロキシがエンドポイントを通過させないケースなどがここに表示されます。
- **危険な`rm -rf`に対する安全プロンプトが、位置引数に対する`rm -rf`や、二重引用符で囲まれた`sh -c`スクリプト内の`rm -rf`まで検知できるように改善**されます。
- **APIが応答ヘッダーを一切返さない場合、再試行の待機時間が3分ではなく`API_TIMEOUT_MS`(デフォルト10分)まで延長され**、何を変更すべきかをメッセージで案内します。
- **プロンプト入力欄の単語単位の編集ショートカットがBashと同じ挙動になります。** Ctrl+Wは空白まで削除し、Alt+F・Alt+Dは単語の終わりで止まり、句読点を単語の境界として扱います。`keybindingFlavor`設定はもはや効果を持ちません。
- [VSCode] **MCPサーバーダイアログにサーバー追加フォームと削除機能が追加され**、IDEを離れることなくMCPサーバーを追加・削除できます。
- [VSCode] **権限・確認プロンプトに折りたたみボタンが追加**され、プロンプトを閉じなくても背後の会話をスクロールして読めるようになります。
