## 主要な新機能と実践活用

### Autoモードのclassifier、サーバーサイドが再びデフォルトに — オーバーヘッド課金が消滅 (v2.1.278)

**Claude API・Enterpriseユーザー、およびBedrock・Vertex・Foundry・ゲートウェイ環境全般で、autoモードのclassifierがサーバーサイド実行をデフォルトとするよう変更されました。** **サーバーサイドclassifierには追加のオーバーヘッド課金がなく、課金が発生する方式にフォールバックする際は警告が表示されます。**

```bash
# Bedrock、Vertex、Foundry、ゲートウェイ環境でサーバーサイドclassifierをオフにし、以前どおりローカルclassifierを使う
export CLAUDE_CODE_AUTO_MODE_SERVER=0
```

**`/status`に、今回のセッションでautoモードのclassifierがサーバー側で動作しているかを示す`Auto mode server`行が新たに追加されます。9/15ブリーフィングで触れたとおり、Bedrock・Vertex・Foundryはしばらくローカルclassifierをデフォルトにしていましたが、今回の変更で再びサーバーサイドがデフォルトとなり、課金構造も明確になりました。** [ドキュメント](https://code.claude.com/docs/en/auto-mode-classifier-billing) · [全リリースノート](https://github.com/anthropics/claude-code/releases)

### Claude、生体分子モデル30種類以上を平均4倍高速化 (9/19)

**タンパク質構造予測や設計などに使われるオープンソースの生体分子モデル30種類以上を、Claudeで最適化した事例です。** **4週間未満の作業で、数値精度をわずかに落とせば平均約4倍、同じ出力を維持する場合でも約2倍まで速度が向上しました。**

**計算負荷の高い部分を処理する専用GPUカーネルFlashPairformerを新たに作成するなど、Claudeが単なるコード生成にとどまらず、科学計算分野の性能最適化作業も実戦で担えることを示す事例です。** [GeekNews](https://news.hada.io/topic?id=33921)

## 開発者ワークフローティップス

### Stagehand v4 — Playwrightより2倍速く、トークン効率80%向上したブラウザ自動化 (9/20)

**AIエージェントがWebサイトを操作しデータを抽出するのを助けるオープンソースSDKで、Playwrightに似たコードと自然言語コマンドを組み合わせて使えます。** **ブラウザを制御するたびに外部スクリプトと通信していた従来の構造をやめ、ブラウザ内の拡張機能でコマンドを処理する方式に変えたことで、速度とトークン効率を大きく高めました。**

```bash
npm install @browserbasehq/stagehand
```

**Claude CodeでWebスクレイピングやUIテスト自動化エージェントを作っているなら、Playwrightのコードはほぼそのまま維持しつつ、曖昧なセレクタが必要な部分だけを自然言語コマンドに置き換えてみる価値があります。** [GeekNews](https://news.hada.io/topic?id=33959)

### 最も重要な製品判断は「何を作らないか」である (9/20)

**アプリにドキュメント一覧と通知を一つ追加しようとした小さな要望が、要件を一つずつ積み重ねるうちにGoogle DriveとGmailを中途半端に再発明する作業へと膨れ上がりかねないという警告です。** **機能を作らないよう説得するには、初期開発コストよりも、リリース後何年も続く運用・保守コストを具体的に示すほうが効果的です。**

**Claude Codeによって機能実装のスピードが上がった分、何を作るかよりも何を作らないかを先に決める習慣がむしろ重要になっています。** [GeekNews](https://news.hada.io/topic?id=33950)
