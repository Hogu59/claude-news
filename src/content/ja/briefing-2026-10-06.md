## 主要な新機能と実践活用

### WebSearch予算が1時間ごとに自動でリフィルされる方式に変更 (v2.1.290)

**これまでは対話型セッションでWebSearchの呼び出しが200回に達するとそこで打ち止めでしたが、今後は1時間ごとに100回ずつ自動で補充される方式に変わりました。** リフィル速度は環境変数で調整したり、完全に無効化したりできます。

```bash
# 1時間あたりのリフィル数を調整(デフォルト100)
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=50

# リフィルを無効化して従来どおり上限で打ち止めにする場合
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=0
```

**長時間続くリサーチセッションでWebSearchを多用し、200回の上限に引っかかってセッションを新しく始め直した経験があるなら、今後はそうした中断なしに作業を続けられます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### Claude Opus 5.5エージェントが室温磁性半導体の候補物質を設計・再発見 (10/6)

**Claude Opus 5.5のエージェントチームと研究者が協力し、新物質YBaMnFeO5を設計するとともに、既知の物質KV[Cr(CN)6]を独自に再発見しました。** 計算上、両物質は完全な結晶構造においてネットのスピン磁気モーメントがゼロでありながら、電子状態をスピンごとに分離する「Luttinger補償磁性体」という性質を持ち、室温で動作する半導体の候補とされています。

**複雑な多段階の研究パイプライン(仮説設定→計算→候補検証)をエージェントに任せた事例で、コーディング作業以外の科学研究にも同じ探索・計画・検証のループが応用できることを示しています。** [GeekNews](https://news.hada.io/topic?id=34847)

## 開発者ワークフローティップス

### `/claude-api managed-agents-onboard`でManaged Agentsパターンを即座にブートストラップ (v2.1.290)

**Managed Agentsパターンを、Consoleページが`ant apply`ファイルで説明している内容そのままに設定してくれるサブコマンドが追加されました。** URLを渡せばそのページの設定がそのまま適用され、`deep-researcher`のようなquickstart名を渡せば`ant` CLIでConsoleのクイックスタートテンプレートを直接構成できます。

```bash
# Consoleページが説明するant applyファイルで設定
/claude-api managed-agents-onboard <url>

# 組み込みのquickstartテンプレートで直接始める
/claude-api managed-agents-onboard deep-researcher
```

**組織にManaged Agentsを導入する際、ドキュメントを見ながらファイルを一つずつ手作業で揃える代わりに、このコマンド一つで標準構成を取得し、そこからカスタマイズを始められます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### MCPBでローカルMCPサーバーをClaude Desktopのワンクリック拡張としてパッケージ化 (Anthropic公式ドキュメント、10/5)

**MCPB(.mcpb)は、ローカルMCPサーバーと`manifest.json`を1つのzipファイルにまとめ、Claude Desktopがブラウザ拡張のようにインストールできるようにするパッケージング方式です。** インストールはファイルのダブルクリック、Claude Desktopのウィンドウへのドラッグ、またはSettings → Extensions → Advanced settings → Install Extensionのいずれか好きな方法で行えます。

**社内で作ったMCPサーバーを同僚に配布する際、インストールスクリプトや設定手順書を別途用意する代わりに、zipファイル1つを共有するだけでインストールを完了できます。** [GeekNews](https://news.hada.io/topic?id=34822)

## エコシステム＆プラグイン

### Cloudflare、AIエージェント向けWeb Search APIをベータ公開 (10/6)

**CloudflareがAIエージェントやアプリケーションがインターネットを検索し、リアルタイムの情報に基づいて応答できるようにするWeb Search APIをベータ公開しました。** ローンチ時点ではCeramic.ai、Exa、Linkupの3社の検索プロバイダーから選べ、いずれもCloudflare経由でルーティングされます。

**Claude Codeのエージェントパイプラインに検索機能を自前のインフラとして取り込みたいチームなら、WebSearch標準ツールの代わりにこうしたサードパーティ検索APIをルーティング・キャッシュ層に組み込む選択肢として検討する価値があります。** [GeekNews](https://news.hada.io/topic?id=34826)

### Claude Tag(Slack)、`!fast`でスレッドをその場でFastモードに切り替え (v2.1.290)

**Slackでメンション時に`!fast`を付けると、そのスレッドが必要に応じてOpusに切り替わるfastモードになり、応答に「(fast)」の表示が付きます。`!fast off`で元のモードに戻せます。** 同リリースでは、access bundleのカスタム接続にPath prefixesフィールドも追加され、許可ルールをホスト全体ではなく特定のパスに絞れるようになりました。

**SlackでClaude Tagを使って協業しているチームなら、通常はコストの低いモデルでスレッドを運用し、複雑な質問が出たときだけ`!fast`で格上げすることで、コストと応答品質を状況に応じて調整できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.290**(10/5)の項目です。

- **Claudeアプリゲートウェイのログイン承認ページにDenyボタンが追加**され、待機中のログインを即座に終了させ、待っているターミナルを数秒以内に停止させられるようになりました。
- **`claude plugin validate --json`に`gatingHooks`フィールドが追加**され、モードが登録した各ゲーティングフックに`.catch`があるかをすぐに確認できるようになりました。
- **Bashツールが`pyright`を読み取り専用コマンドとして扱わなくなり**、実行前に権限確認を求めるようになりました。
- **`/code-review`の中(medium)強度が、Opus 5.5・Sonnet 5.5のようなチューニングされていないモデルでも整理やCLAUDE.md規約に関する発見事項を併せて報告する**ように変更されました。
- **Claude in Chromeの`browser_batch`呼び出しのタイムアウトが60秒から90秒に延長されました。**
- **WebFetchが100,000文字を超えるページテキストを黙って切り捨てていた問題が修正**され、どれだけ読み取れなかったかを通知し、`offset`で続きを読めるようになりました。
