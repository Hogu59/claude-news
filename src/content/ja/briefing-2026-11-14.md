## 開発者ワークフローティップス

### サンドボックスで実行されるBashコマンドが既定で権限確認を通るようになりました (v2.1.325)

**これまではサンドボックス内で実行されるBashコマンドは承認なしにそのまま実行されていましたが、本バージョンからはそうしたコマンドも通常の権限確認フローに従うようになりました。** サンドボックスがコマンドの影響範囲を制限してくれる点は変わりませんが、その中で実行されるというだけで承認が自動的にスキップされることはなくなります。これまでのようにプロンプトを出さずに実行を続けたい場合は、設定を変更する必要があります。

```json
{
  "sandbox": {
    "autoAllowBashIfSandboxed": true
  }
}
```

**managed settingsでサンドボックスを強制的に有効化している組織の場合、この値を最も優先順位の高いmanaged設定のソースに入れておかないと、コマンドがプロンプトなしで実行され続けません。**

**サンドボックスモードでClaude Codeを運用し、承認なしでコマンドが即実行されることを前提にワークフローを組んでいた場合、v2.1.325にアップグレードした後に権限プロンプトが急に増えたのはこの変更が原因だと理解しておき、必要な場合のみ上記の設定で以前の動作に戻すとよいでしょう。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### 信頼していないリポジトリでの読み取り専用gitコマンドも確認対象になりました (v2.1.325)

**プロジェクト自身のリポジトリでもなく、個別に信頼設定もしていないリポジトリでは、読み取り専用のgitコマンドであっても確認を求められるようになりました。** こうしたリポジトリをプロンプトなしで扱い続けたい場合は、`additionalDirectories`設定ではなく`--add-dir`でそのフォルダを明示的に指定して渡す必要があります。

```bash
# 信頼していない別リポジトリのgitコマンドをプロンプトなしで実行したい場合
claude --add-dir ../other-repo
```

**モノレポ外の別リポジトリを合わせて開いておき、git logやgit diffのような読み取り専用コマンドを頻繁に実行していた場合、v2.1.325からはそのリポジトリを`--add-dir`で明示しないと、毎回表示される確認プロンプトを避けられません。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### scheduled taskと`/loop`がunattended skillの実行前に確認を求めるようになりました (v2.1.325)

**`allowed-tools`やhooksを宣言したskillをscheduled taskや`/loop`が実行しようとすると、まず確認を求めるように変わりました。** 人が介在しない無人運用を続けたい場合は、そのskillを明示的に許可リストに追加する必要があります。

```text
permissions.allowにSkill(スキル名)を追加 → 確認なしで無人実行
```

**scheduled taskやself-pacedな`/loop`にhooks付きのskillを紐づけて夜間に動かしていた場合、v2.1.325へのアップグレード後にこの設定を事前に追加しておかないと、次回実行時に確認待ちで止まってしまう可能性があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

**Claude Codeでブラウザ自動化が必要なのに、専用ブラウザを新たに立ち上げたりセッションクッキーを移したりするのが手間だったなら、すでにログイン済みの自分のChromeをそのままエージェントに接続する方法を試してみる価値があります。** [GitHub](https://github.com/BeatAPI/BeatBrowser) · [GeekNews](https://news.hada.io/topic?id=37096)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.325**(11/13)の項目です。

- **Claude Code on the web(クラウドセッション)のMCPツール説明文の文字数上限が4,096字から16,384字に拡大され、他のClaude Codeセッションと同じになりました。**
- **Claudeが自分で作成したartifactやそのデータを読み取る際、権限を確認しないように変更されました。**
- **`/cost`、`$.session.usage()`、`--max-budget-usd`などのコスト・トークン指標が、modの`$.model.complete`・`$.model.classify`呼び出しも合わせて集計するようになりました。**
- **VS CodeにAPIキーを作成しないConsoleログイン方式が追加されました。**
- **`claude -p`は、ログインキャッシュのデータがまだない場合にそのデータを待ってから最初のリクエストを送るようになり、クリーンな環境での初回起動が数秒遅く始まることがあります。**
- **Windowsで、アカウント権限で開けないフォルダ配下にPATHエントリがある場合に起動時約1秒間フリーズしていた問題が修正されました。**
