## 開発者ワークフローティップス

### easel — MCPメトリクス結果などを自動でグラフ化する内蔵modが追加されました(v2.1.330)

**これまでClaude CodeがMCPツールから受け取った数値結果をグラフで見るには、その都度リクエストする必要がありましたが、今回のリリースからPro・Max、そして対応環境ではTeam・Enterprise(macOS・Linux)でも、「easel」という内蔵modがリクエスト時やMCPメトリクス結果の下に自動でグラフを表示するようになりました。** 自動チャートを望まない場合は`/config`で無効化できます。

```bash
# /configを開いてeaselの自動チャート機能を無効化したい場合
/config
# → automatic charts(自動チャート)項目をオフに
```

**MCPでメトリクスや数値データを頻繁に確認し、毎回「グラフにして」と頼んでいた人なら、v2.1.330からはリクエストなしで表示される自動チャートをそのまま活用できます。不要な場合だけ`/config`でオフにしてください。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### スケジュールタスクと`/loop`が、セッションが生きている限り最大30日間実行できるようになりました(v2.1.330)

**これまで繰り返しのスケジュールタスクと`/loop`はセッションが生きていても7日で終了していましたが、今回のリリースから最大30日まで延長され、終了タイミングも事前に通知されるようになりました。** ただし、このリリース以前に作成・保存済みのタスクには依然として7日制限が適用されます。

**長時間のモニタリングや定期チェックを`/loop`やスケジュールタスクで回していて7日ごとに再設定が必要だった人は、v2.1.330にアップグレードした後に新しく作成するタスクから最大30日間ノンストップで実行できるようになります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### VS Codeに、直前の回答地点から会話をフォークする`/fork`が追加されました(v2.1.330)

**これまで会話を分岐させて別のアプローチを試すにはセッションを新規に始める必要がありましたが、今回のリリースからVS Codeで`/fork`コマンドを使うと、直前の回答の位置からその場で会話をフォークできます。**

**VS CodeでClaude Codeを使いながら同じ会話の中で異なるアプローチを試したかった人は、v2.1.330から`/fork`でこれまでの文脈を保ったまま分岐を試せます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## セキュリティ・制限事項

### ルート・ホーム・作業フォルダを対象とする`rm`コマンドが、より多くのケースで承認を求めるようになりました(v2.1.330)

**これまでも危険な`rm`コマンドの一部は確認を経ていましたが、今回のリリースからルート、ホーム、最上位フォルダ、作業フォルダを対象とする`rm`コマンドの承認対象が広がり、誰も承認に応答できない状況(無人の自動化パイプラインなど)では、そのコマンド自体が拒否されるようになりました。**

**autoモードやbypass permissionsモードでClaude Codeを無人の自動化パイプラインに組み込んでいる場合、v2.1.330へのアップグレード後、これまで黙って通過していた一部の削除系コマンドが新たに拒否されたり、承認待ちで停止したりする可能性がある点を踏まえておく価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.330**(11/20)の項目で、上記で取り上げていないものです。

- **`CLAUDE_CODE_FULL_SIGN_IN_LINK=1`環境変数が追加**され、短縮ログインリンクでエラーが出る場合やスクリプトが値を読み取る必要がある場合に、完全なリンクを出力できるようになりました。
- **`/mcp`がプラグインがインストールしたMCPサーバーを内蔵サーバーと誤って分類していた問題が修正**され、「Plugin MCPs」と、`--mcp-config`・内蔵サーバーをまとめた「Other MCPs」に区別されるようになりました。
- **`/stats`がUTC基準の日付で集計していた問題が修正**され、ローカルタイムゾーン基準で集計されるようになりました。
- **`claude plugin install --json`の結果に、インストールコマンドがstderrに出力したか(`commandPrinted`)、失敗したか(`commandFailed`)を示すフィールドが追加**されました。
- **VS Codeに、選択したメッセージを固定せず流れるままにする`claudeCode.pinPrompt`設定と、EscキーがClaudeを停止させないようにする`claudeCode.escapeStopsClaude`設定が追加**されました。
- **`/ultrareview`が、セルが別リポジトリへ移動した後に失敗したり無関係なコードをレビューしていた問題が修正**され、両方のフォルダ名を知らせたうえで停止するようになりました。

- **OpenDocKit — HWPからPDF・Excelまで、実際にアップロードされる文書をLLM向けMarkdownに変換するPythonライブラリ(11/20)**: テキスト抽出の際に崩れやすい結合セル、2段組PDF、HWPファイル構造をそのまま保持してRAGパイプラインやエージェントに渡すことを目指しています。ファイル拡張子ではなく内容で形式を判定するため、`.xls`として保存されたHTML形式の表も正しく読み取り、結合セルを行単位で埋めたり、チャートをデータ表に、SmartArtを入れ子リストに、数式をLaTeXに変換したりします。LangChainローダー・LlamaIndexリーダー・MCPサーバーを併せて提供し、Claude Code・Dify・Hermes Agentのプラグインとしても動作します。`pip install opendockit`でインストールでき、デフォルト設定ではオフライン・決定的に動作し、GPUやMLモデルは不要です。[GitHub](https://github.com/hyeonsang010716/OpenDocKit) · [GeekNews](https://news.hada.io/topic?id=37495)
- **Nubis — Claudeパネルを内蔵したWindows向けSSH/RDP/SFTPクライアント(11/21)**: AWS・Tencent Cloud・GCP・Azure・OCIに既に設定済みの認証情報を読み取ってクラウドサーバー一覧を同期し、SSH・RDP・PowerShellをタブで開きつつSFTPパネルも同時に表示できる、個人開発のオープンソースWindowsアプリです。オプションで有効化できるClaudeパネルは現在見ているタブを認識し、PCにインストールされたClaude Codeを内部MCPサーバーとして接続して、コマンド実行やホスト管理・ファイル転送まで行いますが、サーバーに対するすべての操作には承認が必要で、監査ログに記録されます。アプリ自体はサンドボックス化されていないため、ClaudeはユーザーとWindowsアカウントと同じ権限で動作する点に注意が必要です。インストール不要で実行できるポータブルzipとして配布され、テレメトリはありません。[GitHub](https://github.com/windevase/nubis) · [GeekNews](https://news.hada.io/topic?id=37538)
