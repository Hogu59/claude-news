## 主要な新機能と実践活用

### `sandbox.allowNestedUserNamespaces` — LinuxサンドボックスでChromium・rootless podmanを動かせます (v2.1.305)

**新しい設定`sandbox.allowNestedUserNamespaces`を有効にすると、Linux上でサンドボックス実行されるコマンドがユーザーネームスペースを作成できるようになり、Chromiumやrootless podmanのようにユーザーネームスペースを必要とするツールもサンドボックス内で動かせます。** ただしこのオプションはサンドボックスのファイル保護を回避する経路も開くことになるため、どのコマンドにこの権限を与えるかは慎重に判断する必要があります。

```json
{
  "sandbox": {
    "allowNestedUserNamespaces": true
  }
}
```

**サンドボックスモードでブラウザ自動化やrootlessコンテナのビルドを試みてユーザーネームスペース権限不足で止まった経験があるなら、このオプションで解決できますが、その分隔離レベルが下がるというトレードオフも併せて受け入れる必要があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` — 利用上限が予定より早く解除されたかを事前に確認します (v2.1.305)

**新しい環境変数`CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`を設定すると、無人リトライモード(`CLAUDE_CODE_RETRY_WATCHDOG`)が利用上限に達して待機している間、一定間隔で上限がすでに解除されていないかを再確認します。** 10/16のブリーフィングで紹介した`CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`(最大待機時間の制限)と対になる設定で、今回は逆に上限がリセット予定時刻より先に解除された場合を見逃さないようにするものです。

```bash
export CLAUDE_CODE_RETRY_WATCHDOG=1
export CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS=60000
```

**CIやスケジューラでClaude Codeを無人実行し、利用上限のリセットを待つ場面が多いなら、この間隔を短く設定しておくことで、上限が予想より早く解除された際にすぐ作業を再開できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 開発者ワークフローティップス

### `/usage`の警告をfキーで一括修正 (v2.1.304)

**`/usage`に表示される警告が、原因ごとに1行の修正案を示す形に変わり、`f`キーを押すとその修正が一括で適用されるようになりました。** 同じ修正リストはVS Codeパネルや`/doctor`にも同様に表示されます。

**環境変数や設定の問題で`/usage`に警告が積み重なっているなら、1件ずつ追跡して直す代わりに`f`を押して一括で整理し、同じリストがVS Codeや`/doctor`にも表示されることを活用して、どのクライアントで作業していても一貫してチェックしてみてください。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `allowedMcpServers`のフィルタリング範囲が狭くなりました — アップグレード後に自動ロードされるMCPサーバーを確認してください (v2.1.305)

**`allowedMcpServers`が、`managed-mcp.json`内のstdioサーバーのうち`${VAR}`を`env`だけに使うサーバーをもはや除外しないように変更され、これまでallowlistから外れていたサーバーがアップグレード後に自動的にロードされる可能性があります。** 引き続き遮断したい場合は、`allowedMcpServers`ではなく`deniedMcpServers`に明示する必要があります。

**組織単位で`managed-mcp.json`を使ってMCPサーバーを配布し、`allowedMcpServers`で一部を除外していたなら、v2.1.305にアップグレードする前にどのサーバーが新たにロードされ得るかを確認し、必要なサーバーは`deniedMcpServers`に移しておくのが安全です。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.305**(10/20)の項目です。

- **`/artifacts`の削除確認が番号選択方式に変更され**、1またはEnterは維持、2は削除、Escは取消となり、`y`・`n`はもう使えません。
- **ディスクが満杯の状態でBashコマンドが`ENOSPC`の生のパスだけを表示して失敗していた問題が修正**され、ディスクが満杯で何も実行されなかったことを明確に案内するようになりました。
- **起動時の警告がロゴの上に生テキストで出力されていた問題が修正**され、デバッグログに送られるようになり、何も制限しない権限ルールはバナー下のwarning行として表示されるようになりました。
- **スクリーンリーダーモードが改善**され、検索ボックスが電話の留守番電話のように読まれていた記号の代わりに「Search:」と読まれるようになり、Ctrl+R検索のマッチや「ultrathink」のような強調テキストに不要な空白が入らなくなりました。
- **[VSCode] SessionStartやSetupフックの実行中に「Running start-up hooks」のスピナー表示とスクリーンリーダー案内が追加**されました。
- **modのドックパネルが、より広いターミナルで使っていた幅を維持し続けていた問題が修正**され、ターミナル幅の45%以内に制限されるようになりました。
