## 主要な新機能と実践活用

### FlashProve — Anthropicがモデルの重みを公開せずに推論を検証できる研究プロトタイプを公開しました（11/5）

**Anthropicが、zkSNARK暗号証明によって「この応答は特定のモデルから生成された」という事実を、重みを公開せずに検証できるオープンソースの研究プロトタイプFlashProveを公開しました。** モデル提供者があらかじめオフラインで重みを固定する短いコミットメントを一度作成しておけば、以降は特定のプロンプト・応答のペアについて、そのコミットメントが指すモデルが実際にその出力を生成したことを証明できます。誰でもGPUを使わずに、コミットメント・プロンプト・応答・証明だけでこれを検証可能です。約400BパラメータのMoEモデルであるLlama 4 MaverickをH100 1枚で証明したところ、毎秒110トークンの速度で生成でき、証明ファイルは約18.78MB、検証には24スレッドで約17秒かかりました。完全性・健全性・ゼロ知識性・簡潔性という4つの安全性の性質はLeanで形式検証されています。

**整数版のモデルとgreedyデコーディングのみが証明対象で、コンテキストも1,024トークンまでに限られるなど、まだ研究段階ではありますが、モデルルーティングや評価パイプラインを運用していて「実際にどのモデルが応答したか」を外部に証明する必要がある場面があるなら、この方向の進展は注目に値します。** [GeekNews](https://news.hada.io/topic?id=36617)

### claude auth status・claude -p JSONにログイン失効時刻が追加され、失効10日前から警告が表示されます（v2.1.318）

**保存済みのclaude.aiログインがいつ失効するかを、`claude auth status`の`loginExpiresAt`フィールドと、`claude -p`のJSON出力の`credential_expires_at`フィールドで確認できるようになりました。** ログイン失効の10日前からは、`claude -p`のテキスト出力にも1行のstderr警告が表示されます。

```bash
# ターミナルでログイン失効時刻を確認
claude auth status

# claude -p のJSON出力から認証情報の失効時刻だけを取り出す
claude -p "ping" --output-format json | jq -r '.credential_expires_at'
```

**CIやcronで`claude -p`を非対話的に実行する自動化をしているなら、ログインが失効してパイプラインが突然止まる前に、このフィールドやstderr警告で事前に気付き、再認証のスケジュールを組んでおけます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 開発者ワークフローティップス

### modの`$.model.fork`にeffortを指定して、付随作業だけ軽く実行できます（v2.1.318）

**modのコードから`$.model.fork`を呼ぶ際に`effort`オプションを指定できるようになり、セッション全体が`xhigh`や`ultrathink`に設定されていても、要約や分類のような軽い判断で済む付随作業だけを`low` effortで別途実行できます。** 結果には実際に適用されたeffortも一緒に返ってくるため、セッションのeffortとは関係なく、そのフォークがどのeffortで実行されたかをすぐに確認できます。

```js
// modのコード例：セッションのeffortに関わらず、軽い付随作業だけをlow effortで実行
const result = await $.model.fork({
  prompt: "このコミットメッセージを1行で要約して",
  effort: "low",
});
```

**セッションのeffortを高く設定して複雑な作業をさせつつ、その中でmodが呼ぶ軽い補助的な呼び出しまで同じeffortでトークンを使うのはもったいないと感じていたなら、自作のmodにこのオプションを取り入れてみる価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### バックグラウンドサブエージェントのシェルコマンドが3分後に自動でバックグラウンド化され、prompt cacheの失効を防ぎます（v2.1.318）

**バックグラウンドで動くサブエージェントが実行したシェルコマンドが3分を超えると、全プロバイダーでそのコマンドを自動的にバックグラウンドへ移し、その間にprompt cacheが失効しないようにする変更が入りました。** これまでは、サブエージェントが時間のかかるビルドやテストをフォアグラウンドで抱え続けると、その間にprompt cacheが失効し、復帰時にコストの高い再処理が必要になることがありました。

**ビルドやテストのような時間のかかるコマンドをサブエージェントに任せることが多いなら、v2.1.318からは3分を超えるコマンドを自分でバックグラウンドに送らなくても、prompt cacheが自動的に保護されるようになったと期待できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### macOS標準の`/bin/bash`でのgit commit・PR作成がより安定して動作します（v2.1.318）

**BashツールがmacOS標準の`/bin/bash`で実行される際の、git commitとpull request作成の信頼性が改善されました。** zshが標準シェルのmacOSでも、Claude CodeのBashツール自体は`/bin/bash`を使いますが、これまでこの組み合わせでコミットやPR作成が時々失敗したり、不安定に動作することがありました。

**macOSでClaude Codeによるコミットやプルリクエスト作成を自動化していて、原因のわかりにくい失敗を時々経験していたなら、v2.1.318へアップデートしてこの部分が安定したか確認してみる価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `deniedMcpServers`がURLで一致するAnthropic提供サーバーとコネクタもあわせてブロックします（v2.1.318）

**`deniedMcpServers`にURLを登録してブロック設定を行う際、そのURLとアップストリームが一致するAnthropic提供サーバーもブロック対象に含まれるようになり、クラウドセッションやセルフホストランナーのコネクタについても、セッションにそのコネクタ固有のURLが渡される場合は同様にブロックできるようになりました。** それ以外のコネクタは依然として名前でブロックする必要があります。これまではURLベースのブロックリストがAnthropicが直接提供するサーバーやコネクタには適用されず、組織のポリシーで特定のアップストリームを禁止していても、Anthropic提供の経路から回避できる可能性がありました。

**組織として`deniedMcpServers`で特定のMCPサーバーへのアクセスを禁止しているなら、v2.1.318からURLベースのブロック範囲がAnthropic提供のサーバー・コネクタにも広がった点を、ポリシーの見直しに反映しておく価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

**Claude Codeで金融・開示関連の記事を作成したりレビューしたりするワークフローを使っているなら、文章だけ整えて数値はそのまま信じてしまうミスを、このMCPサーバーでもう一段チェックしてみる価値があります。** [GeekNews](https://news.hada.io/topic?id=36523)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.318**（11/4）の項目です。

- **画像が20枚を超えるリクエストで、画像が大きすぎるというエラーが常に2000px制限だと表示していた問題が修正**され、APIが実際に返す制限値が表示されるようになりました。
- **バックグラウンドサブエージェントの実行中、「Now using usage credits」の通知が約30秒ごとに繰り返し表示される問題が修正**されました。
- **ClaudeがPushNotification呼び出しでstatusフィールドを渡し忘れた際に、通知が重複して表示される問題が修正**されました。
- **IDEターミナル内で起動したClaude Codeが、IDE拡張機能を自動でインストール・更新しなくなりました。** 外部のターミナルやエディタの拡張機能画面から`/ide`を使ってください。
- **Claude Codeがセッション中に作られたmodを有効にするか尋ねた際、ユーザーの回答が記録されるようになりました。**
- **不正な`~/.claude.json`を、非対話実行時に黙ってデフォルト値で上書きしていた問題が修正**され、起動が失敗して復旧方法が案内されるようになりました（anthropics/claude-code#87551）。
- **`claude plugin validate`が、`claude plugin marketplace add`では拒否されるカスタム名を使ったマーケットプレイスファイルを通過させてしまう問題が修正**されました。
