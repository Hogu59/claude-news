## 主要な新機能と実践活用

### claude.aiアカウントのスキル・プラグインがターミナルセッションにも同期されます（v2.1.275）

**claude.aiアカウントでログインしたターミナルセッションに、そのアカウントで有効化しているスキルとプラグインが自動的に同期されます。** **ウェブ側で有効にしたスキルをターミナルで改めて設定する必要がなくなる一方、同期を望まない場合は明示的にオフにする必要があります。**

```json
// settings.json
{
  "syncClaudeAiSkills": false,
  "syncClaudeAiPlugins": false
}
```

**claude.ai上でチーム共有のスキルを管理している場合、ターミナルセッションごとに個別インストールする手間がなくなります。一方、会社アカウントと個人の実験用スキルを分けて使いたい場合は、このオプションで同期をオフにしておくほうが安全です。** [全リリースノート](https://github.com/anthropics/claude-code/releases)

### ターンを即座に終了し、キューのメッセージを一括送信するsend-nowキーが追加されました（v2.1.275）

**ctrl+enterまたはctrl+x ctrl+sを押すと、進行中のターンを即座に中断し、それまでキューに溜めていたメッセージをまとめて送信します。** **送信済みメッセージと送信待ちのメッセージは、モデルが実際に受け取るまでグレー表示になるため状態を区別できます。**

**長い作業の最中に後続の指示を何度もキューに溜める癖がある人は、このショートカットで次の指示を待たずに即座に反映させられます。** [全リリースノート](https://github.com/anthropics/claude-code/releases)

### `/plugin install <plugin> --marketplace <source>`でマーケットプレイスの追加とインストールを一度に処理できます（v2.1.275）

**プラグインをインストールする際、対象のマーケットプレイスがまだ登録されていなくても、コマンド1つでマーケットプレイスの追加まで提案してもらえます。**

```bash
# マーケットプレイスがなくても、インストールコマンド1つで追加するか尋ねられます
claude plugin install my-plugin --marketplace https://github.com/org/marketplace
```

**社内プラグインマーケットプレイスを新しくセットアップするたびに`marketplace add`と`install`を別々に実行していたチームなら、オンボーディング手順をこの1行に簡略化できます。** [全リリースノート](https://github.com/anthropics/claude-code/releases)

### OpenSpec — コーディングエージェントと実装前に仕様をすり合わせる開発ツール（9/17）

**Claude Codeにいきなり実装を任せて、結果が期待と違うたびに差し戻すことが多いなら、実装前に仕様を合意するステップをワークフローに組み込むことで試行錯誤を減らせます。** [GeekNews](https://news.hada.io/topic?id=33841)

### HarnessTax — コーディングエージェントにおいてハーネスはどれだけ重要か？（9/17）

**7つのモデルをClaude Code、Codex CLI、Piに接続して比較した結果、同じモデルでも作業成功率はほぼ同等なのに、トークンコストは最大5倍も差が出ました。** **読み込み・書き込み・編集・bashしか提供しないシンプルなハーネスであるPiも、コスト対成功率では十分な競争力を見せました。**

**Claude Codeを他のハーネスや自作のエージェントループと比較検討しているなら、機能が多いほど必ずしもコスト効率が良いわけではないというこの結果は、ベンチマーク設計の参考になります。** [GeekNews](https://news.hada.io/topic?id=33842)

## 知っておくと便利な小さな変更点

- **メモリ使用量が危険な水準になると目立つ警告が表示され、メモリを解放する方法や安全な再起動手順も併せて案内**されます（v2.1.274）。
- **`CLAUDE_CODE_MCP_STARTUP_WAIT_MS`で、最初の非対話ターンが接続中のMCPサーバーを待つ時間を制限**できます。`0`に設定すると一切待たなくなります（v2.1.274）。
- **npmソース経由でインストールするプラグインが`npm pack --ignore-scripts`で取得され、整合性も検証される**ようになり、パッケージのインストールスクリプトが実行されなくなりました（v2.1.275）。
- **`otelHeadersHelper`の設定に失敗すると起動時に警告が表示**されるようになり、テレメトリが静かに送信されないセッションにすぐ気づけます（v2.1.275）。
- **フルスクリーンモードで折りたたまれたチームメンバー・エージェントのメッセージをクリックしてその場で展開**できるようになりました（v2.1.274）。
- **ClaudeアプリゲートウェイのPostgres接続タイムアウトを`store.connect_timeout_seconds`で延長**できるようになり、データベースの接続が数秒遅れても起動が最大3回までリトライされます（v2.1.274）。
