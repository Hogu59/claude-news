## 主要な新機能と実践活用

### `"attribution": false` — コミット・PRのアトリビューションをまとめて非表示にする (v2.1.281)

**`settings.json`に`"attribution": false`を追加すると、すべてのコミットとPRのアトリビューション表記が表示されなくなります。** **ただし旧バージョンのCLIはこの値が含まれる設定ファイル全体を読み飛ばしてしまうため、複数バージョンが混在する環境で設定ファイルを共有している場合は、booleanではなく従来のオブジェクト形式を維持する必要があります。**

```json
{
  "attribution": false
}
```

**社内ポリシーとしてコミットメッセージにAIツールの表記を入れないと決めているチームなら、コミットごとに個別指示を出さなくても、この設定一つで組織全体に一括適用できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### Autoモードのサーバーサイドclassifier、適用範囲がダイレクトAPI接続とread-onlyコマンドにも拡大 (v2.1.281)

**`CLAUDE_CODE_AUTO_MODE_SERVER`がダイレクトAnthropic API接続にも適用されるようになり、`0`はサーバーサイドclassifierをオプトアウト(この場合ローカルclassifierの使用量にカウント)、`1`はオプトインを意味します。** **サーバーサイドclassifierが動作するセッションでは、read-only・sandboxedなshellコマンドもレビュー対象となり、classifierが問題ありと判定すると実行がブロックされます。**

```bash
# ダイレクトAnthropic API接続でサーバーサイドのAutoモードclassifierを明示的に有効化
export CLAUDE_CODE_AUTO_MODE_SERVER=1
```

**9/19のv2.1.278でBedrock・Vertex・Foundry・ゲートウェイ環境にサーバーサイドclassifierがデフォルト化されたのに続き、今回はダイレクトAPI接続とread-onlyコマンドにまで検討範囲が広がりました。Autoモードで自動化パイプラインを運用している場合、安全だと思っていた参照系コマンドもclassifierの判定待ちになり得る点に注意が必要です。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### Claudeエージェント950体、CRISPR様のリピート配列を持つ新しい酵素システムを発見 (9/24)

**大規模なDNAデータベースの中で、既知の酵素の周辺にあるリピート配列と補助タンパク質を結び付け、これまで解明されていなかった酵素システムARTを突き止めました。** **約950体のClaudeエージェントが21時間かけて2億1,000万トークンを使い、逆転写酵素20万個以上を調査した成果です。**

**9/19の生体分子モデル高速化、9/21のRSA-896素因数分解に続き、Claudeが大規模なエージェント並列実行によって科学研究の探索段階そのものを自動化する事例が積み重なっています。** [GeekNews](https://news.hada.io/topic?id=34195)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.281**(9/23)の項目です。

- **Claudeアプリゲートウェイ用Bedrockアップストリームに`assume_role`が追加**され、ゲートウェイがSTSでロールを引き受けて別のAWSアカウントのBedrockを呼び出せるようになり、開発者ごとにセッションを分離することも可能になりました。
- **Bedrockアップストリームに`guardrail: {id, version}`を指定すると、そのアップストリームを経由するすべてのリクエストにAmazon Bedrockガードレールが適用**されます。
- **MCPのURL-mode elicitationが追加**され、サーバー側からブラウザベースの認証フローを開くよう要求できるようになったほか、サーバーに完了確認手段がない場合は待機ダイアログが画面に残り続けないようになりました。
- **`claude plugin validate`がMCPサーバーまで検査**するようになり、ロード時に静かに欠落してしまう`.mcp.json`のエントリ、宣言されていない`${user_config.*}`参照、安全でないURLを報告します。
- **危険な`rm`コマンドの確認プロンプトが、2分間応答を待った後は書き直しのヒントとともにコマンドを拒否するように変更**され、無人実行のセッションが止まらずに続行できるようになりました(`CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT=1`でオフにできます)。
- **セッションのアーティファクトリンクがプロンプト下の一つのfooter pillに統合**され、ここから開く`/artifacts`は現在のセッションのアーティファクトをリストの一番上に表示します。
- **セルフホストランナーにおいて、システムプロンプトをコマンドラインのテキストではなく非公開ファイル経由で渡す**ように変更され、大きなプロンプトによる実行失敗が起きなくなります。`--system-prompt`や`--append-system-prompt`を付与しているラッパー・hookは`--system-prompt-file`・`--append-system-prompt-file`に置き換える必要があります。
