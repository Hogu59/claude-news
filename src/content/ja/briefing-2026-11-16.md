## 開発者ワークフローティップス

### サブエージェントの応答が出力トークン制限で途切れた場合、今後は全体をより簡潔にして再生成します (v2.1.325)

**これまでは、サブエージェントの応答が出力トークン制限に達して途切れると末尾部分だけが返され、本来必要だった前半の内容がそのまま失われてしまうケースがありました。今回の変更で、応答が途切れた場合にはサブエージェントへ全体の回答をより簡潔な形で書き直すよう自動的に再要求するようになりました。** 特別な設定は不要です。

**複数のサブエージェントに長めの分析レポートやコードレビュー結果を一括で生成させていて、応答が末尾だけ残って途切れてしまい最初からやり直すしかなかった経験があるなら、v2.1.325にアップデートした後はこの自動再要求がその手間を代わりに解消してくれるか確認してみる価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### 相対パスで書いたdeny権限ルールが、cd移動後や--add-dirで追加したディレクトリにもそのまま適用されます (v2.1.325)

**`Read(./.env)`のように相対パスで書かれたdeny・ask権限ルールが、セッション中に`cd`でディレクトリを移動したり`--add-dir`で別のフォルダを追加したりした後は保護対象から外れてしまう問題が修正され、プロジェクトのディレクトリと追加先のディレクトリの両方に正しく適用されるようになりました。**

```json
{
  "permissions": {
    "deny": ["Read(./.env)", "Read(./secrets/**)"]
  }
}
```

**モノレポや複数のリポジトリを`--add-dir`で同時に開いて作業しつつ、`.env`のような機密ファイルを相対パスのdenyルールで保護している場合、これまではディレクトリを移動したりフォルダを追加した後もそのルールが有効に保たれているか疑わしい状況でしたが、v2.1.325からは安心してそのまま使えます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## セキュリティ・制限事項

### Claudeサービス稼働状況 — 本日(11/16)新規インシデントはないものの、iOSアプリのApple経由新規登録エラーが2日以上未解決のままです

**公式のstatus.claude.comを確認したところ、11/16(本日)のセクションは「No incidents reported today」となっており新規報告インシデントはありませんが、claude.aiは依然Degraded Performance表示のままです。** 11/15のブリーフィングで「調査中」として取り上げたClaude iOSアプリのApple経由新規登録エラー(11/14 07:11 UTCに調査開始、主に新規アカウントに影響)は、まだ解決扱いになっておらず続いているようです。最終更新は11/14 20:12 UTCで、それ以降新しい情報なく2日以上「調査中」のまま留まっています。Claude API・Claude Code・Claude Console・Claude Cowork・Claude for Governmentはいずれも正常稼働中です。

**最近Claude iOSアプリでApple IDによる新規登録ができない場合、端末側の問題ではなくこの長期未解決インシデントが原因である可能性が高く、急ぎの場合はGoogleやメールアドレスでの登録を使い続けるのが無難です。Claude Code CLI自体はこの問題の影響を受けません。** [Claude Status](https://status.claude.com)

### Claude CodeのEditツールにあったTOCTOU競合状態の脆弱性が公開されました — CVSS 8.8、v2.1.251で修正済み (公開日11/9)

**Claude CodeのEditツールがmacOS上で対象パスのシンボリックリンクを検証した後、その結果をディレクトリのinodeやファイルディスクリプタに固定していなかったため、検証処理と実際の書き込み処理の間の隙を狙ってサンドボックス内で動く攻撃者コードがワークスペースの親ディレクトリをシンボリックリンクに置き換え、ワークスペース外のユーザー書き込み可能なファイルを上書きできてしまう脆弱性(CVE-2026-88968、CVSS 3.1基準で8.8)が公開されました。** 悪意あるリポジトリを開いたり依存関係のインストールスクリプトを実行したりして、サンドボックス内で攻撃者コードが先に動く必要がある条件付きの脆弱性で、v2.1.251以降では既に修正されています。自動更新を利用していれば既に修正版が適用されているはずで、現在の最新版はそれよりもさらに新しいv2.1.325です。

**自動更新を使わず特定バージョンに固定して運用している場合や、手動でアップデートを管理している場合は、v2.1.251以降かどうか今のうちに確認しておく価値があります。見知らぬリポジトリを開いたり依存関係のインストールスクリプトを実行したりする際は、バージョンに関わらず注意しておくのが安全です。** [GitLab Advisory Database](https://advisories.gitlab.com/npm/@anthropic-ai/claude-code/CVE-2026-88968/)
