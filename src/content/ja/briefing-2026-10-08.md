## 主要な新機能と実践活用

### Claude Haiku 5.5リリース — Haiku 4.5比で平均コスト75%削減(v2.1.293)

**AnthropicはClaude Haiku 5.5(`claude-haiku-5-5`)を公開し、Anthropic APIのデフォルトHaikuモデルとして切り替えました。** 要約、文脈圧縮、データベースクエリ、分類、コーディング補助エージェントのような大量に繰り返されるタスクに最適化されており、プロンプトが10万トークン以下の場合は100万トークンあたり入力$0.10・出力$0.50(10万トークン超では入力$0.50・出力$2.50)と、Haiku 4.5に比べて入出力価格を90%引き下げました。これにより平均実行コストは約75%削減され、コンテキストは100万トークンまで対応します。コンピュータ操作(OSWorld 2.1)ベンチマークでは72.4%、エージェントコーディング(Terminal-Bench 4.0)では39.2%を記録しました。Max 5x・20xプランには月100〜200ドル、TeamプランにはメンバーでシェアできるClaude Platform全モデル向けAPIクレジットが月最大500ドルの範囲で付与されます。

```bash
# Claude Codeセッションのモデルをhaiku 5.5に切り替え
/model claude-haiku-5-5
```

**ログ要約、データベースクエリ、分類、軽量なコーディング補助サブエージェントといった大量の繰り返しタスクを動かしているなら、従来のHaiku 4.5よりはるかに安くなったHaiku 5.5に切り替えるだけでコストを大きく減らせます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases) · [GeekNews](https://news.hada.io/topic?id=34958)

## 開発者ワークフローティップス

### Codemodeパターン — ツール呼び出しをコードにまとめてコンテキストを節約(10/8)

**CodemodeはAIがツールを1つずつ呼び出す代わりに、複数の呼び出しをまとめたコードを書いて実行する方式で、繰り返しや並列処理、中間結果の加工をコード側に任せ、必要な結果だけをモデルに渡すことでコンテキスト使用量を大幅に削減します。** Claude Codeにも既に似た仕組みがあり、Workflowツールは`agent()`・`parallel()`・`pipeline()`関数で複数のサブエージェント呼び出しを1つのスクリプトにまとめて実行し、最終結果だけを返します。

```js
// 複数のサブエージェント呼び出しをコードにまとめて一度に実行
const results = await parallel([
  () => agent('ファイルAのバグをチェック'),
  () => agent('ファイルBのバグをチェック'),
])
```

**サブエージェントを何度も逐次呼び出し、その都度中間結果をそのままコンテキストに積んでいるなら、呼び出しをコードにまとめて必要な結果だけを受け取る方式に変えることで、同じ作業をより少ないコンテキストで終えられます。** [GeekNews](https://news.hada.io/topic?id=34952)

### モードでよく使うツールはisDeferred: falseで最初から公開する(v2.1.293)

**モード(プラグイン)のコードで`$.tool.register`に`isDeferred: false`を指定すると、そのツールのスキーマが最初からプロンプトに載ってモデルに渡されます。** 指定しない場合、ツールは名前だけが見える状態になり、モデルがスキーマを見るにはToolSearchでもう一度問い合わせる遅延読み込み状態のままになります。

```js
// よく使うツールは即時公開してToolSearchの往復をなくす
$.tool.register('myFrequentTool', { isDeferred: false /* ... */ })
```

**ほぼ毎ターン呼び出される中核ツールを持つモードを作っているなら、そのツールだけ`isDeferred: false`に指定してモデルがToolSearchを経由せずすぐにスキーマを見られるようにすれば、繰り返し呼び出しによる遅延とトークンの浪費を減らせます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## セキュリティ・制限事項

### Claudeサービス状況 — 10/8現在Claude Consoleが性能低下、他は正常(10/8)

**公式status.claude.comを直接確認したところ、10/8現在claude.ai・Claude API・Claude Code・Claude Cowork・Claude for Governmentはすべて正常(Operational)ですが、Claude Console(platform.claude.com)は使用量データの読み込み遅延により性能低下(Degraded Performance)状態です。** アナウンスによると、直近約30分の使用量がプラットフォームに反映されるまでより時間がかかる可能性があり、肝心のAPIリクエスト自体には影響しません。10/7には支出上限の処理エラーにより一部組織のリクエストがClaude API・claude.ai・Claude Code・Claude Coworkで誤って拒否されるインシデント(21:23 UTCに解決)と、別件の使用量データ読み込みエラーがあり、10/6のOpus 5.5エラー増加(12:43 UTCに解決)もすべて当日中に解消されています。

**Claude Consoleの使用量ダッシュボードの数値が最新状態と合っていないように見える場合、今回の性能低下が関係している可能性が高く、Claude Code自体の作業やAPI呼び出しには影響がないため通常どおり利用して問題ありません。** [Claude Status](https://status.claude.com)

### DNSハイジャックでGoogleなど大手サービスの偽造TLS証明書が発行されました(10/8)

**攻撃者が国コードトップレベルドメイン(.gh、.sl、.as)3つを乗っ取り、権威DNSレコードとネームサーバー委任を改ざんし、自動化されたドメイン所有権検証を通過させてGoogleなど複数の大手オンラインサービスのドメインに対する偽造TLS証明書を不正に取得しました。** 被害ドメインの所有者側のシステム自体は侵害されておらず、Googleは被害の具体的な範囲を公表していません。

**自分が運用するドメインに証明書透明性ログの監視を設定し、CAA DNSレコードで証明書発行権限を制限しておけば、このようにDNS委任が乗っ取られた場合でも攻撃者がさらに証明書を取得する経路を塞ぐことができます。** [GeekNews](https://news.hada.io/topic?id=34955)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.293**(10/7)の項目です。

- **`subagentStatusLine`ペイロードに`agentType`が追加**され、スクリプト側でカスタムサブエージェントの種類を区別できるようになりました。
- **Bashツールで`cat`・`head`・`tail`・`sed -n`・`grep`を使って単一ファイルを参照する際、パス範囲ルールとネストしたCLAUDE.mdが読み込まれない問題が修正**されました。Readツールの代わりにこうしたコマンドでファイルを見ると、CLAUDE.mdの指示が静かに抜け落ちる可能性があったということです。
- **`claude purge`がファイルやフォルダを削除できない場合に、黙って止まる、または終了コード0で止まっていた問題が修正**され、今後は残りを削除した上で削除できなかった項目を列挙し、終了コード1で終了するようになりました。
- **v2.1.290で修正された「コンテナ再起動後にクラウドセッションが復帰できない」問題の修正が、今回取り消されました。** コンテナの再起動で待機中の`/loop`ウェイクアップや予約タスクを取りこぼすと、Claudeに通知されずセッションがそのまま休止状態になる以前の動作に戻っています。
- **claude.aiのスキル同期チェックの間隔が、セッションが使われていない間は10分から約40分に延びました。**
- **OpenTelemetryの`claude_code.at_mention`ログ記録が、プロンプト1回あたりエージェント・MCPリソースイベントそれぞれ最大100件までしか記録されない**ように変更されました。
