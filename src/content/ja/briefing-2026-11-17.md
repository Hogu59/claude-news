## 開発者ワークフローティップス

### エージェントチームを有効にした状態でもCode Modeが使えるようになりました (v2.1.326)

**11/12のブリーフィングで紹介した実験的機能Code Mode(複数のツール呼び出しをJavaScriptにまとめて一度に実行する機能)は、これまでagent teams機能と同時に有効化できませんでしたが、今回のリリースから併用できるようになりました。** すでにCode Modeを有効にしていた場合、チーム機能をオンにしたセッションは起動時から自動的にCode Modeで始まります。

**複数のサブエージェントをチームとしてまとめて運用しつつ、Code Modeによるラウンドトリップ遅延の削減効果も享受したかった方は、v2.1.326にアップグレードすれば特別な設定なしに両方の機能を同時に有効化できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `--allowedTools`・`--disallowedTools`・`--tools`に不完全なルールを書くと、起動時に警告が出るようになりました (v2.1.326)

**権限ルールを完全な形で書かなかった場合(例:ツール名だけ書いて括弧内のパターンを書き忘れるケースなど)、これまでは何も言わずに無視されていましたが、今後はClaude Code起動時にどの項目が完全なルールに見えないかを警告で知らせてくれます。**

```bash
# 例: 括弧内のパターンが欠けた不完全なルール
claude --allowedTools "Bash" --disallowedTools "Read(./secrets"
```

**CIスクリプトやシェル関数で`--allowedTools`・`--disallowedTools`の値を組み立てて使っている場合、v2.1.326から表示されるこの起動時警告は注目に値します。これまでルールが黙って無視されて意図通りに動いていなかったケースをすぐに見つけられます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### OpenTelemetryのリソース属性にホスト情報を含める`OTEL_RESOURCE_INCLUDE_HOST`が追加されました (v2.1.326)

**この環境変数を有効にすると、OpenTelemetryへエクスポートするリソース属性に`host.name`と`host.id`が追加されます。** デフォルトは無効です。

```bash
# OpenTelemetryのリソース属性にhost.name、host.idを含めたい場合
export OTEL_RESOURCE_INCLUDE_HOST=1
```

**複数台のマシンでClaude CodeをOpenTelemetryで監視していて、どのホストで発生したイベントか区別しづらいと感じていた方は、v2.1.326からこの環境変数でホスト単位の識別をすぐに追加できます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## セキュリティ・制限事項

### Claudeサービス状況 — Claude Meetingsの参加エラーが続いており、iOSアプリのログインエラーは解決済みです

**公式のstatus.claude.comを直接確認したところ、本日(11/17)新たに報告されたインシデントはありませんが、11/16 15:10 UTCから発生しているClaude Meetings(ベータ)の参加エラーはまだ解消されていません。** 新しい通話にClaudeが参加できない問題で、自動参加(Auto-join)機能は一時停止されており、手動での追加操作も影響を受けます。進行中の通話や主要機能には影響はなく、直近の更新(11/16 18:10 UTC)では一部の通話で参加できない状態が続く可能性があり、完全な解決にはさらに時間がかかると案内されています。一方、11/16のブリーフィングで進行中として取り上げたClaude iOSアプリのApple ID経由の登録エラーは、11/16 19:52 UTCに解決の告知が出され、3日以上続いた末にようやく収束しました。これ以外にも、11/16 07:32〜08:45 UTCにはClaude Sonnet 5.5・Fable 5.2のリクエストエラーが一時的に増加するインシデントがありましたが、こちらは速やかに解決しています。claude.aiはこうした経緯もあり依然Degraded Performanceと表示されており、Claude API・Claude Code・Console・Cowork・Governmentはすべて正常です。

**Claude MeetingsでClaudeを会議に自動参加させるワークフローを使っている場合、当面は手動で参加状況を確認する方が安全です。Claude Code CLI自体はこのインシデントの影響を受けず、通常どおり利用できます。** [Claude Status](https://status.claude.com)

### bypass permissionsモードとPowerShellツールで承認が必要になる範囲が広がりました (v2.1.326)

**これまで、承認をすべてスキップするbypass permissionsモードでも実行されていた一部のツール呼び出しが、今回のリリースからはそのモードでも承認を求められるか、誰も応答できない状況では拒否されるように変更されました。** PowerShellツールについても、より多くのコマンドで事前に承認を求めるようになり、その一部はbypass permissionsモードでも承認が必要になります。また、組み込みコマンドと同じ名前の関数を定義するような一部のPowerShellコマンドは、完全に拒否されるようになりました。

**bypass permissionsモードで無人の自動化を運用している場合、v2.1.326へアップグレードした後、これまでそのまま通過していた一部のコマンドが突然止まって承認待ちになったり拒否されたりする可能性がある点を、あらかじめ想定しておくとよいでしょう。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## エコシステム＆プラグイン

### Taskhand — Claude Codeの使用量タブとローカルAIを内蔵した無料のWindows業務自動化ツール (11/17)

**作者が毎日繰り返していたWebログインの確認、Excel・CSVの整理、ページ変更の検知、フォルダのバックアップといった作業を自動化するために作られたWindows専用ツールです。** Web上の操作を一度録画すればそのまま再現する「なぞる」機能、スケジュール実行・連携実行、サイト・サーバーの状態やディスク容量の監視、Slack・Teams・Discordへの通知、メールで依頼するとPCが作業を実行するリモート実行機能を備えています。「言葉でお願いする」欄にやりたいことを書くとAIが自動化ファイルを作成し試験実行まで行ってくれますが、デフォルトのAIは内蔵されたローカルモデル(llama.cppベースのGemma 4)で、すでに契約しているClaude Code・Codex・Gemini CLIから選んで使うこともでき、Claude Codeを使う場合はトークン使用量を表示する専用タブも用意されています。Windows 10/11専用で管理者権限なしにインストールでき、コード署名がないため初回起動時にSmartScreenの警告が表示されます。

**すでにClaude Codeを契約していて、繰り返し発生するWindowsのデスクトップ作業までAIに任せたいと考えていた方は、追加料金なしで既存の契約をそのまま使い回すこのツールの発想が参考になります。** [プロジェクトページ](https://swbins.github.io/taskhand/) ・ [GeekNews](https://news.hada.io/topic?id=37312)
