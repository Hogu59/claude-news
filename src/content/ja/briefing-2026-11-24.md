# Claude Code デイリーブリーフィング - 2026-11-24

## 最新リリース概要

| バージョン | 日付 | 主な変更点 |
|------|------|----------|
| **v2.1.331** | 11/23 | Bedrock・GCP Agent Platform・Microsoft Foundry・AWS Claude PlatformのターミナルセッションにCode Modeサポートを追加、`claude doctor`にAPI接続状態のチェックを追加、VS CodeにFix with Claude Code・Resolve Merge Conflictsを追加するなど、数百件の機能・安定性修正 |

**v2.1.330(11/20)から3日後の11/23、v2.1.331がリリースされました。** Code Modeのプラットフォーム拡大とclaude doctorの診断強化、VS Codeの生産性向上機能が目立ちますが、それ以外にもMCPツール呼び出しが最大30分間止まっていた問題や、中断したプラグイン更新がスキル欠落につながっていた問題など、数百件の安定性修正が含まれています。

## 開発者ワークフローティップス

### Code ModeがBedrock・GCP Agent Platform・Microsoft Foundry・AWS Claude Platformのターミナルセッションまで拡大されました (v2.1.331)

**これまでCode Mode(Claudeがツール呼び出しをコードとして書いて実行するモード)は主にClaude Platformの標準環境でしか使えませんでしたが、今回のリリースからAmazon Bedrock・Google CloudのAgent Platform・Microsoft Foundry・AWS上のClaude Platformで開いたターミナルセッションでもCode Modeが使えるようになりました。** 同リリースではCode Mode内の`gen_ai.usage.*`・`gen_ai.response.model`・`gen_ai.operation.name`トレーススパンもOpenTelemetryで公開されるよう改善され、どのプラットフォームで動かしていてもトークン使用量とモデル情報を同じ方法で観測できます。

**組織のポリシー上、Bedrockや Foundry、AWS上のClaude Platformのような標準環境以外でClaude Codeを運用していてCode Modeが使えなかった場合、v2.1.331へのアップグレード後は同じプラットフォームでもCode Modeの速度とトークン削減効果をそのまま享受できそうです。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### `claude doctor`にAPI接続状態をその場で確認できる診断項目が追加されました (v2.1.331)

**これまでClaude CodeがAPIに接続できないとき、原因がネットワークなのかプロキシなのか認証情報なのかを見極めるにはログを自分で調べる必要がありましたが、今回のリリースから`claude doctor`にAPI接続状態のセクションが追加され、APIに到達できるか、到達できない場合はHTTPステータスやエラーが何か、あるいはなぜテストできなかったのかがその場で表示されます。**

```bash
claude doctor
# → "API connectivity" セクションで接続可否・HTTPステータス・エラー原因をその場で確認
```

**社内プロキシやゲートウェイ経由でClaude Codeを使っていて接続トラブルが起きると、そのたびにユーザーにログを依頼して原因を追っていた場合、v2.1.331からは`claude doctor`を一度実行するだけで接続failureの箇所をまず絞り込めそうです。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### VS Codeにエラーをその場で修正するFix with Claude Codeとマージコンフリクト解決ボタンが追加されました (v2.1.331)

**これまでVS Codeでエラーや失敗したテストをClaudeに修正してもらうには、内容を自分でコピーしてチャット欄に貼り付ける必要がありましたが、今回のリリースからエラー・警告やTest Results表示・失敗テストのプレビューのQuick Fixメニューにフィックス Fix with Claude Codeが追加され、問題の内容がそのままチャット欄に送られます。** マージコンフリクトのあるファイルのエディタタイトルバーとソース管理のMerge Changesグループには、Resolve Merge Conflictsボタンも新設されました。さらに、変更されたファイルの右クリックメニューにAdd to Chatが、ノートブックセルのメニューには出力・エラーまで合わせて貼り付けるAdd Cell to Chatが追加されています。

**VS Codeでエディタのエラー下線や失敗したテストを見るたびに内容をコピーしてClaudeに個別に説明していた場合、v2.1.331からはQuick FixメニューのFix with Claude Codeやマージコンフリクトファイルのresolveボタンを押すだけでそのままチャットに渡せそうです。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## セキュリティ・制限事項

### Claudeサービス状況 — 11/23に複数モデルのエラーインシデント(17分間、解決済み)、本日(11/24)は新規インシデントなし

**公式のstatus.claude.comを確認したところ、11/20〜11/22の3日間は無事故でしたが、11/23 09:39〜09:56 UTCの17分間、Claude Mythos 5.2・Fable 5.2・Opus 5.5・Sonnet 5.5・Haiku 5.5など複数のモデルでエラーが増加するインシデントが発生しました。** 原因を特定して修正を展開し、ほどなく解決済みとなっており、本日(11/24)は新たに報告されたインシデントはありません。claude.ai・Claude Console・Claude API・Claude Code・Claude Cowork・Claude for Government・AWS・Microsoft Foundry・Google Cloud上のClaudeを含むすべてのコンポーネントが現在Operational(正常)と表示されています。

**昨日(11/23)の朝に複数のモデルで応答エラーに遭遇していたとしても、17分で解決した一時的な現象なので心配は不要で、本日(11/24)は全コンポーネントが安定稼働しています。** [Claude Status](https://status.claude.com)

### 2026年11月30日からmanaged設定のプラグインマーケットプレイスがデフォルトで自動更新されるようになります (v2.1.331)

**これまでmanaged設定の`extraKnownMarketplaces`に登録されたプラグインマーケットプレイスは、自動更新するかどうかが特に定められていませんでしたが、今回のリリース告知によると2026年11月30日以降のリリースから、こうしたマーケットプレイスはデフォルトで自動更新されるようになります。** 自動更新を望まないマーケットプレイスがある場合は、その項目に`autoUpdate: false`を自分で設定する必要があります。

```json
// managed設定のextraKnownMarketplaces項目で
// 特定のマーケットプレイスの自動更新を止めたい場合
{
  "extraKnownMarketplaces": {
    "my-marketplace": {
      "autoUpdate": false
    }
  }
}
```

**組織としてmanaged設定で`extraKnownMarketplaces`を登録してプラグインマーケットプレイスを運用している場合、11月30日以降のリリースから意図せず自動更新がオンになる可能性があるので、バージョンを固定しておきたいマーケットプレイスがあれば今のうちに`autoUpdate: false`を設定しておく価値がありそうです。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.331**(11/23)の項目のうち、上記で取り上げていないものです。

- **Claude appsゲートウェイに`oidc.groups_jsonpath`が追加**され、RFC 9535準拠のJSONPath構文の一部を使ってオブジェクトリストからグループ情報を取得できるようになりました。
- **圧縮されたレスポンスを途中で切ってしまうプロキシの背後で非圧縮レスポンスを要求できる`CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`環境変数が追加**されました。ただしself-hosted runnerやRemote Controlではまだ推奨されていません。
- **`oidc.use_proxy: true`を使う環境で`NO_PROXY`が設定されていてもログインリクエストがIdPのホスト名をそのままプロキシに渡してしまう`CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1`環境変数が追加**されました。
- **プラグインマニフェストに`optionalDependencies`が追加**され、インストールするプラグインがリストアップした任意の依存プラグインを個別にオフにしたり削除したりできるようになりました。
- **ローカルやWebSocket MCPサーバーの一部の不正なレスポンスが原因で、MCPツール呼び出しが最大30分間止まっていた問題が修正**されました。
- **プラグインの更新が中断・失敗した際に、スキルなど一部のコンポーネントが欠けたプラグインフォルダが次回もそのまま読み込まれていた問題が修正**されました (anthropics/claude-code#102186)。
- **タブモードの音声入力が15秒間発話が認識されない、または2分の上限に達して自動停止する際に通知する機能が追加**されました。
