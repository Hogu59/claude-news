## 主要な新機能と実践活用

### SendFeedback ツール — セッション中に問題が起きたら Claude がフィードバックを下書きします (v2.1.247)

**セッション中に何か問題が起きた際、Claude 自身がフィードバックレポートの下書きを作成**し、ユーザーは `/feedback` でそれを確認してから送信するかどうかを判断できるツールが追加されました。

```bash
# セッション中に異常な挙動を検知すると、Claude が自動でフィードバックの下書きを用意します
/feedback
# 下書き作成そのものが不要であれば、feedbackDrafts 設定でオフにできます
```

**これまでは、セッション中に何かおかしな動作があっても、その場の文脈（何をしていて何が問題だったか）を覚えておいて、あとで別途フィードバックを書く必要がありました。** これからは、**問題が起きたまさにその瞬間の文脈を含んだ下書きが自動で用意される**ので、確認して送信するだけで済みます。[全リリースノート](https://github.com/anthropics/claude-code/releases)

### `/claude-api cost-optimize` — API コストを項目ごとに分解して削減します (v2.1.247)

```bash
# 既存プロジェクトの Claude API 支出構造をプロファイリングし、
# キャッシュ・トークン節約・バッチ処理・effort・モデル選択の順にコスト削減策を一つずつ提示します
/claude-api cost-optimize
```

**既存プロジェクトの Claude API 利用パターンをプロファイリングしたうえで、キャッシュ・トークン節約・バッチ処理・effort 調整・モデル選択という各コストレバーを一度に一つずつ、計測可能な単位でチェック**してくれるコマンドです。`claude-api` スキルには、**Admin API（組織メンバー、招待、ワークスペース、API キー、レートリミットレポート、ワークロードアイデンティティフェデレーション、CMEK）のカバレッジも合わせて追加**されました。

**API コストが想定以上に膨らんでいるのにどこから手をつければいいかわからない、という場合は、このコマンドで優先順位付けされたチェックリストをまず受け取ってみる価値があります。** [全リリースノート](https://github.com/anthropics/claude-code/releases)

### Sonnet 5 の自動圧縮しきい値が 1M コンテキスト全体まで拡大します (v2.1.247)

**1M コンテキストウィンドウを使う Sonnet 5 セッションのデフォルト auto-compact しきい値が、これまでより広がった 1M 全体を基準に再計算**されます。その結果、**自動圧縮がかかるタイミングが約93万4千トークンから約96万7千トークンへと後ろ倒し**になります。

**長文コンテキストを頻繁に埋めるセッションであれば、圧縮なしで粘れる余裕トークンが約3万トークンほど増えた**ことになります。[全リリースノート](https://github.com/anthropics/claude-code/releases)

## 開発者ワークフローティップス

### Bash 権限プロンプトからワンキーで auto mode に切り替えられます (v2.1.247)

**Bash 権限プロンプトに auto mode を案内するヒントが追加**され、**「Yes, and switch to auto mode」をワンキー入力でそのまま選択**できるようになりました。

**繰り返し出てくる Bash コマンドのたびに承認プロンプトを押してきたなら、このヒントをきっかけに auto mode への切り替えを試してみる価値があります。** どのルールが自動承認を引き起こすかは、v2.1.246 で追加された `/permissions` の Auto Mode タブで確認・調整できます。[全リリースノート](https://github.com/anthropics/claude-code/releases)

### RAG は思ったより単純です — ベクター DB より先に BM25 から (8/27)

**多くの RAG システムは最初から embedding・ベクター DB・リランキングのパイプラインを導入しがちですが、実際には検索の問題の多くを BM25 とクエリ書き換えだけで解決できる**、という指摘です。**データの鮮度、ドキュメントの更新頻度、クエリの種類、検索量、チームのスキルセットに応じて6種類の検索アーキテクチャを段階的に選び**、より複雑な構成が本当に必要になったときだけ次の段階に進むべき、というのが要点です。

**Claude Code や Claude API の上に社内ドキュメント・コードベース検索を載せる RAG パイプラインを設計しているなら、ベクター DB を導入する前にこの記事の段階別チェックリストで、いまの要件が実際どの段階に当てはまるのかを見極めておく価値があります。** [GeekNews](https://news.hada.io/topic?id=32916)

### Bedrock・Vertex・Foundry で MCP 接続失敗を Claude が正しく認識できるようになります (v2.1.247)

**Bedrock、Vertex、Foundry のセッション（およびテレメトリがオフのすべてのセッション）で、設定済みの MCP サーバーへの接続に失敗した場合、Claude が「ツールがそもそも存在しない」と誤判断するのではなく、接続失敗そのものを認識できる**ように変わりました。

**エンタープライズのデプロイ環境で MCP サーバーを運用しているなら、これまで Claude がツール不在と誤解してタスクを妙な形で迂回していた状況を、この修正で減らせます。** [全リリースノート](https://github.com/anthropics/claude-code/releases)

### プラグインマーケットプレイスが制御文字・不可視文字を含む名前を拒否します (v2.1.247)

**制御文字や不可視文字が混じったプラグイン名はマーケットプレイスに登録できなくなり**、`/plugin` および `claude plugin` の出力でも、**マーケットプレイスが提供するテキストが escape-safe に処理**されるようになりました。

**サードパーティのマーケットプレイスからプラグインをインストールして使っているなら、目に見えない文字で名前を偽装したり、ターミナル出力を細工したりする試みを、この強化が根本から防いでくれる点**は覚えておく価値があります。[全リリースノート](https://github.com/anthropics/claude-code/releases)

### リマインダー — 週間利用量50%ブースト終了まで D-4

**Claude Code の週間利用量50%ブーストが8月31日に終了**します — **D-4**です。8/26に公式 Pricing ドキュメントで確定した通り、**Sonnet 5 の入力2ドル・出力10ドルという価格は9月の値上げなしに恒久的な標準価格として維持**されます。残る変数は週間ブーストの終了だけです。

## 知っておくと便利な小さな変更点

以下はすべて **v2.1.247** の項目です。

- **`spinnerTipsOverride` に `{id, text, cooldownSessions, priority}` 項目と `tipsFile`、`label` が追加**され、組織が独自のティップスを組み込みティップスと一緒にローテーション表示できるようになりました。
- **サブエージェントが初回呼び出しでモデル404に遭遇してもクラッシュせず、セッションのフォールバックモデルチェーンを使用**するようになり、親に渡されるエラーにはエラータイプ・status・request id・モデル名が含まれます。
- **フックやバックグラウンドエージェントが数メガバイトのエラー出力を吐き出して会話が溢れ、「Prompt is too long」でセッションが止まっていた問題**が修正されます。
- **kitty-protocol ターミナルでキリル文字などラテン文字以外のキーボードレイアウトを使っている場合に Ctrl ショートカットが効かなかった問題**が修正されます。
- **Bash サンドボックスの事後クリーンアップが、サンドボックスの書き込み可能領域外に再配置された dotfile 管理(nix/home-manager、stow)の `~/.claude/settings.json` シンボリックリンクを削除してしまっていた問題**が修正されます。
- **`/terminal-setup` が Zed の `keymap.json` 全体を上書きしていた問題**が修正され、既存のキーバインドにマージされるようになりました。
- **クロスセッションのピアメッセージがデフォルトで `Message from @<sender>: <1行目>` という形の1行プレビューに折りたたまれる**ようになり、Ctrl+O で全文を展開できます。
- **ネットワーク・自動マウントパスを指す、あるいは制御文字・不可視文字で始まるターミナルのハイパーリンクが、プレーンテキストとしてレンダリング**されるようになりました。

## 注目プロジェクト＆ツール

- **SELF — クエリ可能な実行ファイル (8/27)**: **プログラムを SQLite データベースとして構成し、コードだけでなく Web サイト、ルート、閲覧履歴、アプリケーション状態までを1つのファイルに保存**する実験的プロジェクトです。**Linux の `binfmt_misc` が専用インタプリタを起動すると、segments テーブルをメモリにマッピング**して動作します。アプリケーションのコードと状態を分けて扱う通常のやり方とは異なるアプローチで、**1つのファイルの中で実行・データ・履歴を一緒にクエリできる**というアイデアが新鮮です。[GeekNews](https://news.hada.io/topic?id=32922)
- **Tailcat — Tailscale アカウント不要で2台のマシンをつなぐ netcat (8/27)**: **Tailscale のオープンソースデータプレーンを利用し、Tailscale アカウントやコントロールサーバーなしに2台のマシンを接続できる netcat 形式の CLI・Go ライブラリ**です。**サーバー側が出力した短い接続トークンを相手に伝えるだけで、標準入出力や TCP ポートが WireGuard 暗号化トンネルで接続**されます。リモートマシンと一時的に安全な接続が必要なとき、**アカウント登録なしですぐ使える軽量な代替手段**です。[GeekNews](https://news.hada.io/topic?id=32920)
