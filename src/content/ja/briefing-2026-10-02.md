## 主要な新機能と実践活用

### Claude Modsと最初の公式モードYou should know — プラグインがより深い動作まで変更可能に (v2.1.287)

**Claude Modsという新しいプラグイン拡張ポイントが追加され、プラグインがClaude Codeのより深い動作まで変更できるようになりました。** 最初の公式モードとしてYou should knowがバンドルされており、サイドエージェントが作業を見守りながら、ユーザーやClaudeが見落としがちな点を指摘してくれます。

```bash
# テレメトリが有効なファーストパーティセッションで有効化
/plugin enable cc-plugin-you-should-know@builtin
```

**長時間のリファクタリングや複雑な多段階タスクの最中にユーザーもClaudeも気づきにくいエッジケースや副作用を、サイドエージェントが代わりに拾ってくれるため、重要な変更を一人でレビューする負担を減らせます。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

### Opus 4.7以降・Fableが、Bedrock・Vertex・Foundry・ゲートウェイで1Mコンテキストをデフォルトに (v2.1.287)

**Opus 4.7以上とFableモデルが、Bedrock、Vertex AI、Foundry、Claudeアプリのゲートウェイにおいて、これまでモデルIDの末尾に付けていた`[1m]`サフィックスなしでも、デフォルトで100万トークンのコンテキストを使うようになりました。** 従来の200Kを維持したい場合は環境変数でオフにできます。

```bash
# 100万トークンコンテキストの代わりに従来の200Kを維持する場合
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

**Bedrock・Vertex・Foundry環境で大規模なコードベースを扱う組織にとっては、特別な設定なしに広いコンテキストを使えるようになる一方、トークン使用量やコストが予想以上に増える可能性があるため、予算を管理している場合はこの環境変数を事前に確認しておく価値があります。** [リリースノート全文](https://github.com/anthropics/claude-code/releases)

## 開発者ワークフローティップス

### 考えを整理する手段としてのコミット説明文 (10/2)

**コミット説明文を自分で書くという行為自体が、コードの変更内容を振り返り判断を見直す作業であり、特にAIが生成した変更が意図どおりかを確認するのにも役立つという内容の記事です。** 何を変えたかよりなぜ変えたかを記録しておくことで、同僚や未来の自分が変更の理由を理解できるようになる点がポイントです。

**Claude Codeにコミットメッセージの作成まで任せている場合、生成されたメッセージをそのまま使う前に、なぜが正しく書かれているかを自分で確認する工程を挟んだほうが、変更履歴の品質を保つうえで有利です。** [GeekNews](https://news.hada.io/topic?id=34623)

### バグ発見 — オラクルのないファジングは結果を検証できない (10/2)

**Rustのregexとregex_liteの結果を互いに比較するファザーで、旧バージョンの既知バグと新しいバグを同時に見つけた事例です。** ポイントは、アルゴリズムのテストでは正解を判定するオラクルと結果を照合する工程がなければ信頼できる結果は得られないということです。最新バージョンではもはやバグは見つかりませんでした。

**Claude Codeにファザーやプロパティベーステストを書かせる際は、入力をランダムに生成させるだけでなく、比較対象となるオラクル（別の実装、リファレンスアルゴリズムなど）も一緒に指定してやると、実際に使えるテストが得られる可能性が高まります。** [GeekNews](https://news.hada.io/topic?id=34618)

## 知っておくと便利な小さな変更点

以下はすべて**v2.1.287**（10/1）の項目です。

- **エージェントビューに`n:<text>`フィルターが追加**され、セッション名とタスクを基準に直接検索できるようになりました。
- **OpenTelemetryの`user_prompt`イベントに`prompt_text`フィールドが追加**されました。`prompt`を削除・マスキングしているバックエンドは、このフィールドも併せて処理する必要があります。
- **MCPサーバーの`alwaysLoad: false`設定が、そのサーバーの全ツールをtool search後回しにする**ように変更されました。
- **Windowsでbashツールを拒否するとPowerShellツールまで無効化されてしまう場合に起動時の警告が追加**され、Claudeがシェルツールを一切持たない状態に入ることを事前に把握できるようになりました。
- **macOS・Linuxのセルフホストランナーに`gh api`（REST専用）が組み込まれ**、GitHub CLIがインストールされていないマシンでも、Anthropic管理のgitを使うセッションがすぐに利用できます。
- **2025-11-25プロトコルのMCPサーバーが送るURLプロンプト（ログインなど）をサポート**しました。更新後にサーバー接続が切れた場合は、該当のMCP設定に`bareElicitationCapability: true`を追加してください。
