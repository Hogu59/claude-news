## New Features & Practical Usage

### Claude Haiku 5.5 Launches — 75% Lower Average Cost Than Haiku 4.5 (v2.1.293)

**Anthropic has released Claude Haiku 5.5 (`claude-haiku-5-5`) and made it the default Haiku model in the Anthropic API.** It's optimized for high-volume, repetitive work — summarization, context compaction, database queries, classification, and coding-assistant subagents — and cuts input/output pricing by 90% versus Haiku 4.5: $0.10/$0.50 per million input/output tokens for prompts under 100K tokens, and $0.50/$2.50 beyond that. That brings average run costs down by about 75%, while context length holds steady at up to 1 million tokens. It scores 72.4% on the computer-use benchmark (OSWorld 2.1) and 39.2% on agentic coding (Terminal-Bench 4.0). Max 5x/20x plans come with $100–200/month in API credit usable across the whole Claude Platform model lineup, and Team plans get up to $500/month shared among members.

```bash
# Switch a Claude Code session's model to Haiku 5.5
/model claude-haiku-5-5
```

**If you're running high-volume repetitive work — log summarization, database queries, classification, lightweight coding subagents — switching from Haiku 4.5 to the now much cheaper Haiku 5.5 can cut costs significantly with just a model swap.** [Full release notes](https://github.com/anthropics/claude-code/releases) · [GeekNews](https://news.hada.io/topic?id=34958)

## Developer Workflow Tips

### The Codemode Pattern — Bundling Tool Calls as Code to Save Context (10/8)

**Codemode has the AI write code that bundles multiple tool calls together instead of invoking them one at a time, offloading loops, parallelism, and intermediate-result processing to code so only the results that matter reach the model — cutting context usage substantially.** Claude Code already has something similar: the Workflow tool's `agent()`, `parallel()`, and `pipeline()` functions let you bundle multiple subagent calls into a single script and get back only the final result.

```js
// Bundle multiple subagent calls as code and run them in one shot
const results = await parallel([
  () => agent('Check file A for bugs'),
  () => agent('Check file B for bugs'),
])
```

**If you've been calling subagents sequentially and piling every intermediate result straight into context, bundling those calls into code and pulling out only what you need can get the same work done with far less context.** [GeekNews](https://news.hada.io/topic?id=34952)

### Expose Frequently Used Mode Tools Immediately with isDeferred: false (v2.1.293)

**Setting `isDeferred: false` on `$.tool.register` in mode (plugin) code makes that tool's schema load into the prompt from the start.** Without it, a tool shows up by name only, left in a deferred state where the model has to make an extra ToolSearch round trip just to see its schema.

```js
// Expose a frequently used tool immediately to skip the ToolSearch round trip
$.tool.register('myFrequentTool', { isDeferred: false /* ... */ })
```

**If you're building a mode with a core tool that gets called on almost every turn, setting just that tool to `isDeferred: false` lets the model see its schema immediately instead of going through ToolSearch — cutting the latency and token overhead of repeated calls.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude Service Status — Claude Console Degraded as of 10/8, Everything Else Normal (10/8)

**Checking status.claude.com directly: as of 10/8, claude.ai, the Claude API, Claude Code, Claude Cowork, and Claude for Government are all Operational, but Claude Console (platform.claude.com) is in Degraded Performance due to delayed usage-data loading.** Per the status page, usage from roughly the past 30 minutes may take longer than normal to appear on the platform, and core API requests themselves are unaffected. On 10/7, a spending-limit processing error caused requests from some organizations to be wrongly denied across the Claude API, claude.ai, Claude Code, and Claude Cowork (resolved 21:23 UTC), alongside a separate usage-data loading error; a 10/6 spike in Opus 5.5 errors (resolved 12:43 UTC) was also resolved the same day.

**If the numbers on your Claude Console usage dashboard look out of date, it's most likely related to this degraded-performance incident — it doesn't affect your actual Claude Code work or API calls, so keep using it as normal.** [Claude Status](https://status.claude.com)

### DNS Hijacking Let Attackers Obtain Forged TLS Certificates for Google and Other Major Services (10/8)

**Attackers took control of three country-code top-level domains (.gh, .sl, .as), manipulated authoritative DNS records and nameserver delegation, passed automated domain-control validation, and obtained forged TLS certificates for domains belonging to Google and other major online services without authorization.** The systems of the affected domain owners themselves were not compromised, and Google has not disclosed the full scope of the impact.

**If you run your own domains, setting up Certificate Transparency log monitoring and restricting certificate issuance authority with CAA DNS records can block attackers from obtaining further certificates even if DNS delegation is hijacked this way.** [GeekNews](https://news.hada.io/topic?id=34955)

### Meta and Microsoft Are Scaling Back Internal Claude Use and Shifting to Their Own AI Tools (10/8)

**Microsoft has cut its projected $1B+ annual internal Anthropic spend by more than a third, is steering employees toward GitHub Copilot and OpenAI-based tools, and has slashed its per-employee monthly AI spending cap from mostly $100,000 down to roughly $10,000.** Meta's Claude Code user count has dropped from roughly 60,000 earlier this year to about 30,000 recently; layoffs played a part, but the bigger driver is migration to its own tools, MetaCode (30,000+ users) and Muse Code (6,000+ users). Both companies are driven by cost-cutting and a push to use their own products more, and both continue to offer Claude to their own customers.

**If you're pitching or consulting on Claude Code adoption to enterprise customers, it's worth explaining that internal-use pullback is a separate cost-control measure from external customer offerings, and worth keeping in mind that competition over internal standard tooling is heating up.** [GeekNews](https://news.hada.io/topic?id=34964)

## Minor Changes

All items below are from **v2.1.293** (10/7).

- **Added `agentType` to the `subagentStatusLine` payload**, letting scripts distinguish between custom subagent types.
- **Fixed path-scoping rules and nested CLAUDE.md files not loading when viewing a single file via the Bash tool with `cat`, `head`, `tail`, `sed -n`, or `grep`.** Viewing files this way instead of with the Read tool could silently skip CLAUDE.md instructions.
- **Fixed `claude purge` silently stopping (exit code 0) or hanging when it couldn't delete a file or folder** — it now deletes everything else, lists what it couldn't delete, and exits with code 1.
- **Reverted the v2.1.290 fix for "cloud sessions failing to wake after a container restart."** If a container restart causes a pending `/loop` wakeup or scheduled task to be missed, the session now silently stays asleep again instead of notifying Claude — the old behavior is back.
- **The claude.ai skill-sync check interval grew from 10 minutes to roughly 40 minutes while a session is idle.**
- **OpenTelemetry's `claude_code.at_mention` logging now caps at 100 agent events and 100 MCP resource events per prompt.**

## Interesting Projects & Tools

- **Show GN: Boxdawn — a tool that spots redundant multi-agent work from a single agent trace file (10/8)**: run multiple agents and agent A's file reads get repeated by B and C — each individual log looks fine on its own, but cost leaks out in between. It filters first on deterministic criteria like SHA256 equality, then optionally reviews at the semantic level via API, detecting five duplication patterns: repeat, context_resend, redundant_read, duplicate_creation, and semantic_duplicate. It supports traces from Claude Code, LlamaIndex, the OpenAI Agents SDK, and the Anthropic SDK, and you can either upload a file on the web with no login or run it via a local CLI. [GeekNews](https://news.hada.io/topic?id=34953)
- **Docker Agent — a Docker CLI plugin for defining and running AI agents from YAML config alone (10/8)**: build tool-based agents by combining built-in tools, MCP servers, and local or remote models without writing code, and it also supports multi-agent setups where several specialized agents collaborate and automatically delegate work to each other. It works with OpenAI, Anthropic, Gemini, AWS Bedrock, and local models, and agents you build can be pushed to an OCI registry and pulled down to run as-is in other environments. [GeekNews](https://news.hada.io/topic?id=34968)
