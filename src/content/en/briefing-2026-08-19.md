## New Features & Practical Usage

### Spellcheck arrives in prompt input (v2.1.235)

An opt-in **`spellcheck` setting** has been added that **underlines misspelled words as you type in the prompt input, using whichever of `aspell`, `hunspell`, or `ispell` is installed**.

**If you're in the habit of typing long prompts or CLAUDE.md drafts directly in the terminal, you can now catch typos on the spot without switching to a separate editor.** That said, **it only works if a spell checker is installed locally**, so it's worth confirming that `aspell`, `hunspell`, or `ispell` is present before turning it on. [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### Embedded grep no longer hangs on pathological patterns (v2.1.235)

**The `grep` built into native macOS and Linux builds now fails fast instead of exhausting memory when it hits a pathological regex pattern.** At the same time, **combining `-m N` with `-A` or `-C` now prints the correct number of context lines.**

**In practice**: if you've ever had a session freeze while running a complex regex against a large codebase, this fix should make that far less likely. **When you want to cap match counts while still seeing surrounding context (combinations like `-m 5 -C 3`), you can now trust the results are accurate.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Background cloud sessions use less memory and CPU (v2.1.235)

**Memory and CPU usage improved for long-running background cloud sessions like `/ultrareview` and `/autofix-pr`, since their event streams no longer get fully re-scanned and re-rendered on every update.**

**If you're in the habit of running several `/ultrareview` or `/autofix-pr` sessions in the background while working on something else, this improvement should noticeably ease the load on your local machine.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Context limit errors now explain the cause and the fix (v2.1.235)

**Context limit error messages now tell you when auto-compact is disabled, and point you to `/config` to turn it back on.**

**Previously, when a session suddenly hit its context limit, it was hard to tell whether auto-compact was off or whether the context genuinely filled up.** Now you can **identify the cause immediately and act on it directly from `/config`.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude Code's 50% weekly usage boost extended again through August 31 (8/19)

The 8/18 briefing had this counting down as **"expiring tomorrow (8/19) — D-1."** Instead of ending today, **the 50% weekly usage limit boost for Claude Code has been extended again, this time through August 31.** This marks **another extension of the temporary boost that's been running since July**, with a note that **the team hopes to make it permanent as part of the plan, but wants to watch model demand — which is currently surging — over the next few weeks before deciding.**

**If your team has been relying on the extra weekly headroom to batch large workloads, you can keep using the boosted limit through 8/31.** That said, **since this isn't the first extension, it's worth checking the announcement again around 8/31.** [GeekNews](https://news.hada.io/topic?id=32631)

### Permission prompt Shift+Tab bug — was granting session-wide edit permission instead of closing the field (v2.1.235)

A bug has been fixed where **pressing Shift+Tab inside a permission prompt's comment field approved the edit and granted session-scoped edit permission, instead of simply closing the field.**

**The intended action was just to close the comment input, but in practice it was quietly granting far broader permissions than expected** — **a clear example of how a single stray keystroke can expand a permission's scope well beyond what was intended.** Updating to v2.1.235 resolves the issue. [Full release notes](https://github.com/anthropics/claude-code/releases)

### Permission dialog wording now always matches the actual scope being granted (v2.1.235)

**The text shown in permission dialogs, along with the "don't ask again" option, has been updated to always match the scope that will actually be applied once approved.** Additionally, **the "don't ask again" option is no longer offered when the content can't be displayed in full.**

Following the **credential-masking hardening for permission previews and MCP diagnostics** covered in the 8/18 briefing, **this continues a pattern of hardening aimed at making sure permission approval screens accurately reflect what they're actually authorizing.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Claude incident — roughly 2 hours 12 minutes of multi-model performance degradation on the afternoon of 8/18 (Minor)

**A direct query of the official Claude Status (status.claude.com) API** turns up **one more confirmed incident**, following the **8/17 13:56-15:29 UTC incident** covered in the 8/18 briefing.

- **Incident**: Degraded performance for multiple models
- **Time**: **2026-08-18 16:20:22 UTC - 19:01:45 UTC (actual impact window 16:11-18:23 UTC, roughly 2 hours 12 minutes)**
- **Impact level**: **Minor**
- **Status**: Resolved

**All services are currently operational.** **As of the StatusGator check (2026-08-19 01:03 UTC), user reports over the past 24 hours stood at 13,492** — still elevated, though **most are already marked resolved.** **With Minor-level performance degradation now occurring two days in a row (8/17-8/18)**, if you're running Opus 5 or Sonnet 5 in production, **it's worth checking whether any requests processed during those windows were affected.** [Claude Status](https://status.claude.com/history) · [StatusGator](https://statusgator.com/services/claude)

### Reminder — weekly usage boost and Sonnet 5 launch pricing now both converge on D-12

**The 50% weekly usage boost for Claude Code now ends 8/31**, per the extension covered above, **and Sonnet 5's launch pricing was already set to end 8/31** — **the two dates are now both D-12.** Starting 9/1, Sonnet 5 pricing rises to $3 input / $15 output (+50%). See the 7/13 briefing for details.

## Minor Changes

All items below are from **v2.1.235**.

- Fixed **misaligned nested markdown list items at depth 3 or deeper**, and added hanging indent for wrapped list items in the terminal UI.
- Fixed **slash command, keyword, and mention highlighting appearing offset by a character or more in some multi-line prompts.**
- Fixed **general-purpose being suggested as a default even in sessions where the Agent tool isn't available** — omitting `subagent_type` now shows a clear error listing the available agents.
- Fixed **the notebook cell delete/replace confirmation dialog silently omitting the existing content when a cell couldn't be read** — the dialog now explains why.
- Fixed **slash commands run while Claude is responding displaying as HTML entities instead of the actual characters.**
- Fixed **the "Update installed" restart notice failing to appear in the prompt footer after a background auto-update.**
- Fixed **the expanded task list (ctrl+t) always starting collapsed when resuming or rerunning a session that still had open tasks.**
- Changed `SendMessage` to **reject messages that are too large for cross-session delivery upfront**, instead of silently dropping them.

[GeekNews](https://news.hada.io/topic?id=32627)

## Interesting Projects & Tools

- **VisiGrid — a local-native spreadsheet designed like a code editor (8/19)**: An **open-source spreadsheet that borrows the interaction model of a code editor rather than a traditional spreadsheet like Excel**, **built around the keyboard and a Command Palette instead of menus.** **It's built on GPUI, a GPU-accelerated UI framework, supports macOS, Windows, and Linux, and has a cold start of around 300ms.** Developers used to keyboard-driven workflows can carry the same feel over into spreadsheet work.
