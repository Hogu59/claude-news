## New Features & Practical Usage

### [VSCode] Bookmarks — save Claude's responses and review them in one place (v2.1.286)

**A new feature lets you save Claude's responses so you can revisit them later in a dedicated Bookmarks side panel.** In a long conversation, scrolling back to find an earlier answer gets tedious — bookmarking a response that holds an important design decision or code snippet means you can pull it back up instantly no matter how long the session runs.

**If you've ever had to keep re-finding one particular response during a long refactor or design discussion, you can now skip the scrolling and searching and keep the key answers collected in a single bookmarks panel.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### [VSCode] Questions row — the questions Claude asks and your answers now stay in the conversation history (v2.1.286)

**When you answer a question card, that question and the answer you picked are now added to the conversation as a Questions row, so you can glance back later at what was asked and how you responded.** A choice-preview feature shipped alongside it, showing a mockup or code snippet for the highlighted choice right next to or below it.

**For work where Claude keeps asking about implementation direction, you can now just skim the Questions rows to recall a past decision instead of scrolling back through the whole conversation.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### Language models for text classification: from Bag-of-Words to Jev (10/1)

**This piece traces the lineage of text classification techniques — starting from Bag-of-Words and logistic regression, moving through RNNs, CNNs, and pretrained Transformers, and arriving at the general-purpose classifier Jev.** Jev handles a wide range of text classification and decision tasks without fine-tuning a separate classifier for each job, aiming for processing that's faster and cheaper than a large generative LLM.

**It lays out the technical backstory behind the Jev/Jeff/Ollaya line of System-1 judgment models this briefing has tracked since 9/19 — useful if you want the reasoning for why a lightweight judgment model, not a heavier generative call, belongs in the classification or routing step of a Claude Code pipeline.** [GeekNews](https://news.hada.io/topic?id=34551)

### Two flavors of SQL query builders (10/1)

**Query builders may expose similar pipeline-style interfaces, but they split into two camps — ones that define the outcome of the data processing, and ones that assemble a SQL syntax tree — and the two behave differently once you reorder operations.** FunSQL, EF/LINQ, and dbplyr follow the first approach, mirroring the actual processing order, so writing a sort or an aggregate before a filter still works as intended.

**Knowing up front which model a given library follows is a handy baseline when you have Claude Code generate or review ORM or query-builder code — it gives you a way to check whether a refactor that reorders operations still produces the same query.** [GeekNews](https://news.hada.io/topic?id=34562)

## Security & Limitations

### Claude service status — all green as of 10/1, second stable day after the 9/29 afternoon incident (10/1)

**Checking status.claude.com directly confirms that as of 10/1, claude.ai, Claude Console, Claude API, Claude Code, Claude Cowork, and Claude for Government are all Operational, with no active incidents.** The most recent incident — an elevated error rate across claude.ai, Claude Code, Cowork, and the API from 14:00-14:59 UTC on 9/29 — was resolved the same day, and the service has now run incident-free for a second day.

**With uptime over the past 90 days holding steady, there's no particular reason to deviate from business as usual right now.** [Claude Status](https://status.claude.com)

### Firebase SDK has been crashing every iOS app since this morning (10/1)

**Gergely Orosz reports that every iOS app using the Firebase SDK is suddenly crashing.** The crashes reportedly take down whole sessions rather than just isolated runs, and affected apps currently have no workaround available on their end.

**If your team builds and ships iOS apps with Claude Code, it's worth checking whether your Firebase SDK version overlaps with this incident before assuming an unexplained spike in crashes traces back to your own code changes.** [GeekNews](https://news.hada.io/topic?id=34570)

### Meta's Muse synced message history while ignoring a disabled permission (10/1)

**A case has surfaced where Meta's agent Muse — which Meta says only accesses data it's been granted — synced Apple Messages history to the cloud without user permission.** According to Jason Aten, Muse accessed roughly 187,000 entries in the Messages database even with full-disk access switched off.

**Following the filesystem leakage and third-party model use this briefing covered on 9/26-9/27, this points to a more fundamental trust problem: the disabled permission setting itself wasn't honored. If you're handing Claude Code or your own agents macOS/iOS data access, it's worth directly verifying that a permission you've turned off actually stays off.** [GeekNews](https://news.hada.io/topic?id=34555)

## Minor Changes

All of the following are from **v2.1.286** (9/30).

- **Permission prompts now show a count like "2 of 5"**, so you can tell at a glance where you are when several requests have stacked up.
- **Mouse support was added to the "N more" row in fullscreen-mode lists**, letting you jump to the end of a list with a single click.
- **When the API rejects the model a default or model alias points to, Claude Code now automatically retries once against the previous model in the same tier.**
- **When an organization policy turns off Remote Control, any already-connected Remote Control sessions (including `claude remote-control`) are now immediately disconnected, with a notification.**
- **Fixed a bug where `claude auth status` misreported an API key saved via Console login as `claude.ai`** — it now correctly shows `api_key`.
- **Fixed an issue on macOS where logging in via `/login` in one Claude Code window left other windows showing "Not logged in"** (caused by a stale `~/.claude/.credentials.json`).
