# Claude Code Daily Briefing - 2026-11-05

**v2.1.318 shipped just one day after v2.1.317 (11/3).** Beyond small new features like advance warning of login expiration and effort control for mods, the release also bundles several stability fixes with real day-to-day impact — including a regression (introduced in 2.1.314) where `--continue` would lose the prior conversation once retries for a malformed tool call were exhausted, and a bug where Bash commands piling up on macOS would cause memory to balloon and the process to hang.

## New Features & Practical Usage

### FlashProve — Anthropic releases a research prototype for verifying inference without revealing model weights (11/5)

**Anthropic has open-sourced FlashProve, a research prototype that uses zkSNARK cryptographic proofs to verify that a given response actually came from a specific model — without ever disclosing its weights.** A model provider generates a short, one-time offline commitment that pins down the weights; from then on, for any given prompt-response pair, it can produce a proof that the model behind that commitment really produced that output, and anyone can verify the proof using just the commitment, prompt, response, and proof file — no GPU required. Proving Llama 4 Maverick, a roughly 400B-parameter MoE model, on a single H100 ran at 110 tokens per second, produced a proof file of about 18.78MB, and verification across 24 threads took around 17 seconds; the four safety properties — completeness, soundness, zero-knowledge, and succinctness — were formally verified in Lean.

**It's still early-stage research — only integer model versions and greedy decoding are provable for now, and context is capped at 1,024 tokens — but if you run model routing or evaluation pipelines and ever need to prove to an outside party which model actually generated a response, this is a direction worth tracking.** [GeekNews](https://news.hada.io/topic?id=36617)

### Login expiration now shows up in claude auth status and claude -p JSON, with warnings starting 10 days out (v2.1.318)

**You can now see when a stored claude.ai login will expire via the `loginExpiresAt` field in `claude auth status` and the `credential_expires_at` field in `claude -p` JSON output.** Starting 10 days before expiration, `claude -p` text output also prints a one-line stderr warning alongside the regular response.

```bash
# Check login expiration from the terminal
claude auth status

# Pull just the credential expiration time out of claude -p JSON output
claude -p "ping" --output-format json | jq -r '.credential_expires_at'
```

**If you run automation that calls `claude -p` non-interactively via CI or cron, this field — or the stderr warning — lets you catch an expiring login and schedule re-authentication before your pipeline grinds to a halt.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### mod's `$.model.fork` can now target a specific effort level, so side tasks stay cheap (v2.1.318)

**Calls to `$.model.fork` in mod code can now pass an `effort` option, so even when an entire session is running at `xhigh` or `ultrathink`, lightweight side tasks like summarizing or classifying can be forked off at `low` effort instead.** The result includes the effort level actually applied, so you can confirm at a glance what effort a given fork ran at, regardless of the session's overall setting.

```js
// Example mod code: run a lightweight side task at low effort regardless of session effort
const result = await $.model.fork({
  prompt: "Summarize this commit message in one line",
  effort: "low",
});
```

**If you've set a high session effort for a complex task but felt wasteful about a mod burning the same effort on trivial helper calls underneath it, this option is worth wiring into any mods you maintain.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Background subagent shell commands now auto-switch to background after 3 minutes, protecting prompt cache (v2.1.318)

**When a background subagent's shell command runs past 3 minutes, it now gets automatically moved to the background across all providers, so the prompt cache doesn't expire while it runs.** Previously, a subagent holding a long build or test command in the foreground could let the prompt cache lapse in the meantime, forcing a more expensive reprocess once it returned.

**If you regularly hand off long-running builds or tests to subagents, v2.1.318 means commands running past 3 minutes now get their prompt cache protected automatically — no need to background them yourself.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### git commit and PR creation are now more reliable under macOS's default `/bin/bash` (v2.1.318)

**Reliability has improved for git commit and pull request creation when the Bash tool runs via macOS's built-in `/bin/bash`.** Even on macOS systems where zsh is the default shell, Claude Code's Bash tool itself uses `/bin/bash`, and that combination had occasionally produced flaky or failed commits and PR creation.

**If you've automated commits or PR creation with Claude Code on macOS and hit hard-to-diagnose failures now and then, it's worth updating to v2.1.318 to see if this has been resolved.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude service status — no incidents from 10/29 through 11/4, everything operational

**A direct check of the official status.claude.com shows "No incidents reported" every day from 10/29 through 11/4, and as of 11/5 claude.ai, the Claude API, Claude Code, Claude Console, Claude Cowork, and Claude for Government are all listed as "All Systems Operational."** The most recent incident was a Google Calendar/Gmail connector error, resolved on 10/28.

**If you ran into service issues in the past few days, they've already been resolved — so if something goes wrong today, it's more likely worth checking your local setup or network first.** [Claude Status](https://status.claude.com)

### `deniedMcpServers` now also blocks Anthropic-provided servers and connectors that match by URL (v2.1.318)

**When you register a URL in `deniedMcpServers`, the block now also covers any Anthropic-provided server whose upstream matches that URL, and connectors on cloud sessions and self-hosted runners can be blocked the same way whenever the session is given that connector's dedicated URL.** Other connectors still need to be blocked by name. Previously, URL-based blocklists didn't apply to servers or connectors provided directly by Anthropic, leaving a potential gap where an organization's upstream block could be bypassed through an Anthropic-provided path.

**If your organization uses `deniedMcpServers` to restrict access to specific MCP servers, it's worth factoring into your policy review that URL-based blocking now extends to Anthropic-provided servers and connectors as of v2.1.318.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Ecosystem & Plugins

### Show GN: AI Office — a desktop app that puts Claude Code and Codex to work as "employees," built for non-developers (11/4)

**Built on the premise that terminal jargon like commit or permission allow keeps non-developers from using these tools, this desktop app wraps Claude Code and Codex in an "AI office" metaphor, letting you hire employees and hand them tasks instead.** File changes and commands don't run until you approve them from an inbox, and every action can be undone in one step; you can also pair with an AI Office instance on another computer using a 12-digit code to hand work to a remote "employee" and get back just the changes, as approval cards.

**If you've wanted to give a non-developer colleague the power of Claude Code or Codex but the terminal itself was the barrier, this app's built-in preview-before-approve and undo make it worth considering for safe delegation.** [GeekNews](https://news.hada.io/topic?id=36570)

### Show GN: korea-finance-factcheck — an MCP server that checks AI-written financial content against DART and Bank of Korea data (11/3)

**Built by someone who co-wrote financial disclosure posts with AI and later discovered errors like swapped merger exchange ratios or earnings inflated 10 to 100 times over, this MCP server cross-checks a draft's M&A exchange ratios, revenue, and operating income against DART filings, and checks bond yields, KOSPI closing prices, base rates, and exchange rates against the Bank of Korea's ECOS API and U.S. Treasury data.** It attaches directly to Claude Code via `uvx korea-finance-factcheck`, and only verifies numbers — it doesn't offer investment advice.

**If your workflow involves writing or reviewing financial or disclosure-related content with Claude Code, this MCP server is worth adding as a second check against the kind of errors that slip through when you polish the prose but trust the numbers as-is.** [GeekNews](https://news.hada.io/topic?id=36523)

## Minor Changes

All of the following are from **v2.1.318** (11/4).

- **Fixed an issue where requests with more than 20 images always reported the "image too large" error as a flat 2000px limit**; it now shows the actual limit returned by the API.
- **Fixed the "Now using usage credits" notification repeating roughly every 30 seconds** while a background subagent was running.
- **Fixed duplicate notifications firing when Claude's PushNotification call omitted the status field.**
- **Claude Code launched from within an IDE terminal no longer installs or updates the IDE extension.** Use `/ide` from an external terminal or the editor's extensions view instead.
- **When Claude Code asks whether to enable a mod created during a session, your answer is now recorded in the session history.**
- **Fixed non-interactive runs silently overwriting a malformed `~/.claude.json` with defaults**; startup now fails with guidance on how to recover instead (anthropics/claude-code#87551).
- **Fixed `claude plugin validate` accepting marketplace files with custom names that `claude plugin marketplace add` would actually reject.**

## Interesting Projects & Tools

- **Show GN: Krill — a Rust desktop app that runs terminal coding agents like Claude Code and Codex in parallel across git worktrees (11/4)**: Each task gets its own worktree so agents never collide on file changes, with a dashboard that shows at a glance which agents are waiting on input and a diff review panel that pops up right next to the terminal. The UI is decoupled from a daemon process that keeps sessions alive, so closing the app and reopening it reconnects you to the same terminal sessions as long as the daemon is still running. [GeekNews](https://news.hada.io/topic?id=36527)
- **Show GN: claude-account-rotator — a macOS CLI that automatically switches between Claude accounts before you hit usage limits (11/4)**: It reads each account's 5-hour and weekly usage, and once a limit is close — even mid-task — it runs `/exit` and then `claude --resume` under a different account to keep the conversation going. It also watches session logs for 429 responses, excluding any account that's hit its limit until it recovers, and `rotator status --watch` gives you a live dashboard of remaining usage per account. [GeekNews](https://news.hada.io/topic?id=36557)
