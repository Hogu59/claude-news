## New Features & Practical Usage

### `/skill-doctor` — surfaces unused skills and their context cost (v2.1.261)

**A new `/skill-doctor` command shows which loaded skills are actually going unused, along with how much context each one is costing.** **You can use this to prune skills you don't need.**

```bash
/skill-doctor
# Shows loaded skills, each one's context usage, and whether it's actually being invoked
```

**When you accumulate plugins and skills over time, it's easy for skills you never actually call to quietly eat into your context on every turn. `/skill-doctor` lets you find and remove those, freeing up both context headroom and prompt-cache efficiency.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `bashOutputMaxChars`/`taskOutputMaxChars` — receive command and background task output inline up to 128K characters (v2.1.261)

**Previously, output from command execution and background tasks that exceeded a certain length would get written to a file, with only a summary passed inline. New `bashOutputMaxChars`/`taskOutputMaxChars` settings let you raise that inline limit yourself, up to 128K characters.**

```json
// settings.json
{
  "bashOutputMaxChars": 131072,
  "taskOutputMaxChars": 131072
}
```

**If you want to analyze long build logs or test output directly instead of being routed through a file, these settings let you raise the inline limit as high as you need.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### `--append-subagent-system-prompt-file` — pass long subagent prompts without hitting command-line length limits (v2.1.261)

**Until now, appending content to a subagent's system prompt meant passing it as a command-line argument, which made it easy to hit the shell's argument length limit. A new `--append-subagent-system-prompt-file` option reads the content from a file instead.**

```bash
claude --append-subagent-system-prompt-file ./prompts/reviewer-guidelines.md
```

**If you want to attach a large document, like your team's code review standards or architecture guidelines, to a subagent in full, you can now manage it as a separate file and pass it in without worrying about command-line argument limits.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### How is MCP actually being used in production? — an Ask HN thread rounds up the answers (9/4)

**In response to a question about why MCP generated so much buzz at launch yet real production use cases are hard to come by, practitioners shared what they're actually doing.** **The consensus: MCP is being used for internal ops diagnostics, SaaS integrations, voice agents, and customer-facing chatbots, mainly because it cuts down on tool-discovery and integration overhead compared to wiring up plain APIs or CLIs directly.**

**If you're designing a new MCP server for Claude Code, this is worth reading as evidence that narrowing your tool scope to a specific operational or customer-facing scenario tends to work better in practice than building a general-purpose API wrapper.** [GeekNews](https://news.hada.io/topic?id=33224)

## Minor Changes

All items below are from **v2.1.261** (9/4).

- **`/status` and `claude doctor` now show an "Organization policy" line explaining why an organization policy failed to load** — for example, when a proxy isn't passing an endpoint through.
- **The dangerous `rm -rf` safety prompt now also catches `rm -rf` on positional parameters and `rm -rf` inside double-quoted `sh -c` scripts.**
- **When the API sends no response headers at all, the retry wait time now extends up to `API_TIMEOUT_MS` (10 minutes by default) instead of capping at 3 minutes**, with a message explaining what to change.
- **Word-based editing shortcuts in the prompt input now match Bash's behavior.** Ctrl+W deletes through whitespace, Alt+F/Alt+D stop at word boundaries and treat punctuation as a word boundary, and the `keybindingFlavor` setting no longer has any effect.
- [VSCode] **The MCP server dialog now has a form for adding servers and a way to remove them**, so you can add or delete MCP servers without leaving the IDE.
- [VSCode] **Permission and question prompts now have a collapse button**, so you can scroll back through the conversation behind a prompt without dismissing it.
