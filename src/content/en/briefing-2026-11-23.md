## Developer Workflow Tips

### Code Mode scripts calling tools thousands of times barely freeze the terminal anymore (v2.1.330)

**Until now, when a Code Mode script called tools thousands of times, the terminal would freeze for a while — starting with this release, that freeze time has been cut dramatically.** Claude also got better guidance on how to look at images and PDFs from within Code Mode, and commands interrupted with Esc now show "Interrupted" instead of a red error.

```text
A bulk operation where a Code Mode script loops over hundreds or thousands of files, repeatedly calling tools
  (e.g., batch refactoring, large-scale API checks)
  → terminal freezing cut dramatically as of v2.1.330
```

**If running a script that loops over a large batch of files in Code Mode used to lock up your terminal for a while, upgrading to v2.1.330 should make the same workflow feel noticeably smoother.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `/ultrareview` now shows remaining monthly spend limits on Team and Enterprise plans (v2.1.330)

**Until now, `/ultrareview`'s cost-confirmation screen only showed the estimated cost of that one review, so you had to check separately how much room was left in your team's monthly spend limit — starting with this release, Team and Enterprise plans will also show the remaining monthly spend limit whenever it's lower than the cost of that single review.**

```bash
/ultrareview
# → The confirmation screen now shows not just "estimated cost for this review"
#    but also the remaining monthly spend limit, when that limit is lower
```

**If you've been running `/ultrareview` often across a team and separately checking each time whether you'd blow through the monthly spend limit, as of v2.1.330 the confirmation screen alone should give you the answer.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `claude --teleport` now just shows the git command instead of auto-switching branches in some setups (v2.1.330)

**Until now, in some configurations `claude --teleport` would automatically switch to the branch of the selected session — starting with this release, it only displays the git command that would switch the branch, leaving you to run the switch yourself.** In `-p` mode, it returns exit code 1 until the branch is switched.

```bash
claude --teleport
# → Only displays the branch-switching git command (run it yourself)
claude -p --teleport ...
# → Returns exit code 1 until the branch is switched
```

**If you had `--teleport` wired into an automation script to handle branch switching for you, keep in mind that after upgrading to v2.1.330, you'll need to add the git command execution step directly into the script for it to keep working the same way.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Canary tokens planted in two million AI prompts exposed leaks across the AI supply chain (11/23)

**Dragos chief research officer HD Moore ran an experiment planting a unique tracking secret — an AWS key tied to an empty account, SSH or other service passwords, a unique URL/DNS name, or a private git repository reference — into each of roughly two million AI prompts, to track at what stage they leaked.** The results pointed to compromise at at least three AI hosting providers, with attackers testing stolen keys within hours and digging through S3 and Secrets Manager to find additional credentials. One Chinese AI lab actually accessed more than half of the secret URLs sent in requests from July through October — including about two-thirds of requests marked "zero data retention" (ZDR) — and some resellers advertising lower prices turned out to have quietly enabled request logging. The experiment also flagged that AI routers like OpenRouter decrypt prompts to plaintext at every relay, meaning multiple parties can see the contents along the way. Anthropic and Claude weren't named as compromised in this experiment, but it's a concrete, measured demonstration that ZDR and no-retention settings aren't always actually honored in practice.

**If you're sending requests to Claude or any other model through a reseller or AI router rather than using an API key directly, this is worth citing as evidence that it's safer to confirm who's actually processing your requests than to trust a "no data collection" label alone.** [Ars Technica](https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/) · [GeekNews](https://news.hada.io/topic?id=37675)

## Community News

- **A Claude artifact tracking progress on formalizing Alessandro Masullo's Riemann Hypothesis proof manuscript in Lean went public (11/23)**: on top of the roughly 900-page, purely human-written proof draft covered in the 11/20-11/21 briefings, separate contributors are now working through Lean's proof assistant to fill gaps and catch errors, and showing that progress on a Claude-built dashboard (artifact). Hundreds of gaps and flaws have turned up in the published manuscript, some cutting across core arguments badly enough that one view holds they can't be fixed with a simple erratum, and others note that since the progress denominator is just the number of logged issues, it's hard to gauge how much work actually remains. Comments split between worrying that even a passing Lean compile can't guarantee the translated statement still matches the original proposition, and welcoming the fact that this kind of verification work is happening publicly, outside a major research lab. [GeekNews](https://news.hada.io/topic?id=37678)
- **New statistics show that Postgres databases created and discarded by AI agents have become mainstream across the industry (11/23)**: Databricks reported that as of May 2025, over 80% of Neon databases were created by AI agents, up sharply from 0.1% two years earlier; Supabase said about 70% of the more than four million new databases created every month now come from agents or AI tools; and Replit alone reportedly spins up 50,000-70,000 Neon databases a day. In response, lightweight, near-disposable databases are spreading — like PGlite, a sub-3MB Postgres that runs serverlessly inside a browser or agent sandbox, and Cloudflare D1 — but the analysis notes that safely cloning realistic operational data for agents while masking personal information remains an unsolved problem. If you're repeatedly spinning up and tearing down a database for every single feature with an agent like Claude Code, this is worth citing as evidence that the pattern isn't a passing fad — it's already mainstream across the industry. [GeekNews](https://news.hada.io/topic?id=37687)

## Recommended Reads

- **HUMAN.md — a manifesto on the attitude creators should hold in the AI era (11/23)**: it argues that the average is a floor, not a ceiling, and that you should learn the rules a model has been trained on before deliberately breaking them. It offers concrete creative habits — like making 50 ideas, throwing away 47, and only talking about the 3 that worked, rather than presenting one finished opinion — and stresses that the creator is still whoever chooses and takes responsibility for the result, not whoever just typed a single prompt. Comments complained a lot about scroll-triggered animation making the page stutter on mobile and about the 47MB page being slow, and someone also pointed out that the AI-detection tool Pangram flagged the piece itself as AI-written, which fed into a broader reaction not to over-trust detection tools. [GeekNews](https://news.hada.io/topic?id=37683)
- **Performance is a design decision (11/23)**: the piece argues that even now that a single prompt can build an entire website, visitors are the ones who pay the wait time for a slow page, so every design element you add — autoplaying video, custom fonts, carousels — deserves a conscious cost judgment. It cites a case where simply removing lazy-loading from an above-the-fold image and shrinking its size cut LCP, under a throttled mobile profile, from 2,544ms to 1,320ms, and suggests leaving your measurement baseline and performance budget somewhere the next task can reference, the same way a skill file would. It's a useful reminder that when you hand a site off to an AI agent, performance requirements — like where the HTML actually gets generated or whether cache headers are set correctly — are easy to skip past simply because the prompt never spelled them out. [GeekNews](https://news.hada.io/topic?id=37677)
- **We're all juniors now (11/23)**: the piece argues that AI's real value isn't making existing work faster, but redefining what a company can even do in the first place, and that as recent knowledge starts to matter more than years of accumulated experience, the line between junior and senior is itself blurring. Using the model as the brain and a harness like Claude Code as the hands and feet, it notes that while agents handle the mechanics of a system, people end up focused on working with other people — and that empathy and a willingness to keep learning end up being what actually makes the difference. If you're rolling Claude Code or an in-house agent out across multiple roles, it's worth considering which skills that shift will ultimately make more important. [GeekNews](https://news.hada.io/topic?id=37680)

## Interesting Projects & Tools

- **Agent Office — a viewer that shows Claude Code subagents as a pixel-art office (11/22)**: built around the problem that when you run several subagents at once, the terminal alone makes it hard to tell which agent is doing what, or where one got stuck. It casts the main agent as the boss and subagents as employees, showing Edit/Write as typing and Bash as a terminal on a monitor; a failed tool call pops up an "OOPS" speech bubble, and three failures in a row sends smoke up from the monitor. A git commit triggers confetti, a passing test gets a round of applause across the whole office, context compaction shows up as a robot vacuum, and hitting a usage limit turns off the office lights. You can answer permission prompts right from the screen, commands running past five minutes get a speech bubble, and since it works by having Claude Code hooks send data to a local server that pushes updates over SSE, it never stores file contents or command output — only tool names, task names, and the first line of a report. Install it with `npx pixel-agent-office`. [GitHub](https://github.com/donasman/pixel-agent-office) · [GeekNews](https://news.hada.io/topic?id=37633)
- **Fast-Anything — a coding-agent tool that finds just the slow 5% of an app and ports that to Rust instead of the whole thing (11/23)**: it profiles functions, ranks them by execution time and how hard they'd be to port, then picks out functions that only handle deterministic, generic data, records 500 real calls to them, and hands a coding agent an isolated Rust crate plus a TASK.md. The ported Rust code gets verified by replaying both the recorded calls and derived edge-case inputs — NaN, infinity, empty input — checking that output matches the original; only changes that pass get switched on, and turning it off restores the original bytes exactly. The published examples report Python string deduplication dropping from 4.91 seconds to 42ms and PHP from 2.94 seconds to 53ms, though comments pushed back that rewriting in pretty much any language tends to get faster on its own, and that the real bottleneck is more often a DB transaction or network call. It works with any command that takes a prompt over stdin, like `claude` or `codex`, and is also available as a Claude Code plugin and an MCP server with 8 tools. [GitHub](https://github.com/EL4CTEO/fast-anything) · [GeekNews](https://news.hada.io/topic?id=37645)
