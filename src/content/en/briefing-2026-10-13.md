## New Features & Practical Usage

### `$.ui.notify` lets mods ring a user's own notification channels directly (v2.1.295)

**A new API for mod (plugin) developers, `$.ui.notify`, lets mod code fire native notifications straight through whatever channels the user has already configured.** The call also returns which channel actually delivered the notification, so mods juggling multiple notification paths can confirm delivery.

```js
// Send a notification through the user's default channel from mod code
await $.ui.notify({ title: 'Build complete', body: '142 tests passed' })
```

**If you're building a mod that alerts users when a long background job finishes, `$.ui.notify` lets you reuse whatever notification path the user already set up instead of bolting on a separate OS notification library.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `claude plugin validate` now hands you ready-to-paste install instructions when your README is missing them (v2.1.295)

**If a plugin's README has no line explaining how to install it, `claude plugin validate` now prints ready-to-paste install instructions.** Turning on `--strict` doesn't turn this advice into a failing exit code, so it flags the gap without blocking the release itself.

**If you're prepping a README for the plugin marketplace, run `claude plugin validate` once before publishing to check that install instructions haven't been left out.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### AI coding agents produce more code, but not more company-wide software output (10/13)

**A study analyzing development activity across more than 700 companies found that lines of code generated rose by an average of 30% after adopting AI coding agents, but that barely translated into more completed work as tracked in systems like Jira.** More code doesn't guarantee more software output — judging productivity purely by how much code an agent produces is an easy way to fool yourself.

**If your team is measuring Claude Code's impact by lines generated or commit counts, swap those numbers for actual completed, shipped units of work — merged PRs, resolved tickets — so you can judge without distortion whether adopting the agent really moved output.** [GeekNews](https://news.hada.io/topic?id=35257)

### `claude self-hosted-runner` now explains exactly why registration was rejected (v2.1.296)

**When self-hosted runner registration gets rejected, `claude self-hosted-runner` no longer just prints a vague error — it now names the specific organization admin setting that caused the rejection, or tells you a new job assignment is needed if the on-demand runner was restarted.**

**If you're running Claude Code sessions on self-hosted runners in-house, check the clearer error message introduced in this update before digging through logs when registration fails — it'll save you diagnosis time.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude service status — Claude Console degraded for a sixth straight day, everything else normal (10/13)

**Checking status.claude.com directly, as of 10/13 claude.ai, the Claude API, Claude Code, Claude Cowork, and Claude for Government are all Operational, but Claude Console (platform.claude.com) has been in Degraded Performance for six straight days due to a usage-data loading delay that started on 10/7.** No new incidents have been reported since a spend-limit processing error (resolved 21:23 UTC) and a usage-data load error (resolved 02:33 UTC), both on 10/7, and core functionality is still reported as unaffected.

**If the numbers on your Claude Console usage dashboard still look stale, it's this six-day-old degradation at work — your own Claude Code work and API calls aren't affected, so keep using them as normal.** [Claude Status](https://status.claude.com)

### Zod 4.6.6 was found shipping code that downloads and runs external code (10/12)

**The widely used TypeScript schema validation library Zod was found to have added a `meta.test.mjs` file, identical across the `zod` and `@zod/mini` packages, in the commit that bumped the version from 4.6.5 to 4.6.6 — a file that downloads and executes external code.** The code reportedly reads a list of domains from an Ethereum RPC response and pulls further code from each one, and the community is actively investigating it as a suspected supply-chain attack.

**If your project depends on zod or @zod/mini, check package.json and your lockfile right away for an installed version of 4.6.6, and if you find one, pin to an earlier version until an official advisory and patched release are out.** [GeekNews](https://news.hada.io/topic?id=35238)

### A $90,000 remote code execution bug on a Google documentation platform has been disclosed (10/13)

**A vulnerability was found on DevSite, Google's shared documentation platform, where the key used to sign the session cookie was stored inside that same cookie — letting anyone forge a session without logging in.** The root cause was that an OAuth client_secret embedded in the cookie was also reused as Flask's SECRET_KEY, and the write-up details how that was chained all the way to remote code execution.

**If you're using Flask or a similar framework for session management, this is a good prompt to check whether you're reusing an OAuth client secret or any other secret for a different purpose as your session-signing key.** [GeekNews](https://news.hada.io/topic?id=35260)

## Ecosystem & Plugins

### Research firm warns against Anthropic's $2 trillion IPO valuation target (10/12)

**Financial research firm New Constructs warned that Anthropic's reported IPO valuation target of $2 trillion could be the most absurd listing of the year.** Its own estimate puts Anthropic's value at just $150 billion, arguing that justifying the target valuation would require earnings double Nvidia's trailing-year profit.

**If you're tracking Anthropic's fundraising or valuation trajectory, it's worth watching how this kind of critical research ends up affecting the actual IPO timeline or terms.** [GeekNews](https://news.hada.io/topic?id=35243)

### Codex CLI draws controversy for installing a persistent background daemon without consent (10/13)

**Users report that OpenAI's Codex CLI 0.157.0 installs a self-updating daemon by default the first time you open an interactive session — one that keeps running even after every terminal window is closed.** Critics point out that the installed platform package weighs in at roughly 374MB with no explicit consent step, and requests have gone out asking that `daemon_auto_start` be switched to an opt-in model.

**If you're evaluating Codex CLI alongside or instead of Claude Code, know going in that the default install leaves a background daemon running persistently without asking — turn off `daemon_auto_start` yourself if you'd rather it didn't.** [GeekNews](https://news.hada.io/topic?id=35256)

## Minor Changes

Everything below is from **v2.1.296** (10/9) and hasn't been covered in this week's briefings yet.

- **The default character limit for MCP tool descriptions and server instructions loaded into the prompt upfront rose from 2,048 to 4,096 characters.** (This is separate from the limit on descriptions fetched later via ToolSearch.)
- **In fullscreen mode, links under the mouse pointer now get underlined**, so you can tell at a glance whether a link is clickable.
- **The transcript toggle (ctrl+o) now caches syntax-highlighted code blocks in code-heavy conversations**, making it open much faster.
- **Turns or `!` commands started while backgrounding a session with ← now get interrupted instead of running to completion off-screen.**
- **[VS Code] Fixed a bug where the working-status indicator kept animating even with the OS's or VS Code's "reduce motion" setting turned on.**
- **[Claude Tag] Fixed color swatches being rendered next to numbers that merely resemble hex color codes, like 6-digit PR numbers, in Slack replies.**
- **[Cloud sessions] A status filter was added to the Sessions and Runners lists on the Activity tab for self-hosted environments**, so you can filter by multiple statuses at once.
