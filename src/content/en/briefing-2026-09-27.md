## New Features & Practical Usage

### `load_test_mode` — load-test deployments without hitting the real upstream (v2.1.283)

**An opt-in `load_test_mode` block has been added to self-hosted Claude app gateway configuration.** **With it enabled, requests are built and signed normally but never actually reach the upstream — the client instead gets back a predetermined response.**

```json
{
  "load_test_mode": {
    "enabled": true
  }
}
```

**This lets you load-test an entire gateway deployment without incurring real API costs or upstream load, which is useful for teams who want to validate expected traffic volume before rolling out a new deployment.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Claude Tag "Channels Claude can search" — restricts Slack search to public channels (v2.1.283)

**A new admin setting lets organization admins limit Claude's Slack search scope to only the public channels Claude has been added to.** **It can be configured at the organization, workspace, or channel level.**

**If your organization uses Claude Tag in Slack and has been worried about Claude pulling answers from sensitive private channel content, this setting lets you narrow its search scope down to public channels.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### Plan mode is dead — the better models get, the less upfront planning docs matter (9/26)

**As models get better at exploring repositories and making reasonable assumptions on their own, the need for a Plan mode where humans spell out implementation details in advance is diminishing, this piece argues.** **Thinking through an approach before implementation is still valuable, but the core point is that writing that thinking down into an exhaustive planning document doesn't necessarily deepen understanding.**

**If you've been spending time turning every Claude Code Plan-mode session into a detailed document, it may be worth rethinking your workflow to focus less on the length of the plan and more on verifying judgment during execution.** [GeekNews](https://news.hada.io/topic?id=34304)

### How to keep enjoying programming in the LLM era (9/27)

**This piece suggests you can pursue both the enjoyment of programming and a reasonable productivity boost by writing the code yourself and leaving only peripheral work — like organizing plans, research, and review — to the LLM.** **The core argument is that to retain understanding of and control over your codebase, you need to keep writing code yourself instead of handing all implementation over to an agent.**

**Rather than handing Claude Code the entire implementation, deliberately drawing a line where you delegate only peripheral work — research, planning, review — while writing the core code yourself can help you hold onto both enjoyment and productivity.** [GeekNews](https://news.hada.io/topic?id=34336)

## Security & Limitations

### Claude service status — all systems operational as of 9/27, five days of stable operation (9/27)

**A direct check of the official status.claude.com shows that as of 9/27, claude.ai, Claude Console, Claude API, Claude Code, Claude Cowork, and Claude for Government are all Operational, with no active incidents.** **Since the most recent incident — the elevated multi-model error rate on 9/22 — was resolved, the service has now run five straight days without incident.**

**With all systems having stayed operational over the past 90 days, this is a good point to stick with the normal path without any extra action.** [Claude Status](https://status.claude.com)

### A drive-root deletion vulnerability in the Windows PowerShell tool has been closed (v2.1.283)

**Fixed an issue where the PowerShell tool could delete locations — like drive roots or home folders — that `Remove-Item` would have refused, by going through `cmd /c rd`, `rmdir`, `del`, or `erase` instead.**

**Teams that have granted Claude Code broad automation permissions on Windows should update to the latest version, since this fix narrows the blast radius of cmd-based delete commands down to the same level as `Remove-Item`.** [Full release notes](https://github.com/anthropics/claude-code/releases)
