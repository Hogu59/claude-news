## New Features & Practical Usage

### `ANTHROPIC_DEFAULT_MODEL` — set the starting model for new sessions (v2.1.236)

You can now **set which model a new session starts with via an environment variable**. **If you pick a model directly with `/model`, that choice takes precedence and persists across restarts** — unlike the existing `ANTHROPIC_MODEL`, which had to be reapplied every session.

```bash
# Set the default starting model for new sessions
export ANTHROPIC_DEFAULT_MODEL=claude-opus-5
```

Useful for **organizations that want every session to start on the same model team-wide, while still respecting an individual's `/model` override when they need one**. [Full release notes](https://github.com/anthropics/claude-code/releases)

### Get notified when another session goes idle — `SendMessage`'s `notify_when_idle` (v2.1.236)

You can now **ask another Claude Code session running on the same machine to send you a one-time notification the next moment it goes idle**. It's **opt-in, fires once, and works without polling** (macOS and Linux).

Handy if you're **running several sessions in parallel, working on something else, and just want to know the instant a particular one wraps up**. [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### `/goal` check-ins now escalate through 30-minute, 1-hour, and 2-hour stages (v2.1.236)

The feature covered in the 8/18 briefing — **"`/goal` checks in if a background task hasn't finished after 30 minutes"** — has been **expanded into a staged structure: if the task is still pending after that first check-in, `/goal` checks in again at the 1-hour and 2-hour marks.** When a goal is left idle behind a long-running background task, it now re-checks the situation on its own instead of waiting indefinitely for a human to come back.

The **loop-engineering column** covered in the 8/16 briefing argued that **completion criteria — and which decisions stay with a human — need to be defined up front**; this release refines that idea one step further, turning it from **a single check-in into a schedule of check-ins with widening intervals.** If you rely on `/goal` for CI or long-running pipelines, **a task that misses its 30-minute window now sits unattended for at most 2 hours before someone is pinged.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Auto mode gets sharper in three places (v2.1.236)

- **`Monitor` permission rules are now reviewed the same way as Bash commands** — while auto mode is on, `Monitor` commands no longer get a pass; they're scrutinized just like everything else.
- **On Bedrock, Vertex AI, and Foundry, and in environments with telemetry disabled, the classifier now uses the same defaults as the Claude API** (including severity-score-based classification) — closing a gap where auto mode's judgment used to vary by deployment method.
- **Auto mode no longer falls for the trick of making `git status` look clean via `status.showUntrackedFiles=no`.**

**If you're running auto mode across multiple clouds or deployment types at once, this narrows the gaps where approval criteria used to differ by environment.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### How software teams actually use AI — a look at Linear's usage data (8/19)

An analysis of product development activity among Linear's paying customers found that **AI feature usage roughly doubled across every role in H1 2026, spreading regardless of company size**. The key finding: **AI has settled in as something layered on top of existing work rather than something that replaces it** — **time spent writing, triaging, and commenting on issues generally went up, while planning time stayed about the same**.

**In practice**, this suggests that adopting Claude Code is more likely to show up as **"handling more issues, comments, and output in the same amount of time" than as "less work overall."** When reading team productivity metrics, **watching for increased throughput rather than reduced work time** is likely to capture the real change more accurately. ## Security & Limitations

### macOS sandbox wildcard read-block rules get stronger (v2.1.236)

**On macOS, wildcard read-block rules like `**/.env` now take priority even within otherwise allowed read areas.** Such a rule now **covers all content under any matched directory**, and **can no longer be bypassed by renaming the blocked file.**

**If you have a macOS sandbox configuration that blocks reads of sensitive files like `.env` via a wildcard pattern, this hardening closes both the subdirectory bypass and the rename bypass.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Claude incident — roughly 1.5-hour Minor degradation to Opus 5 and Haiku 4.5 on the morning of 8/19; report volume back to normal

- **Time**: **2026-08-19, 09:42:37–11:02:18 UTC (about 1 hour 20 minutes)**
- **Impact**: **Minor**

**As of 8/20, there are no new incidents and all services are operational.** The more notable shift is in **StatusGator's report count** — after holding in the five-figure range (12,938–13,492) for five straight days from 8/15 to 8/19, **the trailing 24-hour report count plunged to just 18** as of this check (2026-08-19, 23:58 UTC). **User-reported issues, which had stayed elevated ever since the authentication outage on the evening of 8/16, have returned to a normal baseline for the first time.** [Claude Status](https://status.claude.com/history) · [StatusGator](https://statusgator.com/services/claude)

## Minor Changes

All of the following are from **v2.1.236**.

- **The `/model` picker now highlights only the newest models by name** — pointing you straight at what's new instead of some arbitrary partial list.
- **`/usage` now shows usage-credit spending rows for Team/Enterprise members**, displaying rows at 0% before any spend occurs.
- **Receiving SIGTERM in print/SDK mode no longer logs a spurious interrupted turn or fake tool rejection** — any in-flight command is simply terminated and the process exits with code 143.
- **Hitting Enter on a mistyped slash command, or one unavailable in the current session, now shows an error instead of running the closest match** — prefixes and aliases still work as before.
- **Remote Control now marks a session offline within seconds of the CLI exiting or its terminal closing.**
- **`SendMessage` now rejects messages upfront when they'd arrive too fast for a session's inbox to keep up**, instead of reporting them as sent and silently dropping them.
- **The session title chip on the prompt border is now aligned with the right edge of the footer**, and **right-aligned footer items (goal indicator, session status, background agent status) now share a consistent right margin.**
- **[VS Code] Screen reader support has been added to the transcript** — live announcements for responses, permission requests, errors, and state changes, plus turn-by-turn heading navigation.

## Recommended Reads

- **"Finding a Random Island's Location with Geometry and CUDA"**: A story of **tracing a single resort photo to a real-world location by converting the relative distances and angles between three visible landmasses into a geometric fingerprint and matching it against coastlines worldwide** — the location turned out to be a resort in Micronesia. The author **reduced OpenStreetMap's 882MB of landmass polygon data by latitude, density, and clustering, generated 80.69 million triangles, and parallelized the matching computation on CUDA.** A fun, geeky detective story that weaves together map data and GPU parallel computing. [GeekNews](https://news.hada.io/topic?id=32678)
- **"Civic Hygiene — Don't Build What Could Be Turned Into a Police State" (2013)**: An old but enduring principle: **even a database built for the public good can be repurposed into a surveillance tool for repressing citizens if the regime in power changes, so systems need to be designed with the next government in mind, not just the current one.** The core example: **data on sexual orientation might be useful for health services or school demand planning, but the same data becomes a weapon aimed at specific citizens if a homophobic faction takes power.** Written in 2013, but **worth revisiting now that AI-powered tools are collecting and processing an ever-widening range of data.** [GeekNews](https://news.hada.io/topic?id=32673)
- **"In the Age of AI, Developers Should Build the Bathhouse, Not the Town Hall"**: In the documentary *The Talking Architect*, architect Jeong Gi-yong asks residents what they actually need before designing a town hall. **They tell him not to build a new town hall at all — and if he insists on building something, to build a bathhouse instead.** What people actually needed wasn't a government building, but a place to wash. The piece extends this into a warning: **the cheaper AI makes it to build things, the easier it becomes to rush into building exactly what was requested without first asking what's actually needed.** Alongside **"Build Wide, Deploy Narrow"** from the 8/15 briefing and **"Design Judgment Is Still a Human Job"** from 8/17, this retells the week's recurring conclusion — that **deciding what to build matters more, not less, in the age of agents** — in the language of architecture. [GeekNews](https://news.hada.io/topic?id=32662)
