## New Features & Practical Usage

### `/doctor prompt-audit` — audits CLAUDE.md, skills, agents, and commands for outdated prompting patterns (v2.1.283)

**A new command scans your CLAUDE.md files, skills, agents, and command files for prompting patterns that were written for older-generation models.** You can also run the same check with `/checkup prompt-audit`.

```bash
/doctor prompt-audit
# or
/checkup prompt-audit
```

**Teams that have been using Claude Code for a while often carry CLAUDE.md files or custom skills written back when they first adopted the tool, and those instructions can be unnecessary — or even counterproductive — for today's models. It's worth running this command periodically to keep your instruction files aligned with current models.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `deniedModels` and `availableModelsMatch: exact` — finer-grained control over which models are allowed or blocked (v2.1.283)

**Setting `availableModelsMatch` to `"exact"` restricts access to only the model versions explicitly listed in `availableModels`, so newly released models won't automatically become available until you add them to the list yourself.** **The `deniedModels` managed setting lets you block specific models even if they'd otherwise be allowed by `availableModels`.**

```json
{
  "availableModels": ["claude-opus-5-5", "claude-sonnet-5"],
  "availableModelsMatch": "exact",
  "deniedModels": ["claude-3-5-sonnet-20240620"]
}
```

**For organizations that tightly govern which models employees can use, this combination is handy: new models stay locked out by default until an admin reviews and explicitly approves them.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### Tired of forgetful AI, one developer built themselves a second brain (9/25)

**After repeatedly watching Claude forget command syntax it had already learned and confidently suggest options that don't exist, one developer started writing down what they'd learned in Obsidian to reference later.** **The core insight: keeping your own notes makes it faster to find answers and explanations tailored to your specific situation, and the act of organizing that information helps you understand and retain it in the first place.**

**If Claude Code keeps making the same mistakes or you find yourself re-explaining things it already confirmed in a previous session, it's worth considering a personal knowledge base like this instead of trying to cram everything into CLAUDE.md.** [GeekNews](https://news.hada.io/topic?id=34251)

### Grouping requests by prompt in your LLM gateway with the `x-claude-code-prompt-id` header (v2.1.283)

**A new gateway hint header, `x-claude-code-prompt-id`, lets teams running their own LLM gateway group multiple requests that originated from a single user prompt.** It's opt-in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`.

```bash
export CLAUDE_CODE_GATEWAY_HINT_HEADERS=1
```

**If your team logs or analyzes Claude Code traffic through an internal LLM gateway or proxy, this header lets you tell at the gateway level whether parallel tool calls or retries came from the same prompt.** [Full release notes](https://github.com/anthropics/claude-code/releases)

**In a 2-1 ruling, the DC Circuit Court of Appeals upheld the Department of Defense's supply-chain risk designation against Anthropic, rejecting the company's arguments that the ban on Claude usage was arbitrary, exceeded the agency's authority, and unconstitutional.** **The designation bars the US military from using Anthropic's models and also affects defense contractors.**

## Ecosystem & Plugins

### Archify — an agent skill that turns code and descriptions into explorable system diagrams (9/25)

**This agent skill analyzes a codebase or takes a plain-language description of a system and turns it into a diagram you can actually explore, with clickable components and connections.** **It works with Cursor, Claude Code, Codex CLI, and OpenCode, can be started from a natural-language description with no repository required, and supports several diagram types including architecture, workflow, sequence, and data-flow diagrams.**

**It tackles a similar problem to Whiteboard, the canvas-based design IDE covered in the 9/25 briefing, but Archify's edge is that it ships as a skill you can drop straight into several coding agents without a separate desktop app. Worth a try if you're tired of narrating your architecture out loud at every design review.** [GeekNews](https://news.hada.io/topic?id=34248)

### Amazon Bedrock Mantle added as an upstream provider in the Claude app gateway (v2.1.283)

**The self-hosted Claude app gateway now supports Amazon Bedrock's Mantle endpoint as a new upstream provider.** **This follows the Bedrock `assume_role` and `guardrail` support covered in the 9/23 briefing, continuing the trend of expanding Bedrock integration options.**

**Organizations running Claude through AWS Bedrock should check whether the new Mantle endpoint fits their existing network and account setup better than their current configuration.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Minor Changes

All of the following are from **v2.1.283** (9/25).

- **When `OTEL_LOG_TOOL_CONTENT=1` is set, output from MCP tools, WebFetch, and WebSearch is now included in the `tool.output` OpenTelemetry event.**
- **In fullscreen mode, you can now expand a truncated message from another session with a single click.**
- **When a `--plugin-dir` fails to load, the error now includes the path (`path`) of the directory that couldn't be loaded.**
- **With `load_test_mode` enabled, the Claude app gateway builds and signs requests but never actually sends them upstream, returning pre-set responses instead — useful for load testing in deployment environments.**
- **The `/ultrareview` launch dialog now warns that reviewing a local branch may upload uncommitted changes.**
- **The "(1M context)" label is no longer shown next to the Opus row and default model name in the `/model` picker when Opus already supports the 1-million-token context window.**
- **Terminal prompt suggestions appear less often after going unused for 20 consecutive times, and return to their normal frequency as soon as you use one.**
- **`--system-prompt` and `--append-system-prompt` can now accept both plain text and a `-file` argument together, with the file's contents applied first followed by the text.**
