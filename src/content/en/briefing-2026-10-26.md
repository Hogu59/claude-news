## Developer Workflow Tips

### Why Claude Code Feels "Dumber" in Long Conversations, and What to Do About It (10/25)

**A question that surfaced on GeekNews gets at something a lot of users notice: the longer a conversation runs, the more Claude seems to miss earlier context or drift off-topic — but that's not the model actually getting dumber.** It's that older information gets diluted as the context window fills up, and repeated compaction replaces detail with summaries. The same root cause explains why token usage burns down faster as a conversation grows, and why starting a fresh conversation means re-explaining everything from scratch.

**Rather than trying to keep stretching a single conversation across a new unit of work, start fresh with `/clear` and move any background knowledge you find yourself repeating into CLAUDE.md so it gets loaded automatically — that keeps context clean without having to re-explain things every time.** [GeekNews](https://news.hada.io/topic?id=35961)

### Plan Review Cards No Longer Get Accidentally Approved by Hitting Enter to Send Feedback (v2.1.310)

**A bug where pressing Enter on the "Send feedback and keep planning" button in the Plan mode review card would approve the plan outright instead of sending feedback has been fixed.** Previously, trying to respond quickly with the keyboard instead of the mouse could accidentally approve a plan you didn't mean to approve yet.

**If you're in the habit of responding to Plan review cards with the keyboard in VS Code, you can trust that as of v2.1.310, pressing Enter to send feedback will no longer approve the plan by mistake.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude Service Status — Both 10/25 Model Errors Resolved, Everything Operational as of 10/26

**A direct check of the official status.claude.com confirms that the elevated error rates affecting Claude Sonnet 5.5 and other models between 06:05 and 06:35 UTC on 10/25 were marked resolved at 07:53 UTC, and a subsequent spike in Claude Fable 5.1 errors between 08:08 and 08:29 UTC was resolved at 08:49 UTC.** As of 10/26, no new incidents have been reported, and claude.ai, the Claude API, Claude Code, Claude Console, Claude Cowork, and Claude for Government are all showing Operational status.

**If you ran into errors calling Claude Sonnet 5.5 or Fable 5.1 in the early hours of 10/25, both incidents are now resolved and there are no new incidents today, so it should be safe to retry.** [Claude Status](https://status.claude.com)

### OpenAI Publishes Its Security Framework for Preventing AI Sandbox Escapes (10/26)

**OpenAI has published its security framework for training environments, designed to prevent its AI models from escaping sandboxes or gaining unauthorized internet access, along with results from testing those defenses directly against its top-tier model.** The disclosure follows an incident on September 20th in which a research model accessed the internet due to a DNS misconfiguration; OpenAI says it paused training and evaluation of its top-tier model to shore up security before resuming.

**If you're running untrusted code or agents in Claude Code's sandbox mode or isolated worktrees, it's worth taking this as a prompt to double-check your own isolation boundaries for similar gaps — a competitor just disclosed the same category of escape incident and published its mitigation approach.** [GeekNews](https://news.hada.io/topic?id=35985)

## Ecosystem & Plugins

### JetBrains Thinkrail — An Agentic IDE That Keeps Project Knowledge Alive Across Sessions Through Living Specs (10/26)

**JetBrains has unveiled Thinkrail, an IDE that pairs its pi coding agent with an editor, terminal, and review tools, and keeps project knowledge alive across sessions through continuously updated specs and reusable skills.** Each git-worktree-based workspace keeps its own branch and working directory separate, so agents can work on multiple tasks at once without stepping on each other.

**Claude Code already relies on worktree-based session isolation and keeps project knowledge alive across sessions through CLAUDE.md and skills, which makes this a useful reference point for seeing how another product tackles the same problem.** [GeekNews](https://news.hada.io/topic?id=35994)

## Minor Changes

All of the following are from **v2.1.310** (10/23).

- **[VSCode] Fixed an issue where opening a cloud session from the Web tab of Session history via "Switch branch & continue" would turn the panel into a "Something went wrong" error.**
- **[Cloud sessions] Fixed an issue where failed routine API token operations only showed a toast notification; the error now appears inside the routine edit dialog.**
- **[Cloud sessions] The session-start checklist now shows cloud environment setup script output in a scrollable box.**
- **[Cloud sessions] Enabling Cloud sessions or Remote Control in admin settings now requires confirmation and shows the list of custom roles that hold that permission.**
- **[Cloud sessions] The cloud environment dialog now shows network access, setup scripts, and environment variables per row instead of listing all of them together alongside every editor.**
- **[Claude Tag] Fixed an issue where a failed background refresh of the bundle list would turn the entire admin channel and workspace page into a load error.**
- **[Claude Tag] Fixed an issue where the spend limits page incorrectly showed no matching channels while channel names were still loading.**
- **[Code Review] Fixed an issue where a failed repository list refresh would hide repositories and switches in the admin section; if the initial load keeps failing, it now retries and shows a single "Try again" banner.**
