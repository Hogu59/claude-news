## Developer Workflow Tips

### easel — a built-in mod that automatically charts MCP metric results and similar data has been added (v2.1.330)

**Until now, seeing a chart of numeric results Claude Code pulled from an MCP tool meant asking for one separately every time. Starting with this release, on Pro, Max, and — where supported — Team and Enterprise plans (macOS and Linux), a built-in mod called easel automatically renders a chart when you ask for one, or right under MCP metric results.** If you don't want automatic charts, you can turn the feature off from `/config`.

```bash
# To open /config and disable easel's automatic charting
/config
# → turn off the "automatic charts" option
```

**If you query metrics or numeric data through MCP often and have been separately asking Claude to "chart this" every time, from v2.1.330 onward it's worth just using the charts that appear automatically — and only switching it off in `/config` if you don't want them.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Scheduled tasks and `/loop` can now run for up to 30 days while the session stays alive (v2.1.330)

**Previously, recurring scheduled tasks and `/loop` would cut off after 7 days even if the session was still alive. Starting with this release, that maximum has been extended to 30 days, and you're now given advance notice of when a run is about to end.** Tasks created and saved before this release are still subject to the old 7-day limit.

**If you've been running long monitoring or recurring check jobs through `/loop` or scheduled tasks and having to reset them every 7 days, after upgrading to v2.1.330 any newly created task can now run uninterrupted for up to 30 days.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### VS Code gained `/fork`, which forks a conversation from right after the last response (v2.1.330)

**Until now, branching a conversation to try a different approach meant starting a brand-new session. Starting with this release, the `/fork` command in VS Code lets you fork the conversation right from the point of the last response.**

**If you've wanted to try different approaches within the same conversation while using Claude Code in VS Code, from v2.1.330 onward `/fork` is worth using to branch off immediately while keeping all the context built up so far.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### `rm` commands targeting root, home, and working directories now require approval in more cases (v2.1.330)

**Some risky `rm` commands already required confirmation before, but starting with this release the scope has widened: more `rm` commands targeting root, home, top-level, and working directories now require approval, and in situations where nobody is available to respond to an approval prompt — such as unattended automation — those commands are simply rejected outright.**

**If you're running Claude Code in an unattended automation pipeline using auto mode or bypass-permissions mode, it's worth keeping in mind that after upgrading to v2.1.330, some deletion-type commands that previously passed through silently may now be rejected or left waiting on approval that never comes.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Community News

- **An Anthropic mathematician announced that he and Claude proved the Riemann Hypothesis and the Generalized Riemann Hypothesis (11/21)**: Anthropic mathematician Levent Alpöge published a public PDF claiming that he and Claude found a proof of the Riemann Hypothesis (RH) and the Generalized Riemann Hypothesis (GRH), formally verified in Lean with no additional assumptions. He says the work started from the idea of extending the Stepanov method from function fields to the integers, reached its final form on 11/16 through repeated application of theta lifts, and that the plain-language explanation runs to roughly 250,000 pages, which is why it wasn't released as-is. He admits he himself hasn't fully mastered the underlying mathematics. In the comments, skepticism about the timing of the announcement right after the IPO, concern that a single hallucinated step could collapse the entire proof, and the counterpoint that Lean's formal verification is at least some basis for trust all came up against each other. [GeekNews](https://news.hada.io/topic?id=37529)
- **Separately, Alessandro Masullo released a roughly 900-page draft proof of the Generalized Riemann Hypothesis written entirely by hand (11/20)**: Masullo released his draft of "The Music of the Primes" — which he'd planned to spend a year polishing before publishing — earlier than planned, saying Brian Conrad has been reviewing it for months and has given largely positive feedback. The draft is notable for being a purely human proof with no AI involved, and some commenters speculated that the early release was a response to Anthropic's announcement. [GeekNews](https://news.hada.io/topic?id=37541)
- **An experiment was released showing a language model improving its own performance by rewriting its weights directly, without gradient-based training (11/21)**: In the study, Qwen3.5 27B used its own scoring results and tools to diagnose why it was failing, then directly swapped out part of its weights with new tensors — without any further training or backpropagation — raising its accuracy on a private test set by 6.6 percentage points. The approach failed at 2B, 4B, and 9B scale and only succeeded at 27B, and the authors themselves are careful to note this doesn't prove full recursive self-improvement. Many comments criticized the title as overstated and pointed out the lack of proper control experiments. [GeekNews](https://news.hada.io/topic?id=37540)

## Minor Changes

All of the following are from **v2.1.330** (11/20) and weren't covered above.

- **Added the `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` environment variable**, which prints the full sign-in link for cases where the short login link errors out or a script needs to read the value directly.
- **Fixed `/mcp` misclassifying plugin-installed MCP servers as built-in servers**; it now separates them into "Plugin MCPs" and an "Other MCPs" group that bundles `--mcp-config` servers with built-in ones.
- **Fixed `/stats` tallying activity by UTC date**; it now aggregates by local time zone instead.
- **Added fields to `claude plugin install --json` output** showing whether the install command wrote to stderr (`commandPrinted`) and whether it failed (`commandFailed`).
- **Added VS Code settings `claudeCode.pinPrompt`**, which lets a selected message scroll away instead of staying pinned, **and `claudeCode.escapeStopsClaude`**, which can be turned off so Esc no longer stops Claude.
- **Fixed `/ultrareview` failing or reviewing the wrong code after a cell moved to a different repository**; it now reports both folder names and stops instead.

The core of it is a "hypothesis-driven debugging" skill that logs testable hypotheses to a CSV and verifies or refutes them experimentally before iterating, plus persistent memory that keeps progress recorded in Markdown so it survives context compaction or an agent swap. Over the past six months, the author used this approach to analyze and modify an Alphasmart NEO, a Sony camera, and synthesizer firmware, estimating that each would otherwise have taken years to do manually. Commenters shared similar results from connecting Ghidra to MCP, and debated whether skill files actually outperform plain prompts. ## Interesting Projects & Tools

- **OpenDocKit — a Python library that converts real-world documents, from HWP to PDF and Excel, into LLM-ready Markdown (11/20)**: It aims to preserve structures that easily break during text extraction — merged cells, two-column PDFs, HWP file structure — and hand them cleanly to RAG pipelines and agents. It detects format by content rather than file extension, so it correctly reads HTML tables saved with an `.xls` extension, fills merged cells row by row, and converts charts into data tables, SmartArt into nested lists, and formulas into LaTeX. It ships with a LangChain loader, a LlamaIndex reader, and an MCP server, and also works as a plugin for Claude Code, Dify, and Hermes Agent. It installs via `pip install opendockit`, runs offline and deterministically by default, and needs no GPU or ML model. [GitHub](https://github.com/hyeonsang010716/OpenDocKit) · [GeekNews](https://news.hada.io/topic?id=37495)
- **Nubis — a Windows SSH/RDP/SFTP client with a built-in Claude panel (11/21)**: A solo-developed, open-source Windows app that reads credentials already configured for AWS, Tencent Cloud, GCP, Azure, and OCI to sync your list of cloud servers, opens SSH, RDP, and PowerShell sessions as tabs, and can open an SFTP panel alongside them. Its optional Claude panel is aware of whichever tab you're currently viewing and connects to Claude Code installed on your PC as an internal MCP server, letting it run commands or handle host management and file transfers — though every action on a server requires approval and is recorded in an audit log. The app itself isn't sandboxed, so it's worth noting that Claude operates with the same Windows account permissions as the user. It ships as a portable zip that runs with no installation, and it collects no telemetry. [GitHub](https://github.com/windevase/nubis) · [GeekNews](https://news.hada.io/topic?id=37538)
