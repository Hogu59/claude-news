**After v2.1.299 and v2.1.300 shipped back-to-back on 10/14, v2.1.301 followed just a day later on 10/15.** This release brings usage-limit handling to the unattended retry watchdog, extends the OpenTelemetry `tool_decision` event, adds bracket-jump (`%`) motion to vim mode, and introduces a multi-line input (`rows`) API for plugin and mod developers.

[Full release notes](https://github.com/anthropics/claude-code/releases)

## New Features & Practical Usage

### Anthropic, OpenAI, and Simons Foundation jointly commit $15M to help mathematicians navigate the AI era (10/16)

**The Simons Foundation, together with Anthropic and OpenAI, has committed a combined $15 million in funding and resources to help the mathematics community adopt AI and adapt to the changes it brings.** The foundation will manage and distribute the funding directly, including through open calls for proposals, while jointly exploring how to evaluate AI-assisted research results and what new tools mathematicians need.

**If you're experimenting with using Claude or other models as a research assistant in mathematics, it's worth watching for when this program opens its call for proposals.** [GeekNews](https://news.hada.io/topic?id=35428)

### OTel `tool_decision` events now separate auto mode classifier verdicts from permission rules (v2.1.301)

**The `tool_decision` OpenTelemetry event now includes `classifier_verdict` and `permission_mode`, so you no longer have to untangle auto mode's classifier decisions from permission-rule decisions bundled into the same field.** Turning on `OTEL_LOG_TOOL_DETAILS=1` also logs `classifier_category`, letting you see by name which built-in rule the classifier used to block a tool call.

```bash
# Include the name of the built-in rule the classifier matched in tool decision events
export OTEL_LOG_TOOL_DETAILS=1
```

**If you run Claude Code in auto mode and monitor tool calls via OpenTelemetry, this new field lets you break out calls blocked by the classifier separately from calls blocked by your organization's permission rules.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS — keeping unattended retries from waiting forever (v2.1.301)

**Setting the new environment variable `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` tells unattended retry mode (`CLAUDE_CODE_RETRY_WATCHDOG`) to give up and end the request instead of waiting when a usage limit's reset time is too far off.** Previously, the watchdog would wait no matter how many hours remained until the limit reset, so overnight unattended jobs could still be stuck the next morning.

```bash
# End the request instead of waiting if the usage-limit reset is more than 30 minutes away
export CLAUDE_CODE_RETRY_WATCHDOG=1
export CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS=1800000
```

**If you run Claude Code unattended via CI or a scheduler, setting a short maximum wait with this variable means a job won't stall indefinitely waiting for a limit reset — it can instead retry cleanly on the next scheduled run.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### The claude-api skill now includes an OpenTelemetry tracing guide (v2.1.301)

**The `claude-api` skill now includes a guide for setting up OpenTelemetry tracing, including how to configure trace destinations with the `ant` CLI.** Previously, wiring OTel tracing into your own Agent SDK application meant hunting down external documentation; now the setup steps are available directly within the skill.

**If you're adding tracing to an application built on the Claude API or Agent SDK, loading the `claude-api` skill and following its trace-destination setup steps is the fastest place to start.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Security & Limitations

### Claude service status — all systems operational, no new incidents (10/16)

**Checking status.claude.com directly shows that as of 10/16, claude.ai, the Claude API, Claude Code, Claude Console, Claude Cowork, and Claude for Government are all Operational, with no newly reported incidents since the Claude Console performance degradation on 10/13 at 18:00 UTC was resolved.** That stable, incident-free run has continued through 10/14 and 10/15, and into 10/16.

**With the service running smoothly for several days straight, if you're hitting unexplained errors in Claude Code sessions or API calls, it's more likely worth checking your local setup or network first rather than assuming a service-side issue.** [Claude Status](https://status.claude.com)

### The engineer behind Mononoke pushes back directly on the Scion design-reuse controversy (10/16)

**Responding to the design-reuse allegations against Scion covered in yesterday's briefing (10/15), the engineer who led the design of Meta Mononoke's Bonsai data model has published further remarks directly accusing Anthropic of deliberate copying and failing to credit the source.** The claims rest on private confirmations and overlapping personnel, though the confirmations themselves haven't been made public, and argue that the similarities extend beyond derived-data handling to cover the entire data model and surrounding structure.

**Separate from the technical achievement Anthropic touted internally when Scion replaced Git, the broader debate over how to credit open-source design work when borrowing from it looks set to continue for a while.** [GeekNews](https://news.hada.io/topic?id=35434)

### An Israeli ad-tech firm distributed zero-click spyware through nothing but online ads (10/16)

**A joint investigation by Citizen Lab and Confiant found that Israeli ad-tech firm Discover-Tech worked with spyware vendors to infect devices simply by serving them an online ad.** The case is drawing attention as the first concrete technical evidence of a targeted-ad delivery pipeline infecting devices with no click or other user action required.

**If you run a service that receives traffic through ad networks, this investigation is a reminder that ad SDKs or third-party ad tags themselves can become a supply-chain attack vector.** [GeekNews](https://news.hada.io/topic?id=35432)

## Minor Changes

All items below are from **v2.1.301** (10/15).

- **Vim mode adds `%` motion**, letting you jump alone to a matching bracket or combine it with d/c/y to define a range.
- **mod's `Input` adds `rows`**, enabling multi-line text fields in the terminal. Enter submits; Shift+Enter or a backslash before a line break inserts a new line.
- **[VSCode] LaTeX math rendering added to Claude's responses**, covering block equations, multi-line equations, and inline math.
- **[VSCode] The Pro/Max plan usage-limit banner now includes a link with more usage details.**
- **Windows: Fixed a bug where the final exit-status line was missing from the output file of interrupted background PowerShell commands.**
