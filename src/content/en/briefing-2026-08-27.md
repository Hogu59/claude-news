## New Features & Practical Usage

### SendFeedback tool — Claude drafts a feedback report when something goes wrong mid-session (v2.1.247)

A new tool lets **Claude draft a feedback report itself when something goes wrong during a session**, which you can then review in `/feedback` and decide whether to send.

```bash
# When Claude detects unusual behavior mid-session, it automatically prepares a feedback draft
/feedback
# If you'd rather skip drafting altogether, turn it off via the feedbackDrafts setting
```

**Until now, if something went wrong in a session, you had to remember the context — what you were doing and what broke — and write up feedback separately later.** Now, **a draft capturing the exact context at the moment the problem occurred is prepared automatically, so all that's left is to review and send it.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### `/claude-api cost-optimize` — break down and cut your API spend line by line (v2.1.247)

```bash
# Profiles your project's existing Claude API spend patterns and
# walks through cost-cutting levers one at a time: caching, token savings, batching, effort, and model choice
/claude-api cost-optimize
```

This command **profiles your project's existing Claude API usage patterns, then walks through each cost lever — caching, token savings, batch processing, effort tuning, and model selection — one at a time, in measurable steps.** The `claude-api` skill also gained **Admin API coverage (organization members, invites, workspaces, API keys, rate limit reports, workload identity federation, and CMEK).**

**If your API costs have been creeping up and you're not sure where to start, this command is worth running to get a prioritized checklist.** [Full release notes](https://github.com/anthropics/claude-code/releases)

### Sonnet 5's auto-compact threshold now scales to the full 1M context (v2.1.247)

**The default auto-compact threshold for Sonnet 5 sessions using the 1M context window is now recalculated against the larger full 1M baseline.** As a result, **auto-compaction now kicks in later — around 967K tokens instead of the previous ~934K.**

**For sessions that regularly fill up long contexts, that's roughly 30,000 more tokens of headroom before compaction kicks in.** [Full release notes](https://github.com/anthropics/claude-code/releases)

## Developer Workflow Tips

### One keystroke switches to auto mode right from the Bash permission prompt (v2.1.247)

**The Bash permission prompt now includes a tip pointing to auto mode**, letting you **select "Yes, and switch to auto mode" with a single keystroke.**

**If you've been clicking through approval prompts for the same repeated Bash commands, this is a good nudge to finally try auto mode.** You can check and adjust which rules trigger auto-approval in the Auto Mode tab of `/permissions`, added in v2.1.246. [Full release notes](https://github.com/anthropics/claude-code/releases)

### RAG is simpler than you think — start with BM25, not a vector DB (8/27)

A piece argues that **many RAG systems reach for embeddings, vector DBs, and reranking pipelines from day one, when a large share of real-world search problems can actually be solved with just BM25 and query rewriting.** The core idea is to **pick from six retrieval architectures in stages, based on data freshness, document change rate, query type, search volume, and team capability** — and only move up a tier when the added complexity is actually justified.

**If you're designing a RAG pipeline on top of Claude Code or the Claude API to search internal docs or a codebase, it's worth running your current requirements against this piece's staged checklist before jumping straight to a vector DB.** [GeekNews](https://news.hada.io/topic?id=32916)

### Claude now clearly recognizes MCP connection failures on Bedrock, Vertex, and Foundry (v2.1.247)

On **Bedrock, Vertex, and Foundry sessions (and any session with telemetry disabled), when a configured MCP server connection fails, Claude now gets told about the connection failure itself** instead of wrongly concluding that the tool doesn't exist at all.

**If you're running MCP servers in an enterprise deployment, this fix should cut down on cases where Claude mistakenly worked around a "missing" tool that was actually just unreachable.** [Full release notes](https://github.com/anthropics/claude-code/releases)

[Claude Status](https://status.claude.com/history) · [StatusGator](https://statusgator.com/services/claude)

### Plugin marketplaces now reject names containing control or invisible characters (v2.1.247)

**Plugin names containing control characters or invisible characters can no longer be registered in a marketplace**, and **text supplied by marketplaces in `/plugin` and `claude plugin` output is now escape-safe** as well.

**If you're installing plugins from third-party marketplaces, this hardening closes off attempts to disguise plugin names with invisible characters or manipulate terminal output.** [Full release notes](https://github.com/anthropics/claude-code/releases)

As confirmed in the official pricing documentation on 8/26, **Sonnet 5's pricing of $2 input / $10 output stays locked in as the permanent standard rate, with no September price increase.** The only remaining variable is the end of the weekly boost.

## Minor Changes

All items below are from **v2.1.247**.

- **`spinnerTipsOverride` gained `{id, text, cooldownSessions, priority}` fields along with `tipsFile` and `label`**, letting organizations rotate their own tips alongside the built-in ones.
- **When a subagent hits a model 404 on its first call, it no longer dies — it now falls back through the session's fallback model chain**, and the error passed up to the parent includes the error type, status, request ID, and model name.
- Fixed an issue where **hooks or background agents dumping several megabytes of error output could overflow the conversation and freeze the session with a "Prompt is too long" error.**
- Fixed an issue where **Ctrl shortcuts stopped working in kitty-protocol terminals on non-Latin keyboard layouts, such as Cyrillic.**
- Fixed an issue where **Bash sandbox post-cleanup would delete `~/.claude/settings.json` symlinks managed by dotfile tools (nix/home-manager, stow) that had been redirected outside the sandbox's writable area.**
- Fixed an issue where **`/terminal-setup` overwrote Zed's entire `keymap.json`** — it now merges into existing keybindings instead.
- **Cross-session peer messages now collapse by default into a one-line preview in the form `Message from @<sender>: <first line>`**, with Ctrl+O to expand the full content.
- **Terminal hyperlinks pointing to network or automount paths, or starting with control or invisible characters, now render as plain text.**

- **"C2PA cameras collapse against real-world attacks"**: An investigation finds that **while Android C2PA camera apps use Key Attestation and Google Play Integrity to block app tampering, an attacker with root access can generate a valid C2PA signature for any arbitrary file.** The core problem: **even a device with a locked bootloader and the latest security patches can be rooted through a single privilege escalation bug.** A useful case study for anyone designing content provenance or integrity verification systems — it shows **device trust alone isn't enough to close out a signing scheme.** [GeekNews](https://news.hada.io/topic?id=32917)

## Interesting Projects & Tools

- **SELF — a queryable executable (8/27)**: An experimental project that **structures a program as a SQLite database, storing not just code but websites, routes, visit history, and application state all in a single file.** It works by having **Linux's `binfmt_misc` invoke a dedicated interpreter that maps the segments table into memory.** It's a departure from the usual approach of keeping an application's code and state separate, and **the idea of querying execution, data, and history together within one file** feels genuinely fresh. [GeekNews](https://news.hada.io/topic?id=32922)
- **Tailcat — a netcat that links two machines without a Tailscale account (8/27)**: A **netcat-style CLI and Go library that uses Tailscale's open-source data plane to connect two machines without needing a Tailscale account or control server.** One side prints a short connection token; hand it to the other machine, and **standard input/output or a TCP port gets linked through a WireGuard-encrypted tunnel.** A **lightweight option you can use immediately, with no account signup required**, whenever you need a quick, secure connection to a remote machine. [GeekNews](https://news.hada.io/topic?id=32920)
