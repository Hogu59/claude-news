**풀스크린 모드에서 대화 옆에 diff 패널을 띄워, Claude가 편집하는 동안 커밋되지 않은 변경사항을 실시간으로 보여주는 기능이 추가**됐습니다. **`/diff`로 언제든 켜고 끌 수 있습니다.**

```bash

```

**대화 흐름과 실제 코드 변경을 동시에 확인하고 싶을 때, 별도로 IDE나 `git diff`를 오가지 않고 한 화면에서 검토**할 수 있습니다. 같은 릴리스에서 **헤드리스 세션에도 `/reload-plugins`가 추가**되고, **`/advisor`의 텍스트 형태(`/advisor`, `/advisor <model>`, `/advisor off`)가 데스크톱 앱·Remote Control·헤드리스 세션에서도 쓸 수 있게** 됐습니다. ## 보안/제한 이슈

### 괄호가 포함된 권한 규칙이 무효화되며 read-only 폴더가 쓰기 가능한 상태로 남던 버그 (v2.1.260)

**경로에 괄호가 포함된 `Edit`/`Write`/`Read` 권한 규칙이 Bash 샌드박스에서 유효하지 않은 규칙으로 처리되어 무시되던 문제가 수정**됐습니다. **이 때문에 사용자가 read-only로 지정한 폴더가 실제로는 쓰기 가능한 상태로 남아 있었습니다.**

**폴더나 파일 이름에 괄호가 들어간 프로젝트에서 `Edit()`/`Write()` deny 규칙으로 특정 경로를 보호하고 있었다면, 업데이트 전까지는 그 보호가 조용히 무력화되어 있었을 가능성이 있으므로 최신 버전으로 갱신할 필요가 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### zsh 셸 변수에 숨긴 명령 치환이 자동 승인되던 버그 (v2.1.260)

**`REPORTTIME`, `REPORTMEMORY`, `DIRSTACKSIZE` 같은 zsh 셸 변수 할당 안에 명령 치환을 숨기면 Bash 권한 검사가 이를 자동 승인하던 문제가 수정**됐습니다. **이제 이런 명령은 다른 명령과 마찬가지로 승인을 요구**합니다.

**auto mode나 낮은 권한 모드로 Claude Code를 운영하고 있다면, 지금까지는 이런 셸 변수 할당을 가장해 임의 명령을 승인 없이 실행시킬 수 있는 경로가 있었다는 점에서 업데이트를 권장**합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.260**(9/3) 항목입니다.

- **v2.1.259에서 `Read()` deny 규칙을 Bash 인자에도 적용하도록 바꾼 변경이 되돌려집니다.** 이 변경은 `Read(./**/build/**)` 규칙이 걸려 있으면 모든 모드에서 `npm run build`까지 거부하고, `cd … && grep`이 auto mode에서도 확인을 요구하게 만드는 부작용이 있었습니다.
- **IDE에서 선택한 라인 범위가 스킬이나 슬래시 커맨드를 실행하면 사라지던 문제**가 수정되어, "N lines selected" 컨텍스트가 이제 Claude에 정상 전달됩니다.
- **중첩된 서브그룹(`gitlab.com/group/subgroup/project`)에 있는 GitLab 프로젝트의 저장소 인식**이 수정됩니다.
- **`owner/repo#123` 형식의 이슈 참조가 GitLab 저장소에서 작업 중일 때도 github.com으로 잘못 링크되던 문제**가 수정되어, 이제 gitlab.com 이슈로 정확히 연결됩니다.
- **불닫힌 `[`처럼 컴파일할 수 없는 패턴을 가진 파일 권한 규칙 하나 때문에 모든 파일 편집이 "Invalid regular expression" 오류로 실패하던 문제**가 수정되어, 이런 deny 규칙은 이제 정확히 그 리터럴 경로만 막습니다.
- **풀스크린 모드의 `Ctrl+L`/`Cmd+K`가 터미널의 `clear`처럼 트랜스크립트 뷰를 지우도록 바뀝니다.** 위로 스크롤하면 이전 대화를 다시 볼 수 있습니다.
- **서브에이전트가 시작한 백그라운드 명령의 1시간 실행 시간 제한이 제거**되어, 메인 세션과 마찬가지로 명령이 끝나거나 중단될 때까지 계속 실행됩니다.
- [VSCode] **입력창 풋터의 모델 필에 선택된 effort 레벨이 표시**되고, **세션 목록에 Open/Closed 상태 필터가 추가**됩니다.
