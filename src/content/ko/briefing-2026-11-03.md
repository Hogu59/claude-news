## 주요 신규 기능 & 실전 활용

### Code Review가 클라우드·Remote Control 세션에서도 발견 사항을 카드로 보여줍니다 (v2.1.316)

**Claude Desktop의 Code 탭이나 웹에서 `/code-review`를 시작하면, 클라우드 세션과 `claude remote-control` 세션 모두 이제 발견 사항을 구조화된 카드 형태로 보여주고, 더 이상 일반 텍스트 목록으로만 표시하지 않습니다.** 지금까지는 터미널에서는 발견 사항이 보기 쉬운 카드로 표시됐지만, 같은 리뷰를 클라우드나 Remote Control 세션에서 열면 긴 텍스트 목록을 그대로 읽어야 하는 경우가 있었습니다.

**Claude Desktop이나 웹에서 클라우드 세션을 열어 코드 리뷰를 진행하는 팀이라면, v2.1.316부터는 터미널과 동일하게 심각도별로 정리된 카드를 바로 확인할 수 있어 리뷰 결과를 팀원과 공유하기도 더 쉬워졌습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### Claude Code가 스스로 종료될 때 macOS·Linux에 남던 유령 셸 프로세스가 사라집니다 (v2.1.316)

**자격 증명이 거부되거나 클라우드 세션이 보관(archive) 처리되는 등 Claude Code가 스스로 프로세스를 끝낼 때, 실행 중이던 셸 명령이 macOS·Linux에서 그대로 살아남는 문제가 수정됐습니다.** 지금까지는 세션이 예기치 않게 종료돼도 그 세션이 띄운 백그라운드 명령이 고스란히 남아, 직접 `ps`로 찾아 정리해야 하는 경우가 있었습니다.

**장시간 빌드나 서버 프로세스를 Bash 도구로 띄워둔 채 세션이 자격 증명 오류나 보관 처리로 갑자기 끝난 경험이 있다면, v2.1.316부터는 그런 유령 프로세스를 수동으로 찾아 죽이는 수고를 덜 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 줄바꿈이 든 bash alias와 하이픈으로 시작하는 함수 이름이 더 이상 깨지지 않습니다 (v2.1.316, Git Bash 제외)

**여러 줄에 걸쳐 정의한 bash alias나 이름이 하이픈으로 시작하는 함수가 Bash 도구의 셸에서 깨지거나 통째로 사라지던 문제가 수정됐습니다.** 다만 이 수정은 Git Bash에는 적용되지 않아, Windows에서 Git Bash를 쓰는 경우에는 여전히 같은 문제가 남아 있습니다.

```bash
# 지금까지 Bash 도구에서 깨지거나 사라지던 형태
alias deploy='
  npm run build &&
  npm run test &&
  npm run deploy
'
-my-helper() { echo "줄바꿈 alias와 하이픈 함수 이름"; }
```

**셸 설정 파일에 여러 줄짜리 alias나 하이픈으로 시작하는 함수 이름을 정의해두고 Claude Code의 Bash 도구로 그대로 쓰고 있다면, macOS·Linux·일반 터미널에서는 v2.1.316부터 그대로 동작한다는 점을 확인해볼 만합니다. 다만 Git Bash 환경이라면 여전히 별도 alias로 우회해야 합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### GitHub remote가 없을 때 `/ultrareview`·클라우드 세션의 안내 메시지가 더 명확해졌습니다 (v2.1.316)

**`/ultrareview`나 클라우드 세션, 클라우드 에이전트가 GitHub remote를 찾지 못하면 이제 `https://github.com/new`에서 저장소를 만들라고 구체적으로 안내하며, `/ultrareview`는 `gh`가 거부하는 `gh` 명령을 더 이상 제안하지 않습니다.** 지금까지는 remote가 없는 로컬 저장소에서 이 기능들을 쓰면 원인이 불분명한 오류나, 실행해도 실패하는 `gh` 명령 제안을 받는 경우가 있었습니다.

**새로 시작한 프로젝트나 아직 GitHub에 올리지 않은 저장소에서 `/ultrareview`나 클라우드 세션을 먼저 써보려 한다면, v2.1.316부터는 어디서 저장소를 만들어야 하는지 바로 안내받을 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**최근 며칠 사이 커넥터나 서비스 오류를 겪었다면 이미 모두 해소된 상태이니, 오늘 문제가 발생한다면 로컬 설정이나 네트워크 쪽을 먼저 점검해보는 것이 합리적입니다.** [Claude Status](https://status.claude.com)

**Team·Enterprise 계정으로 로그인했을 때, Anthropic API에서 받아온 서버 관리형 설정은 이제 별도 승인 절차 없이 바로 적용되는 대신, 로컬에 저장된 설정 사본이 서명 검증을 통과하지 못하면 그 사본은 거부됩니다.** 지금까지는 로컬에 남아 있는 관리형 설정 사본이 조작되거나 손상됐더라도 이를 구분 없이 그대로 적용하는 경우가 있었습니다.

**조직 차원에서 managed settings로 Claude Code 정책을 배포하고 있다면, v2.1.316부터는 손상되거나 조작된 로컬 설정 사본이 조용히 적용될 위험이 줄었다는 점을 안심하고 반영해도 됩니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.316**(10/31) 항목입니다.

- **`autoMode.allow` 목록에 `$defaults`가 없으면 내장 예외 규칙이 사라지던 문제가 수정**돼, 호스트 앱의 `--settings`, `/permissions`에서 추가한 첫 규칙, `/auto-mode-setup`에서 가져온 내장 예외가 다시 함께 적용됩니다.
- **auto mode가 서버로부터 안전성 평가 결과를 받지 못해 턴을 멈췄을 때, 클라우드 세션과 클라우드 예약 작업이 "실패"로 표시되지 않던 문제가 수정**됐습니다.
- **백그라운드 에이전트가 여전히 작업 중일 때 auto mode가 턴을 멈추면 `claude -p`의 텍스트 출력이 이유를 알려주지 않던 경우가 있었는데, 수정**됐습니다.
- **자격 증명 이름을 가진 환경변수에 `1` 같은 스위치 값이 들어 있으면, 플러그인 MCP `headersHelper` 스크립트가 손상된 `CLAUDE_PLUGIN_ROOT`와 서버 URL을 받던 문제가 수정**됐습니다.
- **대화 일부가 저장되는 중에 `/clear`나 `/resume`을 실행하면 그 대화를 재개했을 때 계획(plan)이 복원되지 않던 희귀한 문제가 수정**됐습니다.
- **좁은 터미널에서 최초 실행 설정이 보안 안내와 터미널 설정 설명 중 일부 단어를 빠뜨리던 문제가 수정**됐습니다.
- **[Windows] rc 파일이 errexit·pipefail을 설정하고 winpty alias만 정의돼 있거나 전혀 없을 때, Git Bash에서 Bash 도구가 alias·함수를 잃어버리던 문제가 수정**됐습니다.
- **[Cloud sessions] Enterprise 구성원이 자신의 클라우드 환경에서 네트워크 secret을 직접 추가·삭제**할 수 있게 됐습니다. 지금까지는 보기만 가능했습니다.
