### Claude Haiku 5.5 출시 — Haiku 4.5 대비 평균 비용 75% 절감 (v2.1.293)

**Anthropic이 Claude Haiku 5.5(`claude-haiku-5-5`)를 공개하며 Anthropic API의 기본 Haiku 모델로 전환했습니다.** 요약, 문맥 압축, 데이터베이스 질의, 분류, 코딩 보조 에이전트처럼 대량으로 반복되는 작업에 최적화됐고, 프롬프트 10만 토큰 이하 구간에서는 100만 토큰당 입력 $0.10·출력 $0.50(10만 토큰 초과 구간은 입력 $0.50·출력 $2.50)로 Haiku 4.5보다 입출력 가격을 90% 인하했습니다. 이 덕분에 평균 실행 비용은 약 75% 줄었고, 컨텍스트는 100만 토큰까지 지원합니다. 컴퓨터 사용(OSWorld 2.1) 벤치마크에서 72.4%, 에이전트 코딩(Terminal-Bench 4.0)에서 39.2%를 기록했습니다. Max 5x·20x 플랜에는 월 100~200달러, Team 플랜에는 구성원이 함께 쓸 수 있는 월 최대 500달러의 Claude Platform 전체 모델용 API 크레딧이 함께 제공됩니다.

```bash
# Claude Code 세션의 모델을 Haiku 5.5로 전환
/model claude-haiku-5-5
```

**대량의 반복 작업—로그 요약, 데이터베이스 질의, 분류, 경량 코딩 보조 서브에이전트—을 돌리고 있다면, 기존 Haiku 4.5보다 훨씬 저렴해진 Haiku 5.5로 바꾸는 것만으로 비용을 크게 줄일 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases) · [GeekNews](https://news.hada.io/topic?id=34958)

### Codemode 패턴 — 도구 호출을 코드로 묶어 컨텍스트를 절약하기 (10/8)

**Codemode는 AI가 도구를 하나씩 호출하는 대신 여러 호출을 묶는 코드를 작성해 실행하는 방식으로, 반복·병렬 처리와 중간 결과 가공을 코드에 맡기고 필요한 결과만 모델에 전달해 컨텍스트 사용량을 크게 줄입니다.** Claude Code에도 이미 비슷한 메커니즘이 있는데, Workflow 도구는 `agent()`·`parallel()`·`pipeline()` 함수로 여러 서브에이전트 호출을 하나의 스크립트로 묶어 실행하고 최종 결과만 돌려줍니다.

```js
// 여러 서브에이전트 호출을 코드로 묶어 한 번에 실행
const results = await parallel([
  () => agent('파일 A의 버그를 점검'),
  () => agent('파일 B의 버그를 점검'),
])
```

**서브에이전트를 여러 번 순차 호출하며 중간 결과를 매번 컨텍스트에 그대로 쌓고 있었다면, 호출을 코드로 묶어 필요한 결과만 추려 받는 방식으로 바꿔보면 같은 작업도 더 적은 컨텍스트로 끝낼 수 있습니다.** [GeekNews](https://news.hada.io/topic?id=34952)

### 모드의 자주 쓰는 도구는 isDeferred: false로 바로 노출하기 (v2.1.293)

**모드(플러그인) 코드에서 `$.tool.register`에 `isDeferred: false`를 지정하면, 그 도구의 스키마가 처음부터 프롬프트에 실려 모델에 전달됩니다.** 별도 지정이 없으면 도구는 이름만 보이고, 모델이 스키마를 보려면 ToolSearch로 한 번 더 조회해야 하는 지연 로딩 상태로 남습니다.

```js
// 자주 쓰는 도구는 즉시 노출시켜 ToolSearch 왕복을 없앤다
$.tool.register('myFrequentTool', { isDeferred: false /* ... */ })
```

**매 턴마다 거의 반드시 호출되는 핵심 도구를 가진 모드를 만들고 있다면, 그 도구만 `isDeferred: false`로 지정해 모델이 ToolSearch를 거치지 않고 바로 스키마를 보게 하면 반복 호출의 지연과 토큰 낭비를 줄일 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
