## 주요 신규 기능 & 실전 활용

### Monitor 도구와 플러그인 모니터가 Bedrock·Vertex·Foundry 게이트웨이까지 확장됐습니다 (v2.1.310)

**Bedrock·Vertex·Foundry를 통해 Claude Code를 쓰거나 텔레메트리·비필수 트래픽을 꺼둔 세션에서도 Monitor 도구와 플러그인 모니터를 쓸 수 있게 됐고, 이런 환경에서도 긴 포그라운드 sleep은 똑같이 차단됩니다.** 지금까지는 이 게이트웨이들이나 텔레메트리를 끈 세션에서 플러그인 모니터와 긴 sleep 차단이 적용되지 않는 경우가 있었습니다.

**조직 정책으로 텔레메트리를 꺼두거나 Bedrock·Vertex·Foundry로 Claude Code를 운영하면서 플러그인 모니터 기반 관측을 포기하고 있었다면, v2.1.310부터는 그 환경에서도 동일하게 모니터링 범위를 넓힐 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Enterprise custom roles로 Cloud sessions·Remote Control 권한을 역할별로 통제할 수 있습니다 (v2.1.310)

**Claude Code cloud sessions와 Remote Control 권한이 Enterprise custom roles에 추가돼, Owner가 역할마다 이 두 기능에 대한 접근을 따로 제어할 수 있습니다.** 지금까지는 두 기능 모두 역할 기반으로 세분화된 접근 제어가 없었습니다.

**Enterprise 플랜에서 custom roles로 조직 권한을 관리하고 있다면, cloud sessions와 Remote Control을 특정 역할에만 열어주거나 차단하도록 지금 권한 매트릭스를 다시 점검해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### Linux에서 `/sandbox`가 Ubuntu AppArmor 제약을 이름까지 짚어 알려줍니다 (v2.1.310)

**Ubuntu의 AppArmor가 유저 네임스페이스를 제한해 bubblewrap이 샌드박스를 시작하지 못할 때, `/sandbox`와 샌드박스 시작 경고가 이제 그 제약의 이름과 해제 방법까지 함께 안내합니다.** 지금까지는 샌드박스가 왜 시작되지 않는지 원인을 직접 추적해야 하는 경우가 있었습니다.

**Ubuntu에서 Claude Code 샌드박스 모드를 쓰다 bubblewrap 시작 실패를 겪었다면, v2.1.310부터는 `/sandbox` 안내만으로 AppArmor 제약 해제 방법을 바로 확인할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### auto mode가 작업 디렉터리 밖 첫 읽기를 막기 전에 더 명확한 경고를 보여줍니다 (v2.1.310)

**auto mode가 작업 디렉터리 밖의 파일을 처음 읽기 전에 띄우는 프롬프트가, 그런 읽기를 막아두면 이후 셸 명령도 권한을 물을 수 있다는 점을 함께 알려주도록 개선됐습니다.** 지금까지는 이 프롬프트만 보고는 거부의 범위가 셸 명령까지 번질 수 있다는 걸 알기 어려웠습니다.

**auto mode로 무인 세션을 운영하면서 작업 디렉터리 밖 읽기를 막아두고 있다면, 이 경고를 참고해 셸 명령이 예기치 않게 권한을 묻기 시작할 가능성을 미리 감안해두는 것이 좋습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

- **배경 정리(background cleanup)가 `cleanupPeriodDays`를 매우 큰 값으로 설정했을 때 붙여넣은 이미지 같은 최근 파일까지 지워버리던 문제가 수정**됐습니다.

- **[Cloud sessions] 클라우드 환경 편집 다이얼로그에서 저장·보관이 실패해도 다이얼로그 안에 오류가 표시되지 않던 문제가 수정**됐습니다.
- **[Cloud sessions] 클라우드 환경의 설정 스크립트를 파일에서 불러오는 Choose file 버튼이 추가**됐습니다.
- **[Claude Tag] `!restart`·`!help` 같은 `!` 명령을 굵게·기울임·취소선으로 보내면 일반 메시지로 처리되던 문제가 수정**됐습니다.
