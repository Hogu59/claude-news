## 개발자 워크플로우 팁

### tmux 안에서 모드의 Image가 제대로 그려지려면 allow-passthrough·focus-events가 필요합니다 (v2.1.310)

**모드(mod)의 `Image`가 kitty, Ghostty, iTerm2 3.5+에서 풀스크린 렌더링을 지원하도록 개선됐지만, tmux 안에서는 `allow-passthrough`와 `focus-events`가 켜져 있어야 실제 이미지가 그려지고, 꺼져 있으면 `alt` 텍스트만 보입니다.**

```tmux
# ~/.tmux.conf
set -g allow-passthrough on
set -g focus-events on
```

**tmux 안에서 이미지를 보여주는 mod를 쓰다 글자만 보였다면, 위 두 옵션을 켜고 tmux를 재시작하는 것만으로 해결될 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 비대화형 세션에서 MCP 서버의 elicitation이 응답받지 못하고 타임아웃되면, 같은 호출을 반복하지 않습니다 (v2.1.310)

**`-p`나 Agent SDK 같은 비대화형 세션에서 MCP 도구 호출이 서버의 elicitation(사용자 확인) 요청에 대한 응답을 받지 못해 타임아웃되면, Claude Code가 이제 "응답이 오지 않았다"는 사실과 같은 호출을 다시 시도하지 말라는 설명을 함께 전달합니다.** 지금까지는 이런 상황에서 Claude가 같은 호출을 반복해 같은 타임아웃을 또 겪는 경우가 있었습니다.

**비대화형·Agent SDK 세션에서 elicitation을 요구하는 MCP 서버를 쓰고 있다면, 응답할 사람이 없는 환경에서는 그 서버의 elicitation 설정을 미리 끄거나 우회해두는 것이 안전합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 커스텀 게이트웨이가 특정 베타 헤더를 거부해도 Claude Code가 자동으로 재시도합니다 (v2.1.310)

**`effort-2025-11-24` 베타 값이나 대화 중간의 system 메시지를 거부하는 일부 게이트웨이·호환 서버 뒤에서 요청이 실패하던 문제가 수정돼, Claude Code가 이제 그 값들 없이 자동으로 재시도합니다.** 지금까지는 이런 게이트웨이 뒤에서 요청이 그냥 실패로 끝나는 경우가 있었습니다.

**`ANTHROPIC_BASE_URL`로 자체 게이트웨이나 호환 서버를 연결해 쓰다 특정 베타 헤더 때문에 요청이 실패하는 걸 겪었다면, v2.1.310 업그레이드만으로 수동 우회 설정 없이 해결될 가능성이 높습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### HTTP2Shell — Node2Shell로 시작된 Brotli 원격 코드 실행 취약점이 Python·Bun·Envoy·Istio까지 확산됐습니다 (10/25)

**Node.js에서 Node2Shell로 처음 알려진 Brotli 압축 해제 취약점(CVE-2026-111497)이 Python 패키지와 Bun, Envoy, Istio 등 여러 HTTP 라이브러리·애플리케이션에서도 같은 결함을 공유하고 있다는 사실이 확인됐습니다.** 공격자가 조작한 압축 데이터를 처리하면 메모리 유출과 프로세스 충돌, 원격 코드 실행으로 이어질 수 있으며, 서버가 직접 받는 요청뿐 아니라 외부에서 가져오는 응답을 처리하는 경로에도 영향이 미칠 수 있습니다.

**Claude Code로 Node.js·Python 기반 서비스를 다루거나 Envoy·Istio 같은 서비스 메시를 운영하고 있다면, PHP2Shell에 이어 또 다른 ‘2Shell’ 계열 취약점인 만큼 의존성 트리에 Brotli 압축 해제 라이브러리가 포함돼 있는지부터 점검해야 합니다.** [GeekNews](https://news.hada.io/topic?id=35927)
