### `/permissions`에 Auto Mode 탭이 추가됩니다 (v2.1.246)

**Auto mode 분류기 규칙을 보고 편집할 수 있는 전용 탭**이 `/permissions`에 추가됐습니다.

```bash
/permissions
# Auto Mode 탭으로 이동해 자동 승인 분류기 규칙을 확인·편집
```

**Auto mode로 반복 작업을 자동 승인시켜 왔다면, 지금까지는 규칙이 어떻게 적용되고 있는지 한눈에 보기 어려웠습니다.** 이번 탭으로 **어떤 규칙이 자동 승인을 유발하는지 직접 들여다보고 조정**할 수 있습니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### key-amnesia — AI 에이전트에 시크릿을 노출하지 않고 명령을 실행합니다 (8/26)

**`.env`를 `.gitignore`에 넣는 방식은 비밀값이 Git에 커밋되는 것은 막지만, 로컬 프로젝트에 평문으로 남아 있는 값을 에이전트가 그대로 읽어버리는 것까지는 막지 못한다는 문제의식**에서 나온 CLI 도구입니다. **위협의 범위가 Git 저장소를 넘어, 프로젝트 파일과 명령 실행 환경에 접근하는 AI 에이전트 자체로 옮겨갔다는 게 핵심 전제**입니다.

**Claude Code에 프로젝트 디렉터리 접근 권한을 넘기기 전에, `.env`나 셸 히스토리 같은 평문 자격증명을 애초에 에이전트의 실행 환경에서 격리하는 습관을 들일 만합니다.** [GeekNews](https://news.hada.io/topic?id=32893)

### `/cd`로 이동한 새 디렉터리의 설정이 턴이 끝나기 전에 즉시 적용됩니다 (v2.1.246)

```bash
/cd ../other-project
# 이전에는 --resume 이후에나 반영되던 프로젝트 설정·훅·.mcp.json 서버(승인 프롬프트 포함)·
# 스킬·에이전트가 이동 직후 바로 적용됩니다
```

**여러 프로젝트를 오가며 `/cd`로 컨텍스트를 전환하는 워크플로라면, 세션을 다시 시작하지 않아도 새 프로젝트의 `CLAUDE.md` 규칙과 훅이 바로 걸린다는 점**이 실무에서 체감될 만합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 서브에이전트가 `maxTurns`에 도달해도 결과가 사라지지 않고 이어갈 수 있습니다 (v2.1.246)

**`maxTurns` 한도에 걸려 멈춘 서브에이전트의 결과가 이제 완료로 보이는 대신 partial로 표시**되며, **`SendMessage`로 이어가라는 힌트가 함께 붙습니다.**

**동적 워크플로에서 여러 서브에이전트를 굴리는 팀이라면, 턴 제한에 걸린 서브에이전트를 처음부터 다시 실행하는 대신 `SendMessage`로 그 자리에서 이어서 진행할 수 있다는 점을 참고할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

- **매우 긴 단일 줄(예: base64 문자열)이 포함된 diff에서 트랜스크립트가 심각하게 느려지던 문제가 수정**되고, 이런 줄은 이제 잘려서 표시됩니다

- **MCP 도구 인자가 파라미터 스키마가 빈 `{}`일 때 JSON 문자열로 잘못 전송되던 문제가 실제 타입으로 수정**됩니다
