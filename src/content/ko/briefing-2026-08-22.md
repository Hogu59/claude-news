## 주요 신규 기능 & 실전 활용

### Computer Use·Browser Use Tool·Skills API·Files API가 정식 출시됩니다 (8/20)

**Anthropic이 Claude Platform에서 베타로 운영해 온 Computer Use, 그리고 새로 추가된 Browser Use Tool, Skills API, Files API를 나란히 정식 출시(GA)**했습니다. **Computer Use는 이제 한 번의 턴에서 여러 액션을 처리**할 수 있어 **작업 완료 시간과 비용이 약 30% 줄어들며**, **규제 산업을 위한 BAA 하에서 HIPAA 적용도 가능**합니다. **Browser Use Tool은 스크린샷 기반 상호작용에 페이지 구조 분석을 더해**, 픽셀 좌표만으로 요소를 찾던 방식보다 웹 요소를 더 안정적으로 조준합니다. **Skills API는 버전이 매겨진 지침 폴더를 업로드해 Claude의 샌드박스에서 실행**하는 방식이고, **Files API는 조직당 1TB 저장 공간과 자동 만료, 기존 대비 5배 높은 레이트 리밋**을 제공합니다.

**실무로 옮기면**: Files API에서 파일을 읽고, Skills로 정의된 절차를 실행하고, 브라우저·컴퓨터 유즈 도구로 웹 작업을 자동화한 뒤 결과를 다시 파일로 저장하는 흐름을, **별도 셀프호스티드 인프라 없이 Claude Platform 하나로 엮을 수 있다**는 것이 핵심입니다. 세 기능 모두 **Microsoft Foundry에서도 제공되며 Google Cloud Vertex AI 지원은 준비 중**입니다. Claude API 위에서 파일 업로드·브라우저 자동화 파이프라인을 직접 구축해 왔다면, 이번 GA로 **베타 헤더 없이 안정된 엔드포인트를 그대로 쓸 수 있다는 점**을 확인해 볼 만합니다. [출처](https://claude.com/blog/computer-use-skills-api-files-api)

**Anthropic이 직원 교육에 써 온 방식을 그대로 외부에 공개한 무료 학습 허브 Claude Academy를 오픈**했습니다. **Claude 101 같은 입문 과정부터 Claude API·Claude Code로 에이전트를 만드는 기술 심화 과정까지**를 다루며, **개발자·학생·교육자·비영리단체별로 트랙이 나뉘어 있습니다.**

**팀에 Claude Code를 새로 도입하는 온보딩 자료가 마땅치 않았다면, Claude Code 101 같은 공식 커리큘럼을 그대로 활용**할 수 있습니다. [Claude Academy](https://academy.claude.com/)

### `/claude-api upgrade` — Python 프로젝트를 anthropic 1.x로 옮깁니다 (v2.1.239)

```bash
# claude-api 스킬로 Python 프로젝트의 anthropic 0.x 의존성을 1.x로 마이그레이션
/claude-api upgrade
```

**`claude-api` 스킬에 Python 프로젝트를 `anthropic` 0.x에서 1.x로 마이그레이션하는 명령이 추가**됐고, **스킬의 Python 참조 문서도 1.x 기준으로 갱신**됐습니다(예: 타임아웃은 이제 `httpx.Timeout`이 아니라 `anthropic.Timeout`을 씁니다).

**`anthropic` SDK 1.x로의 업그레이드를 미뤄 온 프로젝트가 있다면, 이 명령으로 변경이 필요한 지점을 자동으로 찾아 고치는 첫걸음을 뗄 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.239** 항목입니다.

- **Windows에서도 크로스세션 메시징이 지원**됩니다 — macOS·Linux처럼 여러 머신의 Claude Code 세션이 `SendMessage`로 서로 메시지를 보내고 `ListAgents`로 서로를 찾을 수 있습니다.
- **`ListAgents`가 세션 자신의 이름(다른 세션이 메시지를 보낼 때 쓰는 이름)을 알려주며**, 자기 이름으로 `SendMessage`를 보내면 "no agent named …" 대신 이를 알려줍니다.
- **`ListAgents`·`/list-agents`가 이제 살아 있는 팀메이트도 함께 표시**합니다 — 지금까지는 서브에이전트와 다른 세션만 보이고, 접근 가능한 팀메이트가 목록에서 빠져 있었습니다.
- **`keybindingFlavor: "readline"`이 단어 단위 이동·삭제 키에도 적용**됩니다 — Alt+F와 Ctrl/Option+→가 단어 끝에서 멈추고, Alt+D가 단어를 삭제하며(Ctrl+Y로 되돌리기 가능) 구두점이 단어 경계로 취급됩니다.
- **Alpine/musl 빌드에서 네이티브 이미지 붙여넣기·클립보드·오디오 캡처 애드온이 정상 로드**됩니다 — glibc용 바이너리를 musl 런타임이 거부하던 문제가 musl 빌드 바이너리로 해결됐습니다.
- **월간 지출 한도를 이미 다 쓴 상태에서 뜨는 사용량 한도 메시지가, 세션·주간 한도가 언제 재설정되는지도 함께 알려줍니다.**
- **Bedrock·Vertex·Foundry 등 그동안 제외됐던 환경에도 1회성 풀스크린 렌더러 안내가 추가**됐습니다 — 이런 환경의 신규 설치는 이제 풀스크린으로 시작합니다.
- **Claude in Chrome에서 `/clear`가 세션의 Chrome 탭 그룹을 닫으며**, 빈 탭 그룹은 `/resume` 시점과 Claude Code 종료 시점에도 정리됩니다.
- **모바일에서 업로드한 이미지에 저장된 파일 경로가 함께 포함**돼, Claude가 이를 새로 만드는 파일에 그대로 복사해 넣을 수 있습니다.
- **[VSCode] 사용량 한도 배너의 "View usage" 링크가 배너 중간에 떠 있는 대신 경고 텍스트와 나란히 인라인으로 배치**됩니다.
