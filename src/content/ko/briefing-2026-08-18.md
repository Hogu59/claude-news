## 주요 신규 기능 & 실전 활용

### 사용량 한도가 재설정되면 세션을 자동으로 이어갑니다 (v2.1.234)

**claude.ai 사용량 한도에 걸려 멈췄던 세션이, 한도가 재설정되는 시점에 자동으로 이어서 진행**됩니다. **`/config`의 "Continue automatically at usage limit" 항목에서 끌 수 있습니다.**

**지금까지는 한도에 걸리면 세션이 멈춘 채로 재설정 시각까지 기다렸다가 사람이 직접 다시 지시를 내려야 했습니다.** 이번 변경으로 **긴 작업을 밤새 돌려두거나 한도 재설정을 기다리는 동안 자리를 비워도, 재설정과 동시에 작업이 이어서 진행**됩니다. 다만 **의도치 않게 재개되는 걸 원치 않는다면 `/config`에서 꺼 두는 편**이 안전합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `CLAUDE_CODE_PROJECT_DIR_NAME` — 세션별 트랜스크립트 디렉터리에 짧은 이름을 붙입니다 (v2.1.234)

```bash
# 세션마다 별도 설정 디렉터리를 쓰는 호스트에서, 프로젝트별 트랜스크립트 디렉터리 이름을 지정합니다
export CLAUDE_CODE_PROJECT_DIR_NAME=my-project
```

**세션마다 자체 설정 디렉터리를 두는 호스팅 환경에서, 프로젝트별 트랜스크립트 디렉터리에 짧고 알아보기 쉬운 이름을 직접 지정**할 수 있게 됐습니다. **여러 프로젝트의 세션을 한 호스트에서 동시에 돌리는 셀프호스티드·CI 환경이라면, 자동 생성되는 긴 해시 대신 알아보기 쉬운 이름으로 디렉터리를 관리**할 수 있습니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### GitLab MR 배지가 풋터·상태줄에 표시됩니다 (v2.1.234)

**GitLab 리모트가 있고 인증된 `glab` CLI가 설치된 저장소**라면, **풋터와 상태줄에 merge request가 `!N` 형태로 표시**되며 **draft·pending·green 등 상태**도 함께 보입니다. 8/13~8/15 브리핑이 다룬 **GitLab 전면 지원(시크릿 리댁션·마켓플레이스 클론)과 `--worktree` MR 지원**에 이어, **GitHub의 PR 배지와 동등한 수준으로 GitLab 지원이 계속 채워지고 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### `claude-api` 스킬의 컨텍스트 비용이 약 8배 줄었습니다 — 200k에서 25k 토큰으로 (v2.1.234)

**내장 `claude-api` 스킬을 불러올 때 드는 컨텍스트 비용이 기존 약 200k+ 토큰에서 약 25k 토큰으로 줄었습니다.** **참조 문서를 필요할 때만 온디맨드로 불러오는 방식**으로 바뀐 덕분입니다.

**Claude API 관련 작업을 위해 이 스킬을 자주 불러 쓰고 있었다면, 세션 초반에 컨텍스트를 크게 잡아먹던 부담이 눈에 띄게 줄어듭니다.** 다른 스킬이나 CLAUDE.md 컨텍스트와 함께 쓸 여유가 그만큼 늘어난다는 뜻이기도 합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `/goal`이 30분 넘게 기다리는 백그라운드 작업을 먼저 확인합니다 (v2.1.234)

```bash
# 백그라운드 작업 체크인을 끄려면
export CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0
```

**`/goal`로 목표를 걸어 두었는데 백그라운드 작업이 30분 이상 끝나지 않으면, Claude가 무작정 기다리는 대신 먼저 상황을 확인**합니다. 8/16 브리핑이 다룬 **루프 엔지니어링 칼럼**이 짚었던 **"완료 조건과 어떤 판단을 계속 사람이 맡을지 미리 정의해야 한다"는 원칙**이, 이번엔 **오래 걸리는 백그라운드 작업을 무한정 기다리지 않는 형태**로 반영됐습니다. **`/goal`을 CI나 장기 실행 파이프라인에 걸어 두는 워크플로라면, 이 체크인 덕분에 걸려 있는 작업을 더 빨리 알아챌 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `/permissions`·`/add-dir` 등 다이얼로그가 작업 중에도 바로 열립니다 (v2.1.234)

**`/permissions`가 Claude가 작업하는 도중에도 열리며, 여기서 바꾼 규칙은 현재 턴에도 바로 적용**됩니다. **`/add-dir`도 작업 중 사용 가능**해졌고, **`/autocompact`·`/theme`·`/help`·`/config`·`/advisor` 다이얼로그가 풀스크린 TUI에서 턴 중간에 열립니다.**

**지금까지는 이런 설정을 바꾸려면 턴이 끝날 때까지 기다려야 하는 경우가 많았는데, 긴 작업이 진행되는 도중에 권한 규칙을 조정하고 싶을 때 바로 반영**할 수 있게 됐습니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 권한 프리뷰·MCP 진단의 자격증명 마스킹이 강화됩니다 (v2.1.234)

**MCP 진단이 더 이상 해석된 시크릿 값을 출력하지 않습니다** — 스코프 충돌 경고는 이제 설정된 `${VAR}` 형태로만 보여주고, 연결 실패 상세는 서버 origin만 표시합니다. **채널 서버로 중계되는 권한 프리뷰는 인바운드 신뢰 게이트가 허용한 서버에만 전달**되며, **크기가 큰 private key 블록도 강한 리댁션 아래서 마스킹**됩니다. **셸 구분자가 바로 뒤에 붙은 프로바이더 API 토큰도 이제 마스킹**됩니다.

**여러 서버·채널을 넘나드는 팀 환경에서 권한 요청을 검토·중계하는 흐름이 있다면, 이번 강화로 자격증명이 실수로 노출될 여지가 한층 줄어듭니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.234** 항목입니다.

- **계정 이메일은 이제 사용자 식별용으로만 쓰이며, 요청하지 않는 한 무관한 서비스로 전송되지 않습니다.**
- **`selection:clear` 키바인딩 액션**이 추가돼, 앱 내 텍스트 선택을 지우는 동작을 키 하나에 바인딩할 수 있습니다(에이전트 뷰에서도 동작).
- **자동 생성되는 세션 제목**이 요청 문장을 그대로 반복하는 대신("모바일에서 로그인 버튼 고치기") **짧고 구체적인 이름**("로그인 버튼 버그")으로 바뀌었습니다.
- **`claude setup-token`이 예상치 못한 추가 인자를 조용히 무시하지 않고 거부**합니다.
- **풀스크린 모드에서 Esc가 마우스 텍스트 선택을 더 이상 지우지 않습니다** — 인터럽트·닫기 동작은 그대로 유지되고 선택 영역은 강조 표시된 채 남습니다.
- **auto mode classifier가 모든 Agent 도구 호출 아래 표시하던 "Allowed by auto mode classifier" 문구가 제거**됐습니다.
- **`/config`의 "Default teammate model" 설정이 제거**됐습니다 — 이제 에이전트 팀 팀메이트는 스폰 시 지정하지 않으면 리더의 모델을 그대로 씁니다.
- **Windows에서 `~/.claude.json`이 읽기 전용일 때 시작이 반복 이름변경 재시도로 멈추던 문제**가 수정됐습니다.
