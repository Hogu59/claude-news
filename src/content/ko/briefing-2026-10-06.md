## 주요 신규 기능 & 실전 활용

### WebSearch 예산이 시간당 자동으로 리필되는 방식으로 바뀌었습니다 (v2.1.290)

**기존에는 대화형 세션의 WebSearch 호출이 200회를 쓰면 그대로 끝났지만, 이제는 시간당 100회씩 자동으로 다시 채워지는 방식으로 바뀌었습니다.** 리필 속도는 환경변수로 조정하거나 완전히 끌 수 있습니다.

```bash
# 시간당 리필 속도를 조정 (기본값 100)
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=50

# 리필을 끄고 기존처럼 한도에서 끝내려면
export CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR=0
```

**장시간 이어지는 리서치 세션에서 WebSearch를 자주 쓰다가 200회 한도에 걸려 세션을 새로 시작해야 했던 경험이 있다면, 이제는 그런 중단 없이 계속 이어갈 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### `/claude-api managed-agents-onboard`로 Managed Agents 패턴을 즉시 부트스트랩하기 (v2.1.290)

**Managed Agents 패턴을 Console 페이지가 `ant apply` 파일로 설명하는 그대로 설정해주는 서브커맨드가 추가됐습니다.** URL을 주면 그 페이지의 설정을 그대로 적용하고, `deep-researcher` 같은 quickstart 이름을 주면 `ant` CLI로 Console 퀵스타트 템플릿을 바로 구성합니다.

```bash
# Console 페이지가 설명하는 ant apply 파일로 설정
/claude-api managed-agents-onboard <url>

# 빌트인 quickstart 템플릿으로 바로 시작
/claude-api managed-agents-onboard deep-researcher
```

**조직에 Managed Agents를 도입할 때 문서를 보며 파일을 하나씩 손으로 맞추는 대신, 이 명령 한 번으로 표준 구성을 받아 거기서부터 커스터마이즈를 시작할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### MCPB로 로컬 MCP 서버를 Claude Desktop 원클릭 확장으로 패키징하기 (Anthropic 공식문서, 10/5)

**MCPB(.mcpb)는 로컬 MCP 서버와 `manifest.json`을 담은 zip 파일 하나로, Claude Desktop이 브라우저 확장처럼 설치하게 해주는 패키징 방식입니다.** 설치는 파일 더블클릭, Claude Desktop 창에 드래그, 또는 Settings → Extensions → Advanced settings → Install Extension 중 편한 방법을 쓰면 됩니다.

**사내에서 만든 MCP 서버를 동료에게 나눠줄 때 설치 스크립트나 설정 안내문을 따로 쓰는 대신, zip 파일 하나를 공유하는 것만으로 설치를 끝낼 수 있습니다.** [GeekNews](https://news.hada.io/topic?id=34822)

## 생태계 & 플러그인

### Cloudflare, AI 에이전트를 위한 Web Search API 베타를 공개했습니다 (10/6)

**Cloudflare가 AI 에이전트와 애플리케이션이 인터넷을 검색해 실시간 정보를 근거로 응답할 수 있게 해주는 Web Search API를 베타로 공개했습니다.** 출시 시점에는 Ceramic.ai, Exa, Linkup 세 검색 제공업체 중에서 고를 수 있으며, 모두 Cloudflare를 통해 라우팅됩니다.

**Claude Code 에이전트 파이프라인에 검색 기능을 자체 인프라로 가져오고 싶은 팀이라면, WebSearch 기본 도구 대신 이런 서드파티 검색 API를 라우팅·캐싱 계층에 끼워 넣는 선택지로 검토해볼 만합니다.** [GeekNews](https://news.hada.io/topic?id=34826)

### Claude Tag(Slack), `!fast`로 스레드를 즉석에서 Fast 모드로 전환합니다 (v2.1.290)

**Slack에서 Claude를 멘션할 때 `!fast`를 붙이면 해당 스레드가 필요 시 Opus로 전환되는 fast 모드로 바뀌고, 응답에는 "(fast)" 표시가 붙습니다. `!fast off`로 원래 모드로 되돌릴 수 있습니다.** 같은 릴리스에서 access bundle의 커스텀 연결에 Path prefixes 필드도 추가돼, 허용 규칙을 호스트 전체가 아닌 특정 경로로 좁힐 수 있게 됐습니다.

**Slack에서 Claude Tag로 협업하는 팀이라면, 평소에는 비용이 낮은 모델로 스레드를 운영하다가 복잡한 질문이 나올 때만 `!fast`로 격상시키는 식으로 비용과 응답 품질을 상황에 맞게 조절할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.290**(10/5) 항목입니다.

- **Claude 앱 게이트웨이의 로그인 승인 페이지에 Deny 버튼이 추가**돼, 대기 중인 로그인을 즉시 종료하고 기다리는 터미널이 몇 초 안에 멈추게 됩니다.
- **`claude plugin validate --json`에 `gatingHooks` 필드가 추가**돼, 모드가 등록한 각 게이팅 훅에 `.catch`가 있는지 바로 확인할 수 있습니다.
- **Bash 도구가 더 이상 `pyright`를 읽기 전용 명령으로 취급하지 않아**, 실행 전에 권한을 묻습니다.
- **`/code-review` 보통(medium) 강도가 Opus 5.5·Sonnet 5.5 등 튜닝되지 않은 모델에서도 정리·CLAUDE.md 컨벤션 발견 사항을 함께 보고**하도록 바뀌었습니다.
- **Claude in Chrome의 `browser_batch` 호출 제한 시간이 60초에서 90초로 늘었습니다.**
- **WebFetch가 100,000자를 넘는 페이지 텍스트를 조용히 버리던 문제가 수정**돼, 얼마나 못 읽었는지 알려주고 `offset`으로 이어서 읽을 수 있게 됐습니다.
