## 개발자 워크플로우 팁

### 반복된 자동 압축 실패로 "Prompt is too long"이 뜨던 문제가 수정됐습니다 (v2.1.332)

**지금까지는 자동 압축이 여러 번 실패하면, 컨텍스트 한도에서 압축을 한 번 더 시도했더라면 이어갈 수 있었던 턴도 그냥 "Prompt is too long"으로 끝나버렸는데, 이번 릴리스부터는 그 상황에서 압축을 한 번 더 시도하도록 고쳐졌습니다.** 같은 릴리스에서 압축 요약이 출력 한도를 넘겨 계속 잘릴 때도, 세 번 잘린 뒤 마지막 시도에서는 더 짧은 요약을 요청하도록 바뀌었습니다.

```text
긴 대화에서 자동 압축이 거듭 실패하는 상황
  → (이전) "Prompt is too long"으로 턴이 그냥 끝남
  → (v2.1.332부터) 한도에서 압축을 한 번 더 시도해 이어감
```

**컨텍스트를 꽉 채운 긴 세션에서 압축 실패로 작업이 갑자기 끝났던 경험이 있었다면, v2.1.332 업그레이드 이후에는 그런 상황에서 압축이 한 번 더 시도된다는 점을 염두에 두고 긴 세션을 계속 이어가 볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 읽기 한도를 넘는 큰 파일을 @-mention하면 Claude가 파일 크기와 읽는 방법을 안내받습니다 (v2.1.332)

**지금까지는 확장자가 있는 텍스트 파일을 @-mention했을 때 첫 2,000줄만으로도 읽기 한도를 넘으면 파일이 조용히 통째로 빠져버려 Claude가 그 파일이 있었다는 사실조차 몰랐는데, 이번 릴리스부터는 Claude가 파일 크기와 나머지를 읽는 방법을 안내받습니다.**

```text
@large-log.txt (2,000줄 넘는 대용량 로그)
  → (이전) 파일이 조용히 빠짐, Claude는 존재 자체를 모름
  → (v2.1.332부터) Claude가 파일 크기와 나머지를 읽는 방법을 안내받음
```

**대용량 로그나 데이터 파일을 @-mention해도 아무 반응이 없었던 경험이 있었다면, v2.1.332부터는 Claude가 그 파일의 존재와 크기를 알게 되니 Grep이나 offset으로 필요한 부분만 짚어 읽어달라고 이어서 요청해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### PreToolUse 훅이 거부한 이유가 Read·Grep·Glob·Edit·Write 승인 창에도 표시됩니다 (v2.1.332)

**지금까지 PreToolUse 훅이 승인을 요구하며 적어둔 이유(reason)가 Bash 명령 승인 창에는 보였지만 Read·Grep·Glob·Edit·Write 승인 창에는 표시되지 않았는데, 이번 릴리스부터 이 다섯 가지 도구의 승인 창에도 훅이 적어둔 이유가 함께 표시됩니다.** (anthropics/claude-code#102892, anthropics/claude-code#105343)

```json
{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Read", "hooks": [{ "type": "command", "command": "check-sensitive-path.sh" }] }
    ]
  }
}
```

**PreToolUse 훅으로 민감한 경로의 Read·Edit을 막으면서 이유를 적어둬도 Bash 외의 도구에서는 왜 막혔는지 보이지 않아 혼란스러웠다면, v2.1.332부터는 다섯 가지 도구 모두에서 훅이 적어둔 이유를 그대로 확인할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.332**(11/25) 항목 중 11/26·11/27 브리핑과 위에서 다루지 않은 것들입니다.

- **시작 헤더에 Cyber Verification Program 등급이 표시**됩니다. claude.ai 계정으로 로그인했고 그 등급이 현재 모델에 적용될 때 모델 이름 옆에 함께 나타납니다.
- **다른 세션에서 온 메시지에 지금 세션이 다른 모델로 넘어가 있을 때, 모델을 직접 고르기 전까지 그 사실을 알려주는 꼬리말 줄이 추가**됐습니다.
- **`/schedule`·권한 프롬프트·`/loop`의 클라우드 제안이 "routine"이나 "cloud schedule" 대신 "cloud scheduled task"라고 표현**하도록 바뀌었습니다. `/routines` 명령어 자체는 그대로 동작합니다.
- **macOS에서 컴퓨터 사용이 켜져 있을 때 `computer-use`가 예약된 skill 이름**이 됩니다. 같은 이름의 스킬이나 명령어는 더 이상 로드되지 않으며, 시작 시 이름을 바꾸라는 안내가 뜹니다.
- **`--model default`나 Default 선택이 해당 모델을 쓸 수 없을 때 오류로 멈추는 대신 이전 모델로 넘어가도록 바뀌었습니다** (auto 모드에서는 auto 모드가 허용하는 모델로만 넘어감).
