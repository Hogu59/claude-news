## 주요 신규 기능 & 실전 활용

### Auto 모드 classifier, 서버 사이드가 다시 기본값이 됩니다 — 오버헤드 과금 사라짐 (v2.1.278)

**Claude API·Enterprise 사용자와 Bedrock·Vertex·Foundry·게이트웨이 환경 전반에서, auto 모드 classifier가 서버 사이드 실행을 기본값으로 쓰도록 바뀌었습니다.** **서버 사이드 classifier는 별도의 오버헤드 과금이 없으며, 과금이 발생하는 방식으로 폴백될 때는 경고가 표시됩니다.**

```bash
# Bedrock, Vertex, Foundry, 게이트웨이 환경에서 서버 사이드 classifier를 끄고 이전처럼 로컬 classifier를 씁니다
export CLAUDE_CODE_AUTO_MODE_SERVER=0
```

**`/status`에 이번 세션의 auto 모드 classifier가 서버에서 실행 중인지 보여주는 `Auto mode server` 행이 새로 추가됩니다. 9/15 브리핑에서 다룬 것처럼 Bedrock·Vertex·Foundry는 한동안 로컬 classifier를 기본으로 써왔는데, 이번 변경으로 다시 서버 사이드가 기본이 되면서 과금 구조까지 명확해졌습니다.** [문서](https://code.claude.com/docs/en/auto-mode-classifier-billing) · [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
