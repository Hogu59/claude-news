**`claude-fable-5-2`가 새 기본 Fable 모델로 추가됐습니다.** 100만 토큰 컨텍스트를 지원하며 가격은 입력 100만 토큰당 8달러, 출력 100만 토큰당 40달러, 캐시 읍기는 100만 토큰당 0.20달러입니다. 같은 날 GeekNews에 올라온 Artificial Analysis 벤치마크에 따르면, Max 설정의 Fable 5.2는 Intelligence Index에서 65점을 받아 비슷한 가격대 모델 중앙값(40점)을 크게 웃돌았습니다. 다만 그 대가도 뚜렷해서, 작업당 처리 시간은 44.1분(비교 모델 중앙값 12.9분), 첫 답변 토큰까지 걸리는 시간은 231.55초(비교 모델 중앙값 13.07초), 작업당 평균 비용은 26.54달러로 비교 모델보다 훨씬 오래 걸리고 비쌉니다.

```bash

/model claude-fable-5-1
```

**Fable 모델로 깊은 추론이 필요한 작업을 맡기고 있다면, v2.1.321부터는 기본값이 Fable 5.2로 바뀌어 지능 점수는 크게 오르지만 응답을 기다리는 시간과 비용도 함께 늘어난다는 점을 감안해 작업 성격에 맞게 모델을 골라야 합니다.** [GeekNews](https://news.hada.io/topic?id=36910) · [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `claude remote-control`에 `--settings <file>` 옵션이 추가돼 세션마다 설정 파일을 적용할 수 있습니다 (v2.1.321)

**이 옵션으로 지정한 설정 파일이 `claude remote-control`이 띄우는 모든 세션에 적용되며, 파일이 바뀌어도 `claude remote-control`을 재시작하기 전까지는 새 세션에 반영되지 않습니다.**

```bash
claude remote-control --settings ./remote-settings.json
```

**원격으로 여러 세션을 띄워 운영하면서 세션마다 같은 설정을 일일이 다시 지정해야 했다면, 이 옵션으로 설정 파일 하나를 모든 세션에 일관되게 적용할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**조직 밖에서 받은 MCP 서버나 커스텀 OAuth를 쓰는 서버를 연결해 쓰고 있다면, v2.1.321로 올려 이 경로로 토큰이 새 나가지 않는 버전을 쓰고 있는지 확인할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 읽기 전용 Bash 명령이 샌드박스 밖에서 권한 프롬프트 없이 실행되던 결함이 수정됐습니다 (v2.1.321)

**특정 상황에서 읽기 전용으로 분류된 Bash 명령이 샌드박스를 벗어나 실행되면서도 권한을 묻지 않던 결함이 수정됐습니다.** 샌드박스는 Claude Code가 승인 없이 실행하는 명령의 영향 범위를 제한하는 핵심 안전장치이므로, 읽기 전용이라는 분류를 믿고 프롬프트 없이 넘어가던 경로가 있었다는 점에서 비중 있는 수정입니다. 같은 버전에서 Bash 권한 검사가 잘못된 폴더의 파일 쓰기를 판단해 프롬프트를 띄우지 않던 문제, `cp`·`mv`로 디렉터리에 쓰는 파일에는 deny 규칙과 보호 파일 프롬프트가 적용되지 않던 문제도 함께 고쳐졌습니다.

**샌드박스 모드로 Claude Code를 운영하고 있다면, v2.1.321로 올려 읽기 전용 명령·`cp`·`mv` 관련 권한 검사가 모두 의도대로 동작하는 버전을 쓰고 있는지 확인할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.321**(11/9) 항목입니다.

- **Claude가 세션에서 만든 mod가 auto mode·bypass mode에서는 확인 없이 자동으로 켜지도록 바뀌었습니다.** 관리형 `allowUnsandboxedCommands: false`나 `allowManagedDomainsOnly`가 설정돼 있어도 동일하게 적용되며, `dontAsk` 모드에서는 로드되지 않습니다.
- **mod 자체의 도구 호출(`$.tool.call`, `$.mcp.call`)이 더 이상 권한 프롬프트를 띄우지 않도록 바뀌었습니다.** 사용자가 직접 설정한 ask 규칙이나 `dontAsk`·`-p` 실행에서도 동일하며, deny 규칙과 조직 정책은 그대로 적용됩니다.
- **컨텍스트 사용량 추정치가 정확한 토큰 수를 알 수 없을 때 도구 정의를 과하게 집계하던 문제가 수정**됐습니다.
- **Remote Control의 웹·모바일 화면에서 `/compact`가 두 번 표시되던 문제가 수정**됐습니다.
- **플러그인 자동 업데이트와 `/plugin` 마켓플레이스 업데이트가 저장소의 워크트리나 폴더마다 같은 플러그인을 중복으로 다시 내려받던 문제가 수정**됐습니다.
- **WebFetch가 페이지를 읅는 모델이 텍스트를 돌려주지 않을 때 "응답 없음"을 페이지 내용인 것처럼 Claude에게 전달하던 문제가 수정**돼, 이제 명확한 오류로 실패합니다.
