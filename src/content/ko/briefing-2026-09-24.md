## 주요 신규 기능 & 실전 활용

### `"attribution": false` — 커밋·PR 어트리뷰션을 통째로 숨깁니다 (v2.1.281)

**`settings.json`에 `"attribution": false`를 추가하면 모든 커밋과 PR의 어트리뷰션 문구가 표시되지 않습니다.** **다만 구버전 CLI는 이 값이 담긴 설정 파일 전체를 건너뛰므로, 여러 버전이 함께 쓰이는 환경에서 공유하는 설정 파일이라면 boolean 대신 기존 object 형태를 유지해야 합니다.**

```json
{
  "attribution": false
}
```

**사내 정책상 커밋 메시지에 AI 도구 표시를 넣지 않기로 한 팀이라면, 커밋마다 개별 안내 없이 이 설정 하나로 조직 전체에 일괄 적용할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Auto 모드 서버사이드 classifier, 적용 범위가 다이렉트 API 연결과 read-only 명령까지 넓어집니다 (v2.1.281)

**`CLAUDE_CODE_AUTO_MODE_SERVER`가 이제 다이렉트 Anthropic API 연결에도 적용되어, `0`은 서버사이드 classifier를 옵트아웃하고(이 경우 로컬 classifier가 사용량에 포함), `1`은 옵트인합니다.** **서버사이드 classifier가 도는 세션에서는 read-only·sandboxed shell 명령도 이제 리뷰 대상이 되며, classifier가 문제로 표시하면 실행이 차단됩니다.**

```bash
# 다이렉트 Anthropic API 연결에서 서버사이드 auto 모드 classifier를 명시적으로 켜기
export CLAUDE_CODE_AUTO_MODE_SERVER=1
```

**9/19 v2.1.278에서 Bedrock·Vertex·Foundry·게이트웨이 환경에 서버사이드 classifier가 기본값이 된 데 이어, 이번엔 다이렉트 API 연결과 read-only 명령까지 검토 범위가 넓어졌습니다. Auto 모드로 자동화 파이프라인을 돌리고 있다면, 안전하다고 여겼던 조회성 명령도 이제 classifier 판단을 기다릴 수 있다는 점을 감안해야 합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.281**(9/23) 항목입니다.

- **Claude 앱 게이트웨이의 Bedrock 업스트림에 `assume_role`이 추가**돼, 게이트웨이가 STS로 역할을 가정해 다른 AWS 계정의 Bedrock을 호출할 수 있고, 개발자별로 세션을 분리하는 것도 가능합니다.
- **Bedrock 업스트림에 `guardrail: {id, version}`을 지정하면 해당 업스트림을 거치는 모든 요청에 Amazon Bedrock 가드레일이 적용**됩니다.
- **MCP URL-mode elicitation이 추가**돼, 서버가 브라우저 기반 인증 플로우를 열도록 요청할 수 있고, 서버가 완료 확인 방법이 없을 때는 대기 다이얼로그가 화면에 남지 않습니다.
- **`claude plugin validate`가 MCP 서버까지 검사**해, 로드 시 조용히 누락될 `.mcp.json` 항목, 선언되지 않은 `${user_config.*}` 참조, 안전하지 않은 URL을 보고합니다.
- **위험한 `rm` 명령 프롬프트가 이제 2분간 응답을 기다린 뒤 재작성 힌트와 함께 명령을 거부**해, 무인 실행 세션도 멈추지 않고 이어질 수 있습니다(`CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT=1`로 끌 수 있음).
- **세션 아티팩트 링크가 프롬프트 아래 하나의 footer pill로 통합**되고, 여기서 여는 `/artifacts`는 현재 세션의 아티팩트를 목록 맨 위에 표시합니다.
- **자체 호스팅 러너에서 시스템 프롬프트를 커맨드라인 텍스트 대신 비공개 파일로 전달**하도록 바뀌어, 큰 프롬프트로 인한 실행 실패가 사라집니다. `--system-prompt`나 `--append-system-prompt`를 붙이는 래퍼·hook은 `--system-prompt-file`·`--append-system-prompt-file`로 바꿔야 합니다.
