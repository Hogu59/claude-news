## 주요 신규 기능 & 실전 활용

### Claude Sonnet 5.5 출시 — 기본 Sonnet 모델 교체, 출력 속도 30%+ 개선 (v2.1.284)

**Claude Sonnet 5.5(`claude-sonnet-5-5`)가 Anthropic API의 기본 Sonnet 모델로 지정됐습니다.** 100만 토큰 컨텍스트를 지원하며, 가격은 기존 Sonnet 5와 동일하게 100만 토큰당 입력 2달러·출력 10달러, 캐시 읽기는 0.20달러입니다. GeekNews에 따르면 코딩과 문서·슬라이드·스프레드시트 작업 성능이 높아졌고, Sonnet 5 대비 출력 속도가 30% 이상 빨라졌으며 같은 작업에 필요한 토큰 자체가 줄어 Anthropic 자체 테스트에서 비용 대비 효율이 개선됐습니다.

```bash
# API에서 Sonnet 5.5를 명시적으로 지정
export ANTHROPIC_MODEL=claude-sonnet-5-5
```

**Claude Code에서 기본 Sonnet 모델을 쓰고 있었다면 별도 설정 없이 자동으로 5.5로 전환되며, 비용 구조는 그대로인 채 속도와 토큰 효율만 개선되는 셈이니 굳이 이전 모델로 고정해둘 이유가 줄었습니다.** [GeekNews](https://news.hada.io/topic?id=34444)

### 게이트웨이 사용량 한도, 이제 달러 금액으로 표시됩니다 (v2.1.284)

**Claude 앱 게이트웨이를 쓰는 환경에서 `/usage`와 상태 표시줄에 지출 한도가 "$271.40 / $500.00 spent this month"처럼 실제 달러 금액으로 나타납니다.** 상태 표시줄의 `rate_limits.spend_limit`에도 `used_usd`, `limit_usd`, `period` 필드가 추가됐습니다.

**조직 차원에서 게이트웨이로 지출 한도를 관리하고 있다면, 퍼센트만 보던 것에서 벗어나 실제 소진 금액을 바로 확인할 수 있어 예산 초과 여부를 훨씬 빠르게 판단할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Claude Opus 5.5 프롬프트 작성법 (9/28)

**기존 Opus 5용 프롬프트는 대체로 그대로 쓸 수 있으며, 추론량은 effort의 기본값인 medium부터 시작해 조정하는 것이 권장됩니다.** 이전 모델에 맞춰뒀던 effort 설정을 그대로 옮기면 시간과 토큰 사용량이 불필요하게 늘어날 수 있습니다. 채팅에서는 "답하기 전에 신중하게 생각하라" 같은 문구가 여전히 실제 추론량에 영향을 줍니다.

**Opus 5용으로 짜둔 시스템 프롬프트나 CLAUDE.md 지침을 Opus 5.5로 그대로 옮겨 쓰고 있다면, effort 기본값부터 다시 점검해 불필요한 고강도 추론 설정을 걷어내는 편이 비용 절감에 도움이 됩니다.** [GeekNews](https://news.hada.io/topic?id=34424)

### `/mcp reconnect all` — 끊긴 MCP 서버를 한 번에 재연결합니다 (v2.1.284)

**대화형 터미널에서 연결에 실패했거나 인증이 필요한 모든 MCP 서버를 한 번의 명령으로 한꺼번에 재시도할 수 있게 됐습니다.**

```bash
/mcp reconnect all
```

**MCP 서버를 여러 개 붙여 쓰다 보면 세션 도중 일부가 끊기는 일이 흔한데, 서버마다 개별적으로 재연결을 시도하는 대신 이 명령으로 한 번에 정리할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Auto 모드에 이번만 허용하고 다음엔 다시 묻는 옵션이 추가됐습니다 (v2.1.284)

**작업 디렉터리 밖의 파일을 읽기 전 auto 모드가 묻는 프롬프트에 새 답변이 추가되어, 지금 한 번만 허용하고 다음번 같은 상황에서는 다시 물어보게 할 수 있습니다.** 기존에는 한 번 허용하면 이후에도 계속 허용되거나, 매번 거부해야 하는 두 극단만 있었습니다.

**작업 디렉터리 밖 파일을 가끔만 읽어야 하는 워크플로에서, 매번 전체 허용 여부를 고민하지 않고 건별로 판단하면서도 다음 프롬프트는 놓치지 않을 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 생태계 & 플러그인

### Claude 앱 게이트웨이, Google Cloud OTLP로 텔레메트리 직접 전송을 지원합니다 (v2.1.284)

**게이트웨이 설정의 `telemetry.forward_to` 대상에 `auth: { google: {} }`를 추가하면, 게이트웨이가 이미 보유한 Google Cloud 자격증명으로 텔레메트리를 Google Cloud의 OTLP 엔드포인트에 바로 내보낼 수 있습니다.**

**Google Cloud 위에서 관측성 스택을 운영하는 조직이라면, 별도 중계 서비스 없이 게이트웨이에서 곧바로 OTLP로 텔레메트리를 흘려보낼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Claude 앱 게이트웨이, 인증서 기반 클라이언트 인증을 지원합니다 (v2.1.284)

**게이트웨이와 identity provider 사이의 인증에 인증서 기반 클라이언트 인증(`private_key_jwt`)이 추가돼, 클라이언트 시크릿 대신 인증서 자격증명을 발급하는 identity provider와도 연동할 수 있습니다.**

**금융권 등 인증서 기반 신원 확인을 요구하는 identity provider를 쓰는 조직이라면, 기존에 막혀 있던 게이트웨이 연동이 이번 업데이트로 가능해집니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.284**(9/28) 항목입니다.

- **`/rate-limit-options`가 `/help`와 커맨드 메뉴에 추가**돼, 사용량 한도 안내 문구가 가리키는 명령을 claude.ai 구독자가 바로 찾을 수 있습니다.
- **effort 슬라이더의 `increaseEffort`·`decreaseEffort`·`toggleUltracode` 키바인딩 액션이 추가**돼, 화살표와 Tab 키 동작을 `keybindings.json`에서 재바인딩할 수 있습니다.
- **컴팩션 이후에도 남아 있던 "Prompt is too long" 오류가 수정**돼, 컴팩션한 요청이 여전히 너무 길면 최근 대화를 더 줄여 한 번 더 컴팩션합니다.
- **auto-memory 로딩 시 `MEMORY.md`와 회상된 메모리 노트에서 Claude Code 자체 마크업을 흉내 낸 보이지 않는 문자·태그가 무력화**됩니다.
- **`/plugin` 설정 화면에서 boolean 옵션이 자유 텍스트 대신 참/거짓 선택지로 바뀌고, 숫자 옵션은 잘못된 입력을 거부**합니다.
- **[VSCode] 각 프롬프트·응답 위에 시각을 표시하는 옵션이 추가**됐습니다(날짜가 바뀌면 날짜 줄도 표시, 기본은 꺼짐).
