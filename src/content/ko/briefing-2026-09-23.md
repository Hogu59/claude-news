## 주요 신규 기능 & 실전 활용

### Claude Opus 5.5 출시 — 새 기본 Opus 모델로 전환됩니다 (v2.1.280)

**Claude 5.5 제품군의 첫 모델인 Opus 5.5(`claude-opus-5-5`)가 출시되며 기본 Opus 모델 자리를 이어받았습니다.** **100만 토큰 컨텍스트를 지원하고, 가격은 Mtok당 입력 4달러·출력 20달러이며 캐시 읽기는 Mtok당 0.20달러입니다.**

```bash
# /model 에서 Opus 5.5를 선택하거나, API에서 모델 ID로 직접 지정합니다
claude --model claude-opus-5-5
```

**기본 설정에서 일반적인 작업 비용은 Opus 5보다 40% 낮고 출력 생성은 30% 이상 빠릅니다. AAII 벤치마크 기준 최대 추론 설정(max)의 지능 지수는 58점으로, 이전 Opus 5의 최고점 51점과 Fable 5.1의 53점을 모두 넘어섰으며, 추론 강도를 medium·high·xhigh·max로 올릴수록 51→54→56→58점으로 성능이 오르는 대신 평가당 비용도 함께 증가합니다.**

**같은 예산이라면 추론 강도를 무조건 최대로 올리기보다 작업 난이도에 맞춰 조절하는 편이 비용 대비 효율적이며, Opus 5를 쓰던 기존 워크플로는 비용이 낮아지고 속도도 빨라진 채로 자동 전환됩니다.** [GeekNews](https://news.hada.io/topic?id=34135) · [GeekNews](https://news.hada.io/topic?id=34142) · [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.280**(9/22) 항목입니다.

- **`CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`로 세션의 모든 MCP 서버에 적용되는 도구 설명·서버 지침의 2,048자 상한을 바꿀 수** 있습니다.
- **fullscreen 모드에서 `/skills` 목록에 마우스 휠 스크롤이 지원되고, `/plugin`의 스킬 상태 옵션을 클릭으로 바꿀 수** 있습니다.
- **심볼릭 링크 경로를 통한 쓰기가 실제 링크 대상이 아니라 트리 안의 표기로 판단되던 문제가 수정**돼, `acceptEdits`나 허용 규칙, auto 모드가 의도한 위치 밖으로 나가는 쓰기를 더 이상 잘못 승인하지 않습니다.
- **자체 호스팅 러너에서 lifecycle hook의 git이 러너의 공유 git 파일에 등록된 hook 폴더·프로그램을 무시**하게 되어, 로컬 경로와 `git://` 원격 저장소를 쓰려면 이제 `GIT_ALLOW_PROTOCOL`이 필요합니다.
- **hook 실행 완료를 알리는 OpenTelemetry 이벤트(`hook_execution_complete`)에 hook 출력 크기와 파일로 저장된 초과 출력 건수가 추가**됩니다.
- **[VSCode] `/status`로 여는 Status 다이얼로그, `/sandbox`로 여는 Sandbox 다이얼로그, `/chrome`으로 여는 Claude in Chrome 다이얼로그, `/export`로 여는 대화 내보내기가 새로 추가**됩니다.
