## 주요 신규 기능 & 실전 활용

### `load_test_mode` — 실제 업스트림 호출 없이 배포를 부하 테스트합니다 (v2.1.283)

**자체 호스팅 Claude 앱 게이트웨이 설정에 opt-in `load_test_mode` 블록이 추가됐습니다.** **이 블록을 켜면 요청은 정상적으로 만들어지고 서명까지 거치지만 실제 업스트림에는 전달되지 않고, 클라이언트는 미리 정해둔 응답을 돌려받습니다.**

```json
{
  "load_test_mode": {
    "enabled": true
  }
}
```

**실제 API 비용이나 업스트림 부하 없이 게이트웨이 배포 전체를 부하 테스트할 수 있어, 신규 배포 전에 예상 트래픽 규모를 미리 검증하려는 팀에 유용합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Claude Tag "Channels Claude can search" — Slack 검색 범위를 공개 채널로 제한합니다 (v2.1.283)

**조직 admin이 Claude의 Slack 검색 범위를 Claude가 추가된 공개 채널로만 한정할 수 있는 관리자 설정이 추가됐습니다.** **조직·워크스페이스·채널 단위로 개별 설정할 수 있습니다.**

**Slack에 Claude Tag를 붙여 쓰는 조직에서 Claude가 민감한 비공개 채널 내용까지 검색해 답변에 끌어오는 것을 우려했다면, 이 설정으로 검색 범위를 공개 채널로 좁혀둘 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
