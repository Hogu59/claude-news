## 주요 신규 기능 & 실전 활용

### Claude 앱 게이트웨이에 code 정책 키 추가 — Claude Desktop Code 탭도 게이트웨이로 통제 (v2.1.296)

**Claude 앱 게이트웨이의 `managed.policies[]`에 `code` 키가 추가되어, 터미널용 `cli` 키와 동일한 설정을 Claude Desktop의 Code 탭에도 그대로 적용할 수 있게 됐습니다.** 지금까지는 `desktop` 키로 Claude Desktop 전반을 통제했는데, `code` 키를 지정하면 Code 탭에도 게이트웨이 모드가 켜지면서 조직이 정한 모델·도구·권한 정책이 터미널 세션과 동일하게 적용됩니다.

```jsonc
// 게이트웨이 managed.policies에 code 키 추가
{
  "managed": {
    "policies": [
      { "cli": { /* 기존 CLI 정책 */ } },
      { "code": { /* Claude Desktop Code 탭에도 동일 정책 적용 */ } }
    ]
  }
}
```

**조직 차원에서 Claude 앱 게이트웨이로 Claude Code 사용을 통제하고 있다면, Claude Desktop의 Code 탭만 정책 적용 범위 밖에 남아있지 않은지 이번 업데이트를 계기로 확인해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS — 과부하 재시도의 최대 대기 시간 늘리기 (v2.1.296)

**새 환경변수 `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`를 설정하면, 서버가 과부하(529) 응답을 반복할 때 재시도 백오프가 도달할 수 있는 최대 지연 시간을 원하는 만큼 늘릴 수 있습니다.** 10/6 브리핑에서 다룬 `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`가 백오프의 시작 지연을 조정하는 변수였다면, 이번에 추가된 변수는 반대쪽 끝인 최대 지연을 조정합니다.

```bash
# 과부하 응답 재시도의 최대 대기 시간을 늘려 장시간 안정적으로 재시도
export CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS=120000
```

**트래픽이 몰리는 시간대에 529 오류로 세션이 자주 끊긴다면, 기본 지연 시간 변수와 최대 지연 시간 변수를 함께 조정해 재시도 간격을 여유 있게 늘려두면 무인 실행 중인 세션이 중간에 끊길 위험을 줄일 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

- **auto mode에서 점검할 근거가 없어 실행되지 않은 도구 호출이 빨간 오류 대신 옅은 색의 "Not run" 행으로 표시**됩니다.
