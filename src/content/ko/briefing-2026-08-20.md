## 주요 신규 기능 & 실전 활용

### `ANTHROPIC_DEFAULT_MODEL` — 새 세션의 시작 모델을 지정합니다 (v2.1.236)

**새 세션이 시작할 모델을 환경변수로 지정**할 수 있게 됐습니다. **`/model`로 직접 고르면 그 선택이 우선하고, 재시작 이후에도 유지됩니다** — 이 점이 세션마다 매번 적용되던 기존 `ANTHROPIC_MODEL`과 다릅니다.

```bash
# 새 세션의 기본 시작 모델을 지정합니다
export ANTHROPIC_DEFAULT_MODEL=claude-opus-5
```

**팀 전체가 같은 모델로 세션을 시작하게 강제하고 싶지만, 개인이 필요할 때 `/model`로 바꾼 선택은 존중하고 싶은 조직**이라면 유용합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 다른 세션이 유휴 상태가 되면 알림을 받습니다 — `SendMessage`의 `notify_when_idle` (v2.1.236)

**같은 머신에서 돌아가는 다른 Claude Code 세션에, 그 세션이 다음에 유휴 상태가 되는 순간 알림을 한 번 보내달라고 요청**할 수 있습니다. **옵트인·1회성이며, 폴링 없이 동작**합니다(macOS·Linux 지원).

**여러 세션을 병렬로 띄워 두고 다른 작업을 하다가, 특정 세션이 끝나는 순간만 확인하고 싶은 워크플로**에 바로 쓸 만합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### auto mode가 세 가지 지점에서 더 정교해집니다 (v2.1.236)

- **`Monitor` 허용 규칙도 Bash 명령과 동일하게 검토**됩니다 — auto mode가 켜져 있는 동안은 `Monitor` 명령도 별도로 봐주지 않고 똑같이 심사합니다.
- **Bedrock·Vertex AI·Foundry에서, 그리고 텔레메트리가 꺼진 환경에서 classifier가 Claude API와 같은 기본값(심각도 점수 기반 분류 포함)을 씁니다** — 배포 방식에 따라 auto mode의 판단 기준이 달라지던 격차가 줄었습니다.
- **`git status`가 `status.showUntrackedFiles=no` 설정으로 클린한 상태처럼 보이게 만드는 속임수를 auto mode가 더 이상 통과시키지 않습니다.**

**auto mode를 여러 클라우드·배포 환경에서 동시에 쓰고 있다면, 이번 변경으로 환경마다 승인 기준이 달랐던 부분이 좁혀집니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

- **프롬프트 테두리의 세션 제목 칩이 풋터 오른쪽 끝과 정렬**됐고, **풋터의 오른쪽 정렬 항목(goal 표시, 세션 상태, 백그라운드 에이전트 상태)이 일관된 오른쪽 여백**을 갖습니다.
