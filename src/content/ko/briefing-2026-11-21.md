## 개발자 워크플로우 팁

### easel — MCP 메트릭 결과 등에 자동으로 차트를 그려주는 내장 mod가 추가됐습니다 (v2.1.330)

**지금까지 Claude Code가 MCP 도구로 받아온 수치 결과를 차트로 보려면 매번 따로 요청해야 했는데, 이번 릴리스부터 Pro·Max와, 지원되는 경우 Team·Enterprise 플랜에서(macOS·Linux) easel이라는 내장 mod가 요청을 받을 때나 MCP 메트릭 결과 아래에 자동으로 차트를 그려줍니다.** 자동 차트를 원하지 않으면 `/config`에서 끌 수 있습니다.

```bash
# /config를 열어 easel의 자동 차트 기능을 끄고 싶을 때
/config
# → 자동 차트(automatic charts) 항목에서 끄기
```

**MCP로 메트릭이나 수치 데이터를 자주 조회하면서 매번 "차트로 그려줘"라고 따로 요청하고 있었다면, v2.1.330부터는 별도 요청 없이 자동으로 뜨는 차트를 그대로 활용할 만하며, 원치 않을 때만 `/config`에서 꺼두면 됩니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 예약 작업과 `/loop`가 세션이 계속 떠 있는 동안 최대 30일까지 돌 수 있게 늘었습니다 (v2.1.330)

**지금까지 반복 예약 작업과 `/loop`는 세션이 살아있어도 7일이 지나면 끊겼는데, 이번 릴리스부터는 최대 30일까지 늘어났고 끝나는 시점도 미리 알려줍니다.** 다만 이 릴리스 이전에 만들어 저장해둔 작업은 여전히 7일 제한을 받습니다.

**장시간 모니터링이나 반복 점검을 `/loop`나 예약 작업으로 돌려두면서 7일마다 다시 설정해야 했다면, v2.1.330으로 올라간 뒤 새로 만드는 작업부터는 최대 30일까지 쉬지 않고 돌릴 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### VS Code에 마지막 답변 뒤에서 대화를 포크하는 `/fork`가 추가됐습니다 (v2.1.330)

**지금까지 대화를 분기해서 다른 접근을 시험해보려면 세션을 새로 시작해야 했는데, 이번 릴리스부터 VS Code에서 `/fork` 명령으로 마지막 답변 지점에서 바로 대화를 포크할 수 있습니다.**

**VS Code로 Claude Code를 쓰면서 같은 대화에서 서로 다른 접근을 시험해보고 싶었다면, v2.1.330부터는 `/fork`로 지금까지의 맥락을 유지한 채 바로 분기해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**지금까지도 위험한 `rm` 명령 일부는 확인을 거쳤지만, 이번 릴리스부터는 루트, 홈, 최상위 폴더, 작업 폴더를 대상으로 하는 더 많은 `rm` 명령이 승인을 요구하도록 범위가 넓어졌고, 아무도 승인에 답할 수 없는 상황(무인 자동화 등)에서는 그런 명령 자체가 거부됩니다.**

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.330**(11/20) 항목 중 위에서 다루지 않은 것들입니다.

- **`CLAUDE_CODE_FULL_SIGN_IN_LINK=1` 환경변수가 추가**돼, 짧은 로그인 링크에 오류가 뜨거나 스크립트가 값을 읽어야 할 때 전체 링크를 출력할 수 있습니다.
- **`/mcp`가 플러그인이 설치한 MCP 서버를 내장 서버로 잘못 분류하던 문제가 수정**돼, 이제 "Plugin MCPs"와 `--mcp-config`·내장 서버를 묶은 "Other MCPs"로 구분됩니다.
- **`/stats`가 UTC 기준 날짜로 활동을 집계하던 문제가 수정**돼, 이제 로컬 시간대 기준으로 집계합니다.
- **`claude plugin install --json` 결과에 설치 명령이 stderr에 썼는지(`commandPrinted`)와 실패했는지(`commandFailed`)를 보여주는 필드가 추가**됐습니다.
- **VS Code에 선택한 메시지를 고정하지 않고 흘러가게 두는 `claudeCode.pinPrompt` 설정과, Esc가 Claude를 멈추지 않도록 끄는 `claudeCode.escapeStopsClaude` 설정이 추가**됐습니다.
- **`/ultrareview`가 셀이 다른 저장소로 이동한 뒤 실패하거나 엉뚱한 코드를 리뷰하던 문제가 수정**돼, 이제 두 폴더 이름을 모두 알려주고 멈춥니다.
