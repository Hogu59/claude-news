## 주요 신규 기능 & 실전 활용

### `$.ui.notify`로 모드가 사용자의 알림 채널을 직접 울릴 수 있습니다 (v2.1.295)

**모드(플러그인) 개발자를 위한 새 API `$.ui.notify`가 추가되어, 모드 코드에서 사용자가 이미 설정해둔 알림 채널을 거쳐 네이티브 알림을 직접 띄울 수 있게 됐습니다.** 호출 결과로 어떤 채널이 알림을 전달했는지도 알 수 있어, 여러 알림 경로를 함께 쓰는 모드도 전달 여부를 확인할 수 있습니다.

```js
// 모드 코드에서 사용자의 기본 알림 채널로 알림 발송
await $.ui.notify({ title: '빌드 완료', body: '테스트 142개 통과' })
```

**장시간 백그라운드 작업이 끝났을 때 알려주는 모드를 만들고 있다면, 별도의 OS 알림 라이브러리를 직접 붙이는 대신 `$.ui.notify`로 사용자가 이미 설정해둔 알림 경로를 그대로 재사용할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `claude plugin validate`, README에 설치 안내가 없으면 바로 붙여넣을 문구를 알려줍니다 (v2.1.295)

**플러그인 README에 설치 방법을 안내하는 줄이 없으면 `claude plugin validate`가 그대로 붙여넣을 수 있는 안내 문구를 출력해줍니다.** `--strict` 옵션을 켜도 이 조언 때문에 종료 코드가 실패로 바뀌지는 않아, 배포 자체를 막지 않으면서 누락만 짚어줍니다.

**플러그인 마켓플레이스에 공개할 README를 준비하고 있다면, 배포 직전에 `claude plugin validate`를 한 번 돌려 설치 안내 문구가 빠지지 않았는지 점검해두면 좋습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**팀 차원에서 Claude Code 도입 효과를 코드 생성량이나 커밋 수로 측정하고 있다면, 그 수치 대신 실제로 완료되고 배포까지 이어진 작업 단위(머지된 PR, 해결된 티켓)를 기준으로 삼아야 에이전트 도입이 정말 산출량을 늘렸는지 왜곡 없이 판단할 수 있습니다.** [GeekNews](https://news.hada.io/topic?id=35257)

**널리 쓰이는 TypeScript 스키마 검증 라이브러리 Zod가 4.6.5에서 4.6.6으로 올라가는 커밋에, 외부 코드를 내려받아 실행하는 `meta.test.mjs` 파일이 `zod`와 `@zod/mini` 패키지에 동일하게 추가된 것이 발견됐습니다.** 이 코드는 Ethereum RPC 응답에서 도메인 목록을 읽어와 각 도메인에서 추가 코드를 불러오는 구조로 알려져, 공급망 공격 의심 사례로 커뮤니티에서 집중적으로 검증되고 있습니다.

**프로젝트에서 zod나 @zod/mini를 의존성으로 쓰고 있다면, package.json과 lockfile에서 설치된 버전이 4.6.6인지 바로 확인하고, 해당된다면 공식 공지와 패치 버전이 나올 때까지 이전 버전으로 고정해두는 것이 안전합니다.** [GeekNews](https://news.hada.io/topic?id=35238)

### Google 문서 플랫폼에서 9만 달러 포상금을 받은 원격 코드 실행 취약점이 공개됐습니다 (10/13)
