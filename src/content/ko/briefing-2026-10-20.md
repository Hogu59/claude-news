## 주요 신규 기능 & 실전 활용

### `/auto-mode-setup`이 Bedrock·Vertex·Foundry·Claude apps gateway까지 확장됐습니다 (v2.1.304)

**프로젝트와 최근 세션을 읽어 auto mode에게 사용 환경을 가르치는 가이드 설정 `/auto-mode-setup`이, 이번 릴리스부터 Amazon Bedrock, Google Vertex AI, Microsoft Foundry, Claude apps gateway, 그리고 텔레메트리가 꺼진 세션에서도 쓸 수 있게 확장됐습니다.** 지금까지는 이런 환경에서 auto mode를 쓰려면 설정을 직접 손으로 구성해야 했습니다.

```bash
# 프로젝트와 최근 세션을 기반으로 auto mode 가이드 설정 실행
/auto-mode-setup
```

**Bedrock이나 Vertex, Foundry 기반으로 Claude Code를 운영하면서 auto mode 도입을 미뤄왔다면, 이제 이 명령으로 환경에 맞춘 설정을 바로 시작해볼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Code Review에 리뷰 레벨이 추가되고, 조직 전체 저장소를 한 번에 등록할 수 있습니다 (v2.1.304)

**Owner가 조직 단위로 Quick, Standard(기본값), Deep 중 리뷰 레벨을 고르고 개별 저장소마다 다르게 설정할 수 있게 됐으며, 새로 추가되는 저장소까지 포함해 GitHub organization 전체를 하나씩 선택하지 않고 한 번에 Code Review 대상으로 등록하는 옵션도 추가됐습니다.** 함께, 관리자가 Code Review를 켠 직후 1~2분 안에 열린 PR이 조용히 리뷰에서 빠지던 문제도 수정되어 이제는 다시 시도되어 리뷰됩니다.

**GitHub organization 여러 저장소에 Code Review를 도입했거나 도입을 검토 중이라면, 저장소별 리뷰 깊이를 Quick/Standard/Deep으로 나눠 비용과 꼼꼼함의 균형을 맞추고, 새 저장소를 수동으로 추가하는 번거로움 없이 조직 전체를 한 번에 등록해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Pro·Max 플랜에서 유휴 대화를 재개하면 사용량 경고가 뜹니다 (v2.1.304)

**비활성 상태였던 대화를 재개하는 것이 5시간 사용량 한도의 상당 부분을 쓸 것으로 예상되면 경고가 표시되며, 그대로 재개할지 새 대화를 시작해 필요할 때 Claude가 이전 대화를 찾아보게 할지 선택할 수 있습니다.** 지금까지는 오래 묵혀둔 대화를 재개했다가 예상보다 많은 사용량이 한 번에 소모되는 경우가 있었습니다.

**Pro나 Max 플랜에서 여러 대화를 띄워두고 간헐적으로 돌아가며 쓰는 습관이 있다면, 이 경고를 계기로 새 대화로 시작하는 쪽이 사용량 관리에 더 유리한지 가늠해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### tmux로 Claude Code 세션을 오래 유지하기 — send-keys와 그 한계 (10/20)

**tmux는 AI 코딩 에이전트를 이름 붙은 세션에 계속 살려둬 터미널을 닫거나 SSH 연결이 끊겨도 작업을 이어가게 하고, 여러 에이전트를 한 창에서 관리할 수 있게 해준다는 글입니다.** 최근 추가된 `claude --worktree --tmux`가 단일 브랜치에서 작업할 에이전트의 작업 공간을 자동으로 나눠준다는 점은 짚으면서도, tmux의 `send-keys`로 세션에 입력을 흘려보내는 방식 자체가 타이밍과 출력 파싱 측면에서 갖는 한계도 함께 지적합니다.

**여러 Claude Code 세션을 동시에 돌리며 SSH 연결 끊김이나 터미널 종료로 작업이 날아간 경험이 있다면, `claude --worktree --tmux` 조합과 tmux 세션 구조부터 먼저 살펴보되 send-keys 기반 자동화의 한계는 미리 감안해두는 것이 좋습니다.** [GeekNews](https://news.hada.io/topic?id=35650)

### `/claude-api managed-agents-secure`로 Managed Agents 보안 설정을 바로 점검하기 (v2.1.304)

**새 명령 `/claude-api managed-agents-secure`는 Managed Agents 에이전트의 설정을 Anthropic이 공개한 보안 가이드와 비교해 보여주며, 아무것도 바꾸지 않고 점검만 수행합니다.** 지금까지는 보안 가이드 문서를 직접 열어 항목을 하나씩 대조해야 했습니다.

```bash
# Managed Agents 설정을 Anthropic 보안 가이드와 비교 점검
/claude-api managed-agents-secure
```

**Claude Platform에서 Managed Agents를 운영하고 있다면, 수동으로 가이드 문서와 설정을 대조하는 대신 이 명령 하나로 빠르게 점검하고 벗어난 항목부터 손볼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
