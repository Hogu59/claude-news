## 생태계 & 플러그인

### Show GN: Boxdawn guard — Claude Code가 위험한 명령을 실행하기 전에 판정하는 플러그인 (11/8)

**Claude Code가 Bash·PowerShell 명령을 실행하기 전에 먼저 검사해, 위험한 명령은 거부하거나 확인을 요구하는 플러그인입니다.** 프로젝트 밖의 파일 삭제·덮어쓰기, force push, `reset --hard`, `WHERE` 없는 `DROP`·`DELETE`, `terraform destroy`, `kubectl delete` 같은 명령을 걸러내고, `.env`나 SSH 키 같은 민감 파일은 이름으로 읽히는 순간 확인을 요구하며 `grep -r` 검색에서는 애초에 제외합니다. 같은 `rm -rf`도 프로젝트 안에서는 허용하고 밖에서는 거부하는 식으로 위치까지 따져 판단하며, 심볼릭 링크는 실제 경로로 풀어서 검사합니다. API 키 없이 동작하고 네트워크 연결도 열지 않으며, 권한을 추가로 허용하는 일은 하지 않고 거부·확인만 할 수 있습니다.

```bash
claude plugin marketplace add boxdawn/guard
claude plugin install boxdawn-guard@boxdawn
```

**Claude Code에 accept-edits나 auto mode를 걸어두고 있다면, 이 플러그인으로 명령 하나하나에 위치 기반 판정을 한 겹 더 씌워 위험한 명령이 조용히 실행되는 상황을 줄여볼 만합니다.** [GeekNews](https://news.hada.io/topic?id=36811)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.319**(11/6) 항목 중 지난 브리핑에서 다루지 않은 것들입니다.

- **따옴표로 감싼 단어가 들어간 명령이 Bash deny·ask 규칙을 피해가던 문제가 수정**됐습니다.
- **`timeout 30 rg foo`처럼 읽기 전용 명령을 `timeout`으로 감쌌을 뿐인데 불필요한 권한 프롬프트가 뜨던 문제가 수정**됐습니다.
- **`/clear`가 계속 실행돼야 할 백그라운드 에이전트·팀원·워크플로의 명령과 그 포그라운드 서브에이전트까지 함께 중단시키던 문제가 수정**됐습니다.
- **오래된 handshake를 쓰는 MCP 서버가 연결에 실패하거나 빈 결과를 돌려주던 문제가 수정**됐습니다. Claude Code가 최신 서버에만 쓰는 확장을 오래된 서버에도 선언했던 것이 원인입니다.
- **`/context`의 터미널 표가 각 목록 10개 행으로 유지되고, 온디맨드로 로드되는 MCP 도구들은 서버당 한 줄로 묶여 표시**되도록 개선됐습니다.
- **저장소 최상위에 `HEAD`라는 이름의 파일·폴더가 있으면 `/diff`가 "Diff unavailable"로 뜨고 claude.ai·모바일 앱에서도 diff가 로드되지 않던 문제가 수정**됐습니다.
