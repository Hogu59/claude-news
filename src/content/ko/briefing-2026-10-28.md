## 주요 신규 기능 & 실전 활용

### Claude apps gateway에 `oidc.user_id_claim`이 추가됐습니다 (v2.1.312)

**Claude apps gateway에서 사용자를 식별할 때 기본 `sub` 클레임 대신, Microsoft Entra ID의 `oid`처럼 조직이 실제로 쓰는 다른 id_token 클레임을 지정할 수 있게 됐습니다.** 지금까지는 `sub` 클레임 하나만 사용자 식별에 쓸 수 있어, 자체 ID 체계를 쓰는 조직은 매핑을 따로 관리해야 했습니다.

```yaml
# Claude apps gateway 설정 예시
oidc:
  user_id_claim: oid  # Microsoft Entra ID의 경우
```

**Claude apps gateway를 Entra ID 등 `sub` 외 클레임으로 사용자를 식별하는 OIDC 공급자와 연동하고 있다면, 이 설정으로 기존에 따로 관리하던 사용자 매핑 로직을 걷어낼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Bedrock·Vertex·Foundry·Mantle에서 인식하지 못하는 모델명에도 짧은 시스템 프롬프트가 적용됩니다 (v2.1.312)

**커스텀 배포명이나 추론 프로파일 ARN처럼 Claude Code가 인식하지 못하는 이름으로 Sonnet이나 Haiku를 운영해도, 이제 Bedrock·Vertex·Foundry·Mantle에서는 더 짧은 시스템 프롬프트가 적용됩니다.** 기존 전체 프롬프트를 유지하고 싶다면 환경변수로 끌 수 있습니다.

```bash
# 기존 전체 시스템 프롬프트를 유지하려면
export CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0
```

**Bedrock·Vertex·Foundry에서 커스텀 배포명이나 ARN으로 Claude Code를 연결해 쓰고 있다면, v2.1.312부터 토큰 사용량이 줄어드는지 확인하고 기존 동작이 필요하면 이 환경변수로 되돌릴 수 있다는 점을 기억해두면 좋습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### Write 도구가 대용량 CLAUDE.md·rules 파일을 일부만 보고 덮어쓰지 않습니다 (v2.1.312)

**하위 디렉터리의 매우 긴 CLAUDE.md, rules 파일, `@`로 포함한 파일을 시작 부분만 읽은 뒤 Claude가 그대로 덮어쓰던 문제가 수정돼, 이제 Write는 파일 전체를 읽거나 제자리에서 편집하도록 Claude에게 요청합니다.** 지금까지는 파일 뒷부분의 내용이 통째로 사라질 위험이 있었습니다.

**여러 하위 패키지마다 자체 CLAUDE.md나 rules 파일을 길게 두고 있다면, 이번 수정으로 Claude가 뒷부분을 보지 않고 섣불리 덮어쓰는 사고를 막아준다는 점을 믿고 계속 써도 됩니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `paths:`로 지정한 스킬이 Bash `cd`로 하위 디렉터리에 들어간 뒤에도 다시 검색됩니다 (v2.1.312)

**Bash로 git 저장소 하위 디렉터리에 `cd`한 뒤 디렉터리별 또는 `paths:` 조건이 붙은 스킬을 찾지 못하던 문제가 수정됐습니다.** 지금까지는 셸에서 깊은 경로로 이동하면 그 경로에 맞춰 설계된 스킬이 갑자기 보이지 않는 경우가 있었습니다.

**모노레포에서 패키지별로 `paths:` 조건을 둔 스킬을 운영하고 있다면, Bash로 하위 디렉터리를 옮겨다니는 작업이 많을수록 이번 수정의 체감이 클 것입니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 프롬프트·에이전트 훅이 세션당 동시에 최대 24개까지만 실행됩니다 (v2.1.312)

**서브에이전트를 포함해 한 세션에서 동시에 실행되는 프롬프트·에이전트 훅이 최대 24개로 제한되고, 각 훅의 타임아웃보다 오래 대기 중인 훅은 최대 12개까지 추가로 허용되며, 1초 미만으로 설정한 타임아웃은 1초로 처리됩니다.** 지금까지는 다수의 서브에이전트가 동시에 훅을 트리거할 때 동시 실행 수에 제한이 없었습니다.

**많은 서브에이전트나 fork를 동시에 띄우면서 각 턴마다 훅을 트리거하는 자동화를 쓰고 있다면, 이 동시 실행 한도를 넘는 순간 일부 훅이 대기열에 밀릴 수 있다는 점을 염두에 두고 훅 설계를 점검해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.312**(10/27) 항목입니다.

- **풀스크린에서 대기 중인 메시지 아래 "지금 보내기" 힌트를 클릭하면, 키를 누른 것과 똑같이 즉시 전송**됩니다.
- **사용량 한도 메시지의 표기가 "session limit"에서 "5-hour limit"으로 통일**됐습니다.
- **거부(refusal) 메시지 후 자동 모델 전환이 커스텀 배포명 등 인식하지 못하는 모델명까지 포함하도록 확장**됐으며, `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1`로 끌 수 있습니다.
- **CLI에서 시작한 cloud session의 이름과 브랜치명을 이제 서버에서 받아옵니다.**
- **공식 Anthropic 마켓플레이스 플러그인이 선언한 고정 URL 원격 MCP 서버의 OpenTelemetry `mcp_server.name`이 `custom` 대신 실제 이름을 표시**합니다.
- **Claude Code가 `claude_code.safety_event` OpenTelemetry 이벤트 전송을 중단**했습니다.
- **[Code Review] GitHub의 push 이벤트가 늦게 도착했을 때 오래된 커밋을 리뷰하거나 아예 리뷰하지 않던 문제가 수정**돼, 이제 PR의 현재 커밋을 리뷰합니다.
