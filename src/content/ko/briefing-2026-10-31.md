## 주요 신규 기능 & 실전 활용

**200K 토큰이 넘는 대화를 한동안 그대로 두면 VS Code와 Claude Desktop의 Code 탭이 자동으로 요약하고, prompt cache가 만료된 상태로 다음 메시지를 보내면 그 요약이 바로 쓰입니다.** 지금까지는 유휴 상태로 오래 둔 긴 대화로 복귀하면 캐시가 만료된 전체 대화를 그대로 다시 처리해야 해서 첫 응답이 느리고 비용도 더 들었습니다.

**낮 동안 여러 작업을 오가며 VS Code나 Claude Desktop의 Code 탭에 긴 대화를 열어두는 습관이 있다면, v2.1.314부터는 복귀 시점의 첫 응답이 더 가벼워진다는 점을 기대할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### 백그라운드 에이전트의 상태 요약 호출이 전체 토큰의 15~20%를 쓰고 있었습니다 (GeekNews, 10/29)

**Claude Code가 백그라운드 에이전트의 전체 대화 기록을 약 30초마다 모델에 다시 보내 "가장 최근 행동을 3~5단어로 설명하라"고 요청하고 있으며, 이 상태 요약 호출이 전체 토큰 사용량의 15~20%를 차지한다는 분석이 올라왔습니다.** 결과는 에이전트 패널의 상태 줄에만 쓰이는데도 이를 끄는 설정은 따로 없어, 작성자는 바이너리를 수정하지 않고 요약 타이머만 막는 스크립트를 공유했지만 내부 문자열에 의존하는 만큼 업데이트마다 다시 검증해야 한다고 밝혔습니다.

**백그라운드나 서브에이전트를 여러 개 동시에 오래 띄워두는 워크플로를 쓰고 있다면, 이 상태 요약 호출이 사용량 한도 소모에 어느 정도 기여하는지 염두에 두고 `/usage`로 실제 비중을 확인해볼 만합니다.** [GeekNews](https://news.hada.io/topic?id=36213)

### `permissions.blockWritesOutsideWorkingDirectories`로 모든 권한 모드에서 작업 디렉터리 밖 쓰기를 차단할 수 있습니다 (v2.1.314)

**새 설정이 추가돼, 켜두면 Write·Edit·NotebookEdit이 permission 모드와 무관하게 작업 디렉터리 밖 경로에는 항상 쓰기를 거부합니다.** 지금까지는 bypass permissions 모드처럼 승인 절차가 느슨한 모드에서는 작업 디렉터리 밖 파일도 수정될 여지가 있었습니다.

```json
// settings.json
{
  "permissions": {
    "blockWritesOutsideWorkingDirectories": true
  }
}
```

**여러 저장소나 홈 디렉터리 전체를 대상으로 auto mode나 bypass permissions 모드를 쓰고 있다면, 이 설정으로 의도한 작업 디렉터리 밖 파일이 실수로 바뀌는 사고를 원천적으로 막아둘 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 백그라운드 diff 갱신이 git 인덱스 잠금을 잡아 동시에 실행한 git 명령이 실패하던 문제가 수정됐습니다 (v2.1.314)

**Claude Code가 변경 내용을 보여주기 위해 백그라운드에서 diff를 갱신할 때 저장소의 인덱스 잠금을 잠깐 쥐고 있어서, 같은 순간 터미널에서 git 명령을 실행하면 "Unable to create '.git/index.lock': File exists" 오류로 실패하는 경우가 있었는데 이번에 수정됐습니다.** 지금까지는 Claude Code가 작업 중일 때 다른 터미널에서 git status나 git commit을 실행하면 이유를 알기 어려운 잠금 오류를 만나는 경우가 있었습니다.

**Claude Code를 띄워둔 채 별도 터미널에서 git 명령을 자주 병행한다면, v2.1.314부터는 이런 잠금 충돌을 더 이상 신경 쓰지 않아도 됩니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.314**(10/30) 항목입니다.

- **Microsoft Foundry 세션에서 기본 Sonnet·Opus·Haiku 모델의 배포가 없는 리소스를 쓰면, 해당 모델군의 더 오래된 모델로 자동 전환**됩니다.
- **Bedrock에서 이미지가 많은 대화가 매 턴 실패하고 `/compact`도 "Input is too long."으로 막히던 문제가 수정**돼, 오래된 이미지를 지우고 압축한 뒤 이어갑니다.
- **시스템 인증서 저장소가 이전 루트와 교차 서명된 갱신된 루트 인증서를 갖고 있을 때 TLS 연결이 `UNABLE_TO_GET_ISSUER_CERT`로 실패하던 문제가 수정**됐습니다.
- **"사용량 한도에서 자동으로 계속하기"가 /goal 체크인이나 백그라운드·예약 작업으로 턴이 재시작되면 묻지 않고 세 번을 넘겨 계속되던 문제가 수정**됐습니다.
- **Cowork 클라우드 세션의 WebFetch가 PDF 텍스트를 100,000자 넘는 부분에서 조용히 잘라내던 문제가 수정**돼, 이제 얼마나 못 읽었는지와 이어 읽을 위치를 알려줍니다.
- **PreCompact 훅의 출력이 매우 길면 압축이 실패하거나 반복되던 문제가 수정**돼, 각 훅의 출력이 10,000자에서 잘립니다.
- **Claude apps gateway 업스트림에 `groups` 목록이 추가**돼, failover 시에도 지정한 IdP 그룹의 개발자만 해당 업스트림으로 보냅니다.
