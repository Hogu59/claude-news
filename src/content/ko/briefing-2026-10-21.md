## 주요 신규 기능 & 실전 활용

### `sandbox.allowNestedUserNamespaces` — Linux 샌드박스에서 Chromium·rootless podman을 돌릴 수 있습니다 (v2.1.305)

**새 설정 `sandbox.allowNestedUserNamespaces`를 켜면, Linux에서 샌드박스로 실행되는 명령이 유저 네임스페이스를 만들 수 있게 되어 Chromium이나 rootless podman처럼 유저 네임스페이스가 필요한 도구를 샌드박스 안에서 실행할 수 있습니다.** 다만 이 옵션은 샌드박스의 파일 보호를 우회하는 길을 열어주기도 하므로, 어떤 명령에 이 권한을 주는지는 신중하게 판단해야 합니다.

```json
{
  "sandbox": {
    "allowNestedUserNamespaces": true
  }
}
```

**샌드박스 모드에서 브라우저 자동화나 rootless 컨테이너 빌드를 시도하다 유저 네임스페이스 권한 부족으로 막혔던 경험이 있다면, 이 옵션으로 문제를 풀 수 있지만 그만큼 격리 수준이 낮아진다는 트레이드오프를 함께 받아들여야 합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` — 사용량 한도가 예정보다 일찍 풀렸는지 미리 확인합니다 (v2.1.305)

**새 환경변수 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`를 설정하면, 무인 재시도 모드(`CLAUDE_CODE_RETRY_WATCHDOG`)가 사용량 한도에 걸려 대기하는 동안 정해진 주기로 한도가 이미 풀렸는지 재확인합니다.** 10/16 브리핑에서 다룬 `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`(최대 대기 시간 제한)와 짝을 이루는 설정으로, 이번엔 반대로 한도가 리셋 예정 시점보다 먼저 풀렸을 때를 놓치지 않도록 해줍니다.

```bash
export CLAUDE_CODE_RETRY_WATCHDOG=1
export CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS=60000
```

**CI나 스케줄러로 Claude Code를 무인 실행하면서 사용량 한도 리셋을 기다리는 경우가 잦다면, 이 주기를 짧게 잡아두면 한도가 예상보다 일찍 풀렸을 때 바로 작업을 재개할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### `/usage` 경고를 f 키로 한 번에 고치기 (v2.1.304)

**`/usage`에 뜨는 경고가 이제 각각 원인을 알려주는 한 줄짜리 수정 안내로 바뀌었고, `f` 키를 누르면 그 수정이 한 번에 적용됩니다.** 같은 수정 목록은 VS Code 패널과 `/doctor`에도 똑같이 나타납니다.

**환경변수나 설정 문제로 `/usage`에 경고가 쌓여 있다면, 항목을 하나씩 추적해 고치는 대신 `f`를 눌러 한 번에 정리하고, 같은 목록이 VS Code나 `/doctor`에도 뜬다는 점을 활용해 어느 클라이언트에서 작업하든 일관되게 점검해보세요.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `allowedMcpServers` 필터링이 좁아졌습니다 — 업그레이드 후 자동으로 로드되는 MCP 서버를 확인하세요 (v2.1.305)

**`allowedMcpServers`가 이제 `managed-mcp.json`의 stdio 서버 중 `${VAR}`를 `env`에만 쓰는 서버를 더 이상 걸러내지 않도록 바뀌면서, 지금까지 allowlist에서 빠져 있던 서버가 업그레이드 후 자동으로 로드될 수 있습니다.** 계속 막아두려면 `allowedMcpServers`가 아니라 `deniedMcpServers`에 명시해야 합니다.

**조직 차원에서 `managed-mcp.json`으로 MCP 서버를 배포하면서 `allowedMcpServers`로 일부를 걸러두고 있었다면, v2.1.305로 올리기 전에 어떤 서버가 새로 로드될 수 있는지 먼저 점검하고 필요한 서버는 `deniedMcpServers`로 옮겨두는 것이 안전합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.305**(10/20) 항목입니다.

- **`/artifacts` 삭제 확인이 번호 선택 방식으로 바뀌어**, 1이나 Enter는 유지, 2는 삭제, Esc는 취소이며 `y`·`n`은 더 이상 동작하지 않습니다.
- **디스크가 가득 찬 상태에서 Bash 명령이 `ENOSPC` 원시 경로만 보여주며 실패하던 문제가 수정**돼, 이제 디스크가 가득 찼고 아무것도 실행되지 않았다고 명확히 안내합니다.
- **시작 시 경고가 로고 위에 원시 텍스트로 출력되던 문제가 수정**돼, 이제 디버그 로그로 가고 아무것도 제한하지 않는 권한 규칙은 배너 아래 warning 행으로 표시됩니다.
- **스크린리더 모드가 개선**돼, 검색창이 전화 녹음기로 들리던 기호 대신 "Search:"라고 읽히고 Ctrl+R 검색 매치나 "ultrathink" 같은 강조 텍스트에 불필요한 공백이 들어가지 않습니다.
- **[VSCode] SessionStart나 Setup 훅이 실행되는 동안 "Running start-up hooks" 스피너 상태와 스크린리더 안내가 추가**됐습니다.
- **mod의 독 패널이 더 넓은 터미널에서 썼던 폭을 유지하던 문제가 수정**돼, 이제 터미널 폭의 45% 이내로 제한됩니다.
