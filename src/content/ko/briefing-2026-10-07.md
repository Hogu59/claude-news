## 주요 신규 기능 & 실전 활용

### Agent 도구에 `effort` 파라미터 추가 — 서브에이전트마다 추론 강도를 따로 지정합니다 (v2.1.292)

**Agent 도구에 `effort` 파라미터가 추가되어, Claude가 서브에이전트를 요청받은 추론 강도(effort level)로 실행할 수 있게 됐습니다.** 지금까지는 서브에이전트를 띄울 때 효율과 품질 사이의 균형을 세밀하게 조절할 방법이 마땅치 않았는데, 이제 작업 성격에 맞춰 강도를 직접 지정할 수 있습니다.

**단순 포맷 변환이나 파일 검색 같은 가벼운 서브에이전트는 낮은 effort로, 복잡한 리서치나 설계 판단이 필요한 서브에이전트는 높은 effort로 지정하면, 여러 서브에이전트를 병렬로 돌릴 때 전체 비용과 응답 속도를 더 세밀하게 조절할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `claude plugin install --marketplace` — 마켓플레이스 추가와 플러그인 설치를 한 번에 (v2.1.292)

**`claude plugin install`에 `--marketplace <source>` 플래그가 추가되어, 마켓플레이스가 아직 등록되지 않았다면 `claude plugin marketplace add`와 같은 정책 검사를 거쳐 추가한 뒤 그 자리에서 플러그인까지 설치합니다.**

```bash
# 마켓플레이스를 추가하면서 동시에 플러그인 설치
claude plugin install <plugin-name> --marketplace <source>
```

**사내 플러그인을 동료에게 공유할 때 마켓플레이스 등록과 설치를 두 단계로 안내하지 않고 명령 한 줄로 끝낼 수 있어, 온보딩 문서를 간결하게 유지할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
