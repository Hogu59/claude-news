## 주요 신규 기능 & 실전 활용

### `/doctor prompt-audit` — CLAUDE.md·스킬·에이전트·커맨드의 구식 프롬프팅 패턴을 감사합니다 (v2.1.283)

**CLAUDE.md, 스킬, 에이전트, 커맨드 파일에 남아 있는, 이전 세대 모델을 겨냥해 작성된 프롬프팅 패턴을 찾아주는 명령이 추가됐습니다.** `/checkup prompt-audit`으로도 같은 기능을 실행할 수 있습니다.

```bash
/doctor prompt-audit
# 또는
/checkup prompt-audit
```

**오래된 팀에서는 Claude Code 도입 초기에 작성한 CLAUDE.md나 커스텀 스킬이 지금 모델 기준으로는 불필요하거나 오히려 역효과를 내는 지시를 담고 있는 경우가 많습니다. 정기적으로 이 명령을 돌려 지침 파일을 최신 모델에 맞게 정리해두는 습관을 들일 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `deniedModels`·`availableModelsMatch: exact` — 모델 허용·차단을 더 세밀하게 통제합니다 (v2.1.283)

**`availableModelsMatch`를 `"exact"`로 설정하면 `availableModels`에 나열한 모델 버전만 허용되어, 새 모델이 출시돼도 명시적으로 목록에 추가하기 전까지는 자동으로 열리지 않습니다.** **`deniedModels` 관리형 설정을 쓰면 `availableModels`가 허용한 모델이라도 특정 모델만 따로 차단할 수 있습니다.**

```json
{
  "availableModels": ["claude-opus-5-5", "claude-sonnet-5"],
  "availableModelsMatch": "exact",
  "deniedModels": ["claude-3-5-sonnet-20240620"]
}
```

**조직 차원에서 사용 모델을 엄격히 통제하는 팀이라면, 새 모델이 나올 때마다 관리자가 검토하고 명단에 올릴 때까지 자동으로 막아두는 이 조합이 유용합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
