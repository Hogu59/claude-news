### FlashProve — Anthropic이 모델 가중치 없이 추론을 검증하는 연구 프로토타입을 공개했습니다 (11/5)

**Anthropic이 zkSNARK 암호 증명으로 "이 응답이 특정 모델에서 나왔다"는 사실을 가중치를 공개하지 않고도 검증할 수 있는 오픈소스 연구 프로토타입 FlashProve를 공개했습니다.** 모델 제공자가 가중치를 고정하는 짧은 커밋먼트를 오프라인에서 한 번 만들어두면, 이후 특정 프롬프트·응답 쌍에 대해 그 커밋먼트가 가리키는 모델이 실제로 그 출력을 냈다는 증명을 생성할 수 있고, 누구나 GPU 없이 커밋먼트·프롬프트·응답·증명만으로 이를 검증할 수 있습니다. 약 400B 파라미터 MoE 모델인 Llama 4 Maverick을 H100 한 장으로 증명했을 때 초당 110토큰, 증명 파일은 약 18.78MB, 검증은 24스레드에서 약 17초가 걸렸고, 완전성·건전성·영지식성·간결성이라는 네 가지 안전성 속성은 Lean으로 정형 검증했습니다.

**정수 모델 버전과 그리디 디코딩만 증명 대상이고 컨텍스트도 1,024토큰으로 제한되는 등 아직 연구 단계지만, 모델 라우팅·평가 파이프라인을 운영하며 "실제로 어떤 모델이 응답했는지"를 외부에 증명해야 하는 상황이 있다면 이 방향의 진전을 눈여겨볼 만합니다.** [GeekNews](https://news.hada.io/topic?id=36617)

### claude auth status·claude -p JSON에 로그인 만료 시각이 추가되고, 만료 10일 전부터 경고가 표시됩니다 (v2.1.318)

**저장된 claude.ai 로그인이 언제 끝나는지 `claude auth status`의 `loginExpiresAt` 필드와 `claude -p` JSON 결과의 `credential_expires_at` 필드로 확인할 수 있게 됐습니다.** 로그인 만료 10일 전부터는 `claude -p` 텍스트 출력에도 한 줄짜리 stderr 경고가 함께 표시됩니다.

```bash
# 터미널에서 로그인 만료 시각 확인
claude auth status

# claude -p JSON 출력에서 자격 증명 만료 시각만 추출
claude -p "ping" --output-format json | jq -r '.credential_expires_at'
```

**CI나 cron으로 `claude -p`를 비대화형으로 돌리는 자동화가 있다면, 로그인이 만료돼 파이프라인이 갑자기 멈추기 전에 이 필드나 stderr 경고로 미리 알아채고 재인증 일정을 잡아둘 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### mod의 `$.model.fork`에 effort를 지정해 부수 작업만 가볍게 돌릴 수 있습니다 (v2.1.318)

**mod 코드에서 `$.model.fork`를 호출할 때 이제 `effort` 옵션을 지정할 수 있어, 세션 전체가 `xhigh`나 `ultrathink`로 올라가 있어도 요약·분류처럼 가벼운 판단만 필요한 부수 작업은 `low` effort로 따로 돌릴 수 있습니다.** 결과에는 실제로 적용된 effort가 함께 반환되므로, 세션 effort와 무관하게 포크가 어떤 effort로 실행됐는지 바로 확인할 수 있습니다.

```js
// mod 코드 예시: 세션 effort와 무관하게 가벼운 부수 작업만 low effort로 실행
const result = await $.model.fork({
  prompt: "이 커밋 메시지를 한 줄로 요약해줘",
  effort: "low",
});
```

**세션 effort를 높게 설정해두고 복잡한 작업을 시키면서도, 그 안에서 mod가 돌리는 가벼운 보조 호출까지 같은 effort로 토큰을 쓰는 게 아깝다고 느꼈다면, 직접 만든 mod에 이 옵션을 적용해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 백그라운드 서브에이전트의 셸 명령이 3분 뒤 자동으로 백그라운드로 넘어가 prompt cache 만료를 막습니다 (v2.1.318)

**백그라운드로 돌리는 서브에이전트가 실행한 셸 명령이 3분을 넘기면, 모든 provider에서 그 명령을 자동으로 백그라운드로 옮겨 그 사이 prompt cache가 만료되지 않도록 바뀌었습니다.** 지금까지는 서브에이전트가 오래 걸리는 빌드나 테스트를 포그라운드로 붙들고 있으면, 그 사이 prompt cache가 만료돼 복귀 시 더 비싼 재처리가 필요한 경우가 있었습니다.

**빌드·테스트처럼 오래 걸리는 명령을 서브에이전트에 자주 맡긴다면, v2.1.318부터는 3분을 넘기는 명령을 직접 백그라운드로 보내지 않아도 prompt cache가 알아서 보호된다는 점을 기대할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### macOS 기본 `/bin/bash`에서 git commit·PR 생성이 더 안정적으로 동작합니다 (v2.1.318)

**Bash 도구가 macOS에 내장된 `/bin/bash`로 실행될 때, git commit과 pull request 생성의 신뢰성이 개선됐습니다.** zsh가 기본 셸인 macOS에서도 Claude Code의 Bash 도구 자체는 `/bin/bash`를 쓰는데, 지금까지 이 조합에서 커밋이나 PR 생성이 가끔 실패하거나 불안정하게 동작하는 경우가 있었습니다.

**macOS에서 Claude Code로 커밋이나 PR 생성을 자동화하다 가끔 원인을 알기 어려운 실패를 겪었다면, v2.1.318로 올려 이 부분이 안정화됐는지 확인해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `deniedMcpServers`가 URL로 매칭되는 Anthropic 제공 서버와 커넥터도 함께 차단합니다 (v2.1.318)

**`deniedMcpServers`에 URL을 등록해 차단 설정을 할 때, 이제 그 URL과 업스트림이 일치하는 Anthropic 제공 서버까지 함께 차단 대상에 포함되고, 클라우드 세션과 self-hosted runner의 커넥터도 세션에 그 커넥터 고유 URL이 주어지는 경우라면 같은 방식으로 차단할 수 있게 됐습니다.** 그 외의 커넥터는 여전히 이름으로 차단해야 합니다. 지금까지는 URL 기준 차단 목록이 Anthropic이 직접 제공하는 서버나 커넥터에는 적용되지 않아, 조직 정책으로 특정 업스트림을 막아도 Anthropic 제공 경로로는 우회될 가능성이 있었습니다.

**조직 차원에서 `deniedMcpServers`로 특정 MCP 서버의 접근을 막고 있다면, v2.1.318부터는 URL 기준 차단 범위가 Anthropic 제공 서버·커넥터까지 넓어졌다는 점을 정책 점검에 반영할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

- **Claude Code가 세션에서 만든 mod를 켤지 물을 때, 사용자가 답한 내용이 기록으로 남습니다.**
- **올바르지 않은 `~/.claude.json`을 비대화형 실행이 조용히 기본값으로 덮어쓰던 문제가 수정**돼, 이제 시작이 실패하며 복구 방법을 안내합니다 (anthropics/claude-code#87551).
- **`claude plugin validate`가 `claude plugin marketplace add`는 거부하는, 커스텀 이름을 쓴 마켓플레이스 파일을 통과시키던 문제가 수정**됐습니다.
