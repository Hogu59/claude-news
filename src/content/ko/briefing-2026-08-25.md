## 주요 신규 기능 & 실전 활용

### `/usage`에 Loops 세부 내역이 추가됩니다 (v2.1.243)

**`/usage`에 루프별 실행 횟수, 총 토큰, 실행당 토큰, 마지막 실행 시각을 보여주는 Loops 항목**이 추가돼, **폭주하거나 지나치게 자주 도는 `/loop` 작업을 한눈에 찾아낼 수** 있습니다.

```bash
/usage
# Loops 섹션에서 각 루프의 실행 횟수·누적 토큰·실행당 평균 토큰·마지막 실행 시각을 확인
```

**여러 `/loop` 작업을 상시 돌리고 있다면, 어느 루프가 예상보다 토큰을 많이 쓰는지 이 화면에서 바로 짚어낼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `promptCacheTtl`·`subagentPromptCacheTtl` — 메인 대화와 서브에이전트의 캐시 수명을 따로 관리합니다 (v2.1.243)

**API 키·클라우드 프로바이더 사용자가 메인 대화에는 1시간짜리 프롬프트 캐시를 유지하면서 서브에이전트는 5분 캐시에 머물게 하는 두 설정**이 추가됐습니다. 지금까지는 메인 대화든 서브에이전트든 캐시 수명을 하나로만 다뤄야 했다면, 이제 **긴 메인 세션의 캐시 적중률과 서브에이전트의 짧은 생명주기를 각각에 맞게 조정**할 수 있습니다.

**장시간 유지되는 메인 세션에서 여러 서브에이전트를 자주 띄우는 워크플로라면, 메인 대화의 캐시 비용은 줄이고 서브에이전트 쪽은 기존처럼 짧게 유지하는 조합을 시도해 볼 만합니다.** 정확한 설정 값 형식은 [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)와 공식 문서에서 확인하는 편이 안전합니다.

### Anthropic Console 계정으로 API 키 없이 로그인합니다 (v2.1.243)

```bash
/login
# "Sign in with your Console account" (권장)를 선택하면 API 키를 새로 만들지 않고도 로그인 가능
```

**API 키 발급 자체를 허용하지 않는 조직도 Anthropic Console 계정으로 바로 로그인**할 수 있는 옵션이 `/login`에 추가됐습니다. 함께 추가된 **`modelPicker` 설정으로는 조직이 `/model` 피커에 노출할 모델 목록을 순서·라벨과 함께 직접 큐레이션**할 수 있어(Vertex·Bedrock id 포함), **팀 전체가 승인된 모델만 고르게 하고 싶은 조직**에 유용합니다.

**세션마다 반복해서 일러주던 코드 리뷰 지침을 `agent.md` 파일 하나에 모아 프롬프트에 자동으로 주입**하자, **스파게티 코드와 부족한 주석·구조 문제가 눈에 띄게 줄었다는 사례**입니다. **2025년에는 컴파일조차 못 하던 생성 코드가 2026년에는 복잡한 구현과 버그 분석까지 해내지만, 정작 프로덕션 투입을 막아온 건 구조와 문서화 부족**이었다는 진단이 함께 나옵니다.

**Claude Code의 `CLAUDE.md`도 같은 발상으로 쓸 수 있습니다.** 매번 프롬프트에 반복해서 적던 코드 스타일·구조 규칙이 있다면, **`CLAUDE.md`에 한 번 정리해 두는 편이 세션마다 다시 설명하는 것보다 훨씬 효율적**입니다. [GeekNews](https://news.hada.io/topic?id=32833)

- **세션당 메모리 사용량이 약 40~70MB 줄어듭니다** — 번들 전체를 상주시키는 대신 코드를 온디맨드로 불러오는 방식으로 바뀌었습니다.
- **장시간 세션의 최대 메모리 사용량도 개선**됩니다 — 힙이 커질수록 런타임이 더 일찍 가비지 컬렉션을 수행합니다.
- **시작 시간이 개선**됩니다 — 샌드박스·MCP 초기화가 첫 화면 표시를 막지 않고, 단순 실행 시 서브커맨드 등록을 건너뛰며, 워크플로 탐색·설정·신뢰 저장소 처리 비용도 줄었습니다.
- **`/status`에 `Skipped sources` 줄이 추가**됩니다 — 관리형 설정 소스(예: `managed-settings.json`)가 있어도 더 우선순위 높은 소스에 밀려 적용되지 않았을 때 이를 알려줍니다.
- **`/mcp`·`/plugins`에서 조직이 인증을 관리하는 claude.ai 커넥터에 `managed` 표시**가 붙습니다.
- **`/tasks`와 에이전트 상세 화면에 서브에이전트가 실행된 모델과 effort 레벨이 함께 표시**됩니다.
- **Bedrock·Vertex·Foundry, 그리고 텔레메트리가 꺼진 환경에서도 `/model`·`/fast`·`/effort`가 턴이 끝날 때까지 기다리지 않고 즉시 적용**됩니다.
- **`/loop`에서 할 일이 없는 연속 웨이크업이 각각 출력되는 대신 터미널에서 한 줄로 접힙니다.**
- **macOS 컴퓨터 유즈가 데스크톱·Dock·Finder 창을 클릭할 때, 다른 앱과 동일하게 접근 권한 다이얼로그로 Finder 권한을 요구**합니다.
