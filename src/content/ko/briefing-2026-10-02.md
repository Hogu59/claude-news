## 주요 신규 기능 & 실전 활용

### Claude Mods와 첫 공식 모드 You should know — 플러그인이 더 깊은 동작까지 바꿀 수 있습니다 (v2.1.287)

**Claude Mods라는 새로운 플러그인 확장 지점이 추가되어, 플러그인이 Claude Code의 더 깊은 동작까지 수정할 수 있게 됐습니다.** 첫 번째 공식 모드로 You should know가 번들로 제공되는데, 사이드 에이전트가 작업을 지켜보다가 사용자나 Claude가 놓칠 수 있는 사항을 짚어주는 기능입니다.

```bash
# 텔레메트리가 켜진 공식(first-party) 세션에서 활성화
/plugin enable cc-plugin-you-should-know@builtin
```

**긴 리팩터링이나 복잡한 다단계 작업 중 사용자도 Claude도 놓칠 수 있는 엣지 케이스나 부작용을 사이드 에이전트가 대신 포착해주므로, 중요한 변경을 혼자 검토해야 하는 부담을 줄일 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Opus 4.7+·Fable, Bedrock·Vertex·Foundry·게이트웨이에서 1M 컨텍스트가 기본값이 됩니다 (v2.1.287)

**Opus 4.7 이상과 Fable 모델이 Bedrock, Vertex AI, Foundry, Claude 앱 게이트웨이에서 기존에 모델 ID 끝에 붙여야 했던 `[1m]` 접미사 없이도 기본적으로 100만 토큰 컨텍스트를 쓰도록 바뀌었습니다.** 기존 200K로 유지하고 싶다면 환경변수로 끌 수 있습니다.

```bash
# 100만 토큰 컨텍스트 대신 기존 200K를 유지하려면
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

**Bedrock·Vertex·Foundry 환경에서 대형 코드베이스를 다루는 조직이라면 별도 설정 없이 더 넓은 컨텍스트를 쓰게 되는 대신, 토큰 사용량과 비용이 예기치 않게 늘어날 수 있으니 예산을 관리 중이라면 이 환경변수를 미리 점검해둘 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.287**(10/1) 항목입니다.

- **에이전트 뷰에 `n:<text>` 필터가 추가**돼, 세션 이름과 작업(task)을 기준으로 바로 검색할 수 있습니다.
- **OpenTelemetry `user_prompt` 이벤트에 `prompt_text` 필드가 추가**됐습니다. `prompt`를 지우거나 마스킹하는 백엔드라면 이 필드도 함께 처리해야 합니다.
- **MCP 서버의 `alwaysLoad: false` 설정이 해당 서버의 모든 도구를 tool search 뒤로 미루도록** 바뀌었습니다.
- **Windows에서 Bash 도구 거부가 PowerShell 도구까지 꺼버릴 때 시작 경고가 추가**돼, Claude에게 셸 도구가 전혀 없는 상태로 진입하는 것을 미리 알 수 있습니다.
- **macOS·Linux의 self-hosted runner에 `gh api`(REST 전용)가 내장**돼, GitHub CLI가 설치되지 않은 머신에서도 Anthropic 관리형 git을 쓰는 세션이 바로 사용할 수 있습니다.
- **2025-11-25 프로토콜의 MCP 서버가 보내는 URL 프롬프트(로그인 등)를 지원**합니다. 업데이트 후 서버 연결이 끊겼다면 해당 MCP 설정에 `bareElicitationCapability: true`를 추가하면 됩니다.
