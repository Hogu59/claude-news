## 주요 신규 기능 & 실전 활용

### `claude --desktop` — CLI에서 데스크톱 앱으로 바로 전환합니다 (v2.1.285)

**터미널에서 작업하던 현재 디렉터리, 또는 `--continue`나 `--resume <id>`로 지정한 세션을 Claude 데스크톱 앱에서 곧바로 열 수 있게 됐습니다.**

```bash
claude --desktop
claude --desktop --resume <id>
```

**터미널에서 짧게 시작한 세션을 더 넓은 화면이나 아티팩트 뷰로 이어보고 싶을 때, 세션을 처음부터 다시 찾을 필요 없이 명령 한 번으로 데스크톱 앱으로 넘어갈 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `claude plugin configure` — 플러그인 옵션을 CLI에서 직접 관리합니다 (v2.1.285)

**플러그인의 옵션 목록과 아직 설정되지 않은 값을 보여주고, stdin으로 읽은 새 값을 `--values-stdin`으로 저장할 수 있는 명령이 추가됐습니다.** 번들로 포함된 `.mcpb` MCP 서버 자체의 설정값도 `claude plugin install --config`에 `<server>.<key>=<value>` 형식으로 넘기면, 설치 시점에 값을 지정해 `/plugin` → Configure 화면을 거치지 않고 바로 동작을 시작합니다.

```bash
claude plugin configure <plugin>
claude plugin install <plugin> --config server.apiKey=xxx
```

**CI 파이프라인이나 배포 스크립트로 플러그인을 자동 설치하는 팀이라면, 대화형 Configure 단계 없이 필요한 값을 설치 명령 한 줄에 담아 완전히 자동화할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.285**(9/29) 항목입니다.

- **`CLAUDE_CODE_DISABLE_WEB_FETCH` 환경변수가 추가**돼, WebFetch 도구 자체를 끌 수 있습니다.
- **`CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` 환경변수가 추가**돼, 타임아웃된 비스트리밍 폴백 요청의 재전송 횟수를 제한할 수 있습니다.
- **커스텀 `ANTHROPIC_BASE_URL` 뒤의 세션이 1M 컨텍스트를 지원하는 모델(Opus 4.7+, Sonnet 5+, Fable)의 100만 토큰 컨텍스트를 그대로 사용**하도록 바뀌었습니다. 게이트웨이가 200K에서 멈춘다면 `/autocompact 200k`를 실행하면 됩니다.
- **백그라운드로 돌린 Bash·PowerShell 명령이 시간 제한(기본 30분, 최대 2시간) 이후 자동으로 중단**되며, 중단되면 Claude에게 알림이 갑니다.
- **샌드박스 auto-allow가 `=`가 포함된 인라인 스크립트(`python3 -c`, `node -e`)마다 매번 승인을 요청하던 문제가 수정**됐습니다.
- **SSH로 플러그인·마켓플레이스를 설치·업데이트할 때 `GIT_SSH`나 git config의 `core.sshCommand`에 설정한 ssh 프로그램을 무시하던 문제가 수정**됐습니다.
