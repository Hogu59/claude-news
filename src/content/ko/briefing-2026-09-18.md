## 주요 신규 기능 & 실전 활용

### claude.ai 계정의 스킬·플러그인이 터미널 세션에도 동기화됩니다 (v2.1.275)

**claude.ai 계정으로 로그인한 터미널 세션에, 그 계정에서 활성화해 둔 스킬과 플러그인이 자동으로 동기화됩니다.** **웹에서 켜둔 스킬을 터미널에서 다시 설정할 필요가 없어지는 대신, 원치 않는 동기화라면 명시적으로 꺼야 합니다.**

```json
// settings.json
{
  "syncClaudeAiSkills": false,
  "syncClaudeAiPlugins": false
}
```

**claude.ai에서 팀 공용 스킬을 관리하고 있다면 터미널 세션마다 따로 설치할 필요가 없어지지만, 회사 계정과 개인 실험용 스킬을 분리해서 쓰고 싶다면 이 옵션으로 동기화를 꺼두는 편이 안전합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 턴을 즉시 종료하고 큐에 쌓인 메시지를 한 번에 보내는 send-now 키가 추가됩니다 (v2.1.275)

**ctrl+enter 또는 ctrl+x ctrl+s를 누르면 현재 진행 중인 턴을 바로 중단하고, 그동안 큐에 쌓아둔 메시지를 한꺼번에 전송합니다.** **전송된 메시지와 대기 중인 메시지는 모델이 실제로 받을 때까지 회색으로 표시돼 상태를 구분할 수 있습니다.**

**긴 작업이 진행되는 동안 후속 지시를 여러 번 큐에 쌓아두는 습관이 있다면, 이 단축키로 다음 지시를 기다리지 않고 바로 반영시킬 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `/plugin install <plugin> --marketplace <source>`로 마켓플레이스 추가와 설치를 한 번에 처리합니다 (v2.1.275)

**플러그인을 설치할 때 마켓플레이스가 아직 등록돼 있지 않으면, 명령 하나로 마켓플레이스 추가까지 제안받을 수 있습니다.**

```bash
# 마켓플레이스가 없어도 설치 명령 하나로 추가 여부를 물어봅니다
claude plugin install my-plugin --marketplace https://github.com/org/marketplace
```

**사내 플러그인 마켓플레이스를 새로 세팅할 때마다 `marketplace add`와 `install`을 따로 실행하던 팀이라면, 온보딩 문서를 이 한 줄 명령으로 단순화할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
