## 주요 신규 기능 & 실전 활용

### `ultrathink`를 턴이 진행되는 중간에 입력해도 남은 턴의 effort가 올라갑니다 (v2.1.311)

**인터랙티브 터미널에서 `ultrathink`는 이제 Anthropic API를 통한 Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1 턴을 xhigh effort로 실행하도록 바뀌었고, Claude가 이미 작업 중인 동안 입력해도 그 턴의 나머지 부분에 적용됩니다.** 지금까지는 턴을 시작할 때만 effort를 조정할 수 있었습니다. 덧붙여 `ultrathink`가 effort를 실제로 올릴 수 있는 위치에서만 무지개색으로 표시되도록 바뀌어, 인용부호 안이나 파일 경로의 일부로 쓰인 경우에는 더 이상 색이 입혀지지 않습니다.

```bash
# 작업 중인 턴에 입력하면 남은 턴부터 xhigh effort로 전환
ultrathink
```

**복잡한 리팩터링이나 디버깅 중 Claude의 응답이 부족하다고 느껴지는 순간이 있다면, 턴을 새로 시작하지 않고 그 자리에서 `ultrathink`를 입력해 즉시 effort를 끌어올려 보는 것이 효율적입니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Claude Tag Skills 뷰 — Slack 채널에서 어떤 스킬이 쓰이고 어떤 스킬이 방치되는지 확인합니다 (v2.1.311)

**Claude Tag 분석에 Skills 뷰가 추가돼, Slack 채널에서 Claude가 각 첨부 스킬을 얼마나 자주 실행하는지와 전혀 쓰이지 않는 스킬이 무엇인지 admin 설정의 Usage 링크를 통해 확인할 수 있습니다.** 지금까지는 Slack에 붙여둔 스킬이 실제로 쓰이고 있는지 알 방법이 따로 없었습니다.

**Claude Tag로 여러 스킬을 Slack 채널에 배포해두고 있다면, Skills 뷰로 사용 빈도가 낮은 스킬을 찾아 정리하거나 홍보가 필요한 스킬을 가려내는 데 활용할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)
