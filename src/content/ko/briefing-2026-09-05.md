## 주요 신규 기능 & 실전 활용

### `/skill-doctor` — 쓰이지 않는 스킬과 그 컨텍스트 비용을 보여줍니다 (v2.1.261)

**로드된 스킬 가운데 실제로는 쓰이지 않는 것과, 그 스킬이 컨텍스트에서 차지하는 비용을 보여주는 `/skill-doctor`가 추가**됐습니다. **이를 참고해 불필요한 스킬을 정리(prune)할 수 있습니다.**

```bash
/skill-doctor
# 로드된 스킬 목록과 각 스킬의 컨텍스트 사용량, 실제 호출 여부가 표시됩니다
```

**여러 플러그인·스킬을 누적해서 쓰다 보면 정작 한 번도 안 쓰는 스킬이 매 턴 컨텍스트를 갉아먹기 쉬운데, `/skill-doctor`로 이런 항목을 찾아 제거하면 프롬프트 캐시 효율과 컨텍스트 여유를 함께 확보**할 수 있습니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `bashOutputMaxChars`/`taskOutputMaxChars` — 명령·백그라운드 작업 출력을 최대 128K자까지 인라인으로 받습니다 (v2.1.261)

**명령 실행과 백그라운드 작업의 출력이 일정 길이를 넘으면 파일로 저장되고 요약만 인라인으로 전달되던 기존 방식에서, 인라인으로 받을 수 있는 한도를 최대 128K자까지 직접 올릴 수 있는 `bashOutputMaxChars`·`taskOutputMaxChars` 설정이 추가**됐습니다.

```json
// settings.json
{
  "bashOutputMaxChars": 131072,
  "taskOutputMaxChars": 131072
}
```

**긴 빌드 로그나 테스트 출력을 파일로 우회하지 않고 바로 분석하고 싶을 때, 이 설정으로 인라인 전달 한도를 넉넉하게 늘려둘 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### `--append-subagent-system-prompt-file` — 커맨드라인 길이 제한 없이 긴 서브에이전트 프롬프트를 전달합니다 (v2.1.261)

**서브에이전트 시스템 프롬프트에 내용을 추가할 때 지금까지는 커맨드라인 인자로만 넘길 수 있어 셸의 인자 길이 제한에 걸리기 쉬웠는데, 파일에서 읽어오는 `--append-subagent-system-prompt-file` 옵션이 추가**됐습니다.

```bash
claude --append-subagent-system-prompt-file ./prompts/reviewer-guidelines.md
```

**팀의 코드 리뷰 기준이나 아키텍처 가이드라인처럼 분량이 큰 문서를 서브에이전트에 통째로 붙이고 싶을 때, 이제 별도 파일로 관리하면서 커맨드라인 인자 길이 걱정 없이 전달**할 수 있습니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### MCP는 실제로 어떻게 프로덕션에서 쓰이고 있는가 — Ask HN 댓글 총정리 (9/4)

**MCP가 출시 초기에는 큰 관심을 받았지만 실제 프로덕션 사용 사례는 접하기 어렵다는 질문에, 실무자들의 답변이 모였습니다.** **사내 운영 진단, SaaS 연동, 음성 에이전트, 고객용 챗봇 등에서 일반 API나 CLI 직접 연동보다 도구 탐색과 통합 비용을 줄이는 용도로 MCP가 쓰이고 있다**는 것이 핵심입니다.

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.261**(9/4) 항목입니다.

- **`/status`·`claude doctor`에 조직 정책이 로드되지 못한 이유를 보여주는 "Organization policy" 줄이 추가**됩니다. 예를 들어 프록시가 엔드포인트를 통과시키지 않는 경우가 여기 표시됩니다.
- **위험한 `rm -rf` 안전 프롬프트가 위치 매개변수에 대한 `rm -rf`와, 큰따옴표로 감싼 `sh -c` 스크립트 안의 `rm -rf`까지 잡아내도록 개선**됩니다.
- **API가 응답 헤더를 전혀 보내지 않을 때, 재시도 대기 시간이 3분 대신 `API_TIMEOUT_MS`(기본 10분)까지 늘어나고** 무엇을 바꿔야 하는지 메시지로 안내합니다.
- **프롬프트 입력창의 단어 단위 편집 단축키가 Bash와 동일하게 바뀝니다.** Ctrl+W는 공백까지 삭제하고, Alt+F·Alt+D는 단어 끝에서 멈추며 구두점을 단어 경계로 취급합니다. `keybindingFlavor` 설정은 더 이상 효과가 없습니다.
- [VSCode] **MCP 서버 다이얼로그에 서버 추가 폼과 제거 기능이 생겨**, IDE를 벗어나지 않고 MCP 서버를 추가·삭제할 수 있습니다.
- [VSCode] **권한·질문 프롬프트에 접기 버튼이 추가**되어, 프롬프트를 닫지 않고도 뒤에 있는 대화를 스크롤해서 읽을 수 있습니다.
