## 주요 신규 기능 & 실전 활용

### 내장 "Concise" 출력 스타일이 추가됩니다 (v2.1.237)

**결과부터 먼저 말하고 서두·내레이션은 생략하면서도, 작업 자체는 기존과 똑같이 철저하게 수행하는 내장 출력 스타일**이 추가됐습니다. `/config`의 Output style 항목에서 선택할 수 있습니다.

```bash
# /config 실행 후 Output style 메뉴에서 "Concise" 선택
/config
```

**Claude Code의 응답이 장황하게 느껴져 왔거나, CI 로그·스크립트 출력으로 결과만 빠르게 확인하고 싶은 워크플로**라면 바로 적용해 볼 만합니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `keybindingFlavor` — Bash처럼 Ctrl+W가 동작하는 readline 모드 (v2.1.238)

**프롬프트 입력에서 Ctrl+W의 동작 방식을 지정하는 `keybindingFlavor` 설정**이 추가됐습니다. **`"readline"`으로 설정하면 Ctrl+W가 Bash와 동일하게 이전 공백까지 지우고**, 기본값 `"classic"`은 기존 동작 그대로입니다.

```json
// settings.json
{
  "keybindingFlavor": "readline"
}
```

**터미널에서 Bash 단축키에 익숙한 개발자라면, 이 설정 하나로 Claude Code 프롬프트 입력에서도 같은 손 습관을 그대로 쓸 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### 장시간 세션의 무한 메모리 증가 문제가 해결됩니다 (v2.1.238)

**서브에이전트 도구 결과가 최근 표시 창(recent display window)을 벗어나면 메모리에서 해제**되도록 고쳐, **오래 열어 둔 인터랙티브 세션에서 메모리가 끝없이 늘어나던 문제**가 수정됐습니다.

**하루 종일 하나의 세션을 켜 두고 여러 서브에이전트를 반복해서 돌리는 워크플로**라면, 이번 수정으로 **세션을 장시간 유지해도 메모리 사용량이 더 안정적으로 유지**됩니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### self-hosted runner 운영 옵션이 넓어집니다 (v2.1.238)

```bash
# SIGTERM을 받으면 연결된 세션은 계속 서비스하다가, 지정한 시간 뒤 남은 세션을 정리하고 종료
claude self-hosted-runner --defer-shutdown-max-min 15

# 연결마다 새로 발급된 Proxy-Authorization 헤더가 필요한 egress 프록시 환경
claude self-hosted-runner --proxy-authorization-command "./mint-proxy-token.sh"
```

**`--defer-shutdown-max-min`은 러너를 재배포할 때 이미 붙어 있는 세션을 강제 종료하지 않고 유예 시간을 주며, `--proxy-authorization-command`/`--proxy-authorization-file`은 매 연결마다 새 토큰을 요구하는 egress 프록시 뒤에서 러너를 운영**할 수 있게 해줍니다.

**self-hosted runner를 배포·롤링 업데이트하거나 사내 프록시 뒤에서 운영하고 있다면, 두 옵션 모두 운영 중 유용하게 쓸 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### zsh 셸 조건문에 대한 Bash 도구 권한 검사가 개선됩니다 (v2.1.238)

**zsh 특유의 문법을 쓰는 셸 조건문에 대해 Bash 도구의 권한 검사 정확도가 개선**됐습니다. **zsh를 기본 셸로 쓰면서 Claude Code가 조건문 명령을 잘못 판단해 불필요한 승인 프롬프트를 띄우던 경험**이 있었다면, 이번 개선으로 그런 오탐이 줄어듭니다. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**프로젝트 `.mcp.json`의 `headersHelper`와, 프로젝트·플러그인 에이전트 파일에 정의된 인라인 MCP 서버의 `headersHelper` 실행에 해당 폴더의 trust 다이얼로그 수락이 전제 조건으로 추가**됐습니다(`claude -p`도 동일하게 적용). 또한 **프로젝트 `.mcp.json`·플러그인·에이전트 파일에서 오는 `headersHelper`는 상속된 자격증명 환경변수 없이 실행**되며, **user·managed·claude.ai 스코프 헬퍼는 Claude 설정 디렉터리에서 실행**됩니다.

**신뢰하지 않은 프로젝트를 열었을 때 `.mcp.json`에 심어진 `headersHelper`가 세션이 이미 보유한 자격증명 환경변수에 접근하는 경로를 차단**하는 하드닝입니다. MCP 서버 연동에 `headersHelper`를 쓰고 있다면, **v2.1.238부터는 trust 다이얼로그를 먼저 수락해야 실행된다는 점**을 참고하세요. [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

**컴플라이언스 요구 때문에 Managed Agents를 self-hosted sandbox 구성으로 운영해 온 팀이라면, 이번 업데이트로 클라우드 구성과의 기능 격차가 좁혀집니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

- **플러그인 마켓플레이스의 `headersHelper`**가 카탈로그·동일 출처 아카이브 fetch용 HTTP 헤더(예: 단기 토큰)를 발급합니다 — **설치·업데이트 시 명령이 먼저 표시된 뒤 `[y/N]`(또는 `-y`)로 확인**을 거칩니다.

- **풀스크린에서 Ctrl+L·Cmd+K가 항상 화면만 다시 그리도록 바뀌었습니다** — 더블 프레스로 `/clear`를 실행하던 단축키가 제거돼, 1행짜리 nvim 터미널에서 자동 `/clear` 루프가 걸리던 문제도 함께 사라졌습니다.
- **크로스세션 메시징에서 인바운드를 거부하는 세션(`crossSessionInbound: "refuse"` 등)에 보내면, 조용히 성공한 것처럼 보이는 대신 발신자에게 "거부됨"이 통지**됩니다.
- **수신함이 메시지를 처리하지 못하는 세션(레이트 리밋·큐 가득 참)에 보내도, 메시지가 조용히 사라지는 대신 발신 세션에 알림**이 갑니다.
