## 주요 신규 기능 & 실전 활용

### Claude Mods teammate API `agent.spawn` 추가 — 출시 이틀 만에 안정화 패치도 대거 반영 (v2.1.289)

**플러그인이 teammate 에이전트를 직접 생성할 수 있는 `agent.spawn`이 추가되고, 플러그인 훅 이벤트 전반에서 동일하게 유지되는 agent id, `$.agent.list()`의 idle·waiting 상태 조회가 함께 들어왔습니다.** 10/1 출시된 Claude Mods가 Claude Code 내부 동작까지 깊게 건드리는 확장 지점인 만큼, 같은 릴리스에서 모드가 그린 UI가 멈추거나 세션 전체가 죽는 문제, 플러그인 핫 리로드 실패, 환경변수 접두사 뒤에 명령이 숨어 권한 거부 규칙을 피해가는 문제 등 20여 건의 안정성 버그도 한꺼번에 수정됐습니다.

```bash
# 모드/플러그인 코드에서 teammate 에이전트 생성
$.agent.spawn(...)
```

**사이드 에이전트나 teammate를 활용하는 모드를 개발 중이라면 `agent.spawn`으로 여러 에이전트를 조율하는 패턴을 시도해볼 만하며, 이미 Mods를 쓰고 있다면 이번 업데이트로 체감 안정성이 크게 나아졌을 것입니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.289**(10/3) 항목입니다.

- **`Read` 거부 규칙이 심볼릭 링크를 통해 IDE에서 @멘션·변경·선택된 파일에는 적용되지 않던 문제가 수정**됐습니다.

- **로컬 폴더 마켓플레이스에서 설치한 플러그인의 `plugin list`·`plugin eval`·`plugin update`가 오래된 사본을 보여주던 문제와, 심링크된 `--plugin-dir`의 핫 리로드 문제가 수정**됐습니다.

- **사용자가 설치한 플러그인이 조직이 관리하는 MCP 서버의 로그인 도구 설명을 임의로 바꿔 쓸 수 있던 문제가 수정**됐습니다.
