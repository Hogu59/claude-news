## 주요 신규 기능 & 실전 활용

### 유휴 대화를 캐시 만료 전에 자동으로 압축합니다 (v2.1.299)

**터미널 세션에서 20만 토큰이 넘는 대화를 약 54분 동안 가만히 두면, 1시간짜리 프롬프트 캐시가 만료되기 전에 자동으로 압축되는 기능이 추가됐습니다.** 지금까지는 자리를 비운 사이 캐시가 만료되면 다음 메시지를 보낼 때 전체 대화를 다시 처리해야 해 응답이 느려지고 비용도 더 들었는데, 이제는 캐시가 살아있는 동안 미리 압축을 끝내둡니다.

```bash
# 유휴 압축이 시작되는 최소 토큰 수(기본 20만)를 조정
export CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS=100000
```

```jsonc
// settings.json에서 유휴 압축을 완전히 끄기
{ "idleCompaction": false }
```

**큰 작업을 띄워두고 자리를 비우는 일이 잦다면, 별도 설정 없이도 다음 메시지가 더 빨리 처리되는 효과를 바로 체감할 수 있으며, 압축 시점이나 기능 자체를 조정하려면 위 환경변수와 설정을 v2.1.290 이상에서 사용할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### AWS Claude Platform에 `/advisor`가 추가됐습니다 (v2.1.300)

**AWS의 Claude Platform에서 `/advisor`, `advisorModel` 설정 또는 `--advisor` 플래그로 조언자(advisor)를 직접 고르기 전까지는 어떤 advisor도 실행되지 않도록 하는 기능이 추가됐습니다.** 조직이 advisor 기능 자체를 쓰지 않게 하려면 `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`로 완전히 끌 수 있습니다.

```bash
# AWS Claude Platform에서 advisor 기능을 완전히 비활성화
export CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1
```

**AWS 기반 Claude Platform 환경을 운영하고 있다면, advisor가 기본으로 켜져 있지 않다는 점과 끄는 방법을 미리 알아두면 조직 정책에 맞게 바로 적용할 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

- **(v2.1.299) `CLAUDE_CODE_DISABLE_FILE_MENTIONS` 환경변수가 추가**돼, Claude는 `@` 파일 멘션의 경로만 받아 자신의 파일 도구로 읽고, 파일 내용 자체는 프롬프트에 바로 포함되지 않습니다.
- **(v2.1.299) agent view에 `/effort`·`/fast`가 추가**돼, 새 세션이 시작될 때의 기본값을 지정할 수 있고, 아무 값 없이 입력하면 선택 피커가 열립니다.
- **(v2.1.299) `--safe-mode`로 시작한 백그라운드 세션은 agents view의 미리보기 패널에 safe mode 표시가 추가**됩니다.
- **(v2.1.299) `claude self-hosted-runner orchestrator`에 `--shutdown-drain-sec`가 추가**돼, SIGTERM을 받으면 진행 중인 polling과 spawn 훅이 지정한 시간만큼 마무리할 여유를 갖습니다.
- **(v2.1.300) OpenTelemetry `api_request` 이벤트에 `cache_creation_5m_tokens`·`cache_creation_1h_tokens`가 추가**돼, 캐시 쓰기를 수명별로 나눠 확인할 수 있습니다.
- **(v2.1.300) 더 작은 auto-compact 윈도우를 선택했을 때 `/autocompact`가 높은 토큰 사용량을 잘못 경고하던 문제가 수정**됐습니다.
