## 주요 신규 기능 & 실전 활용

### Claude 아티팩트를 Mac·Windows 데스크톱 앱으로 설치하는 베타 기능이 공개됐습니다 (11/24)

**지금까지 Claude로 만든 아티팩트는 Claude 안에서만 열어볼 수 있었는데, Anthropic이 공식 가이드에서 아티팩트를 고유 아이콘과 별도 창을 가진 독립형 Mac·Windows 앱으로 설치하는 기능을 베타로 공개했습니다.** 설치된 앱은 다른 사람과 공유할 수 있고, 원본 아티팩트를 수정하면 앱도 자동으로 업데이트되며, 알림을 보내거나 메뉴 바·시스템 트레이에 항목을 추가할 수도 있습니다. 모든 플랜에서 쓸 수 있고 Team은 기본으로 켜져 있으며(전체 컴퓨터 접근 권한은 꺼짐), Enterprise는 소유자가 켜야 합니다. 앱은 브라우저 수준 권한으로 시작하지만, 프로그램 실행이나 파일 읽기·수정·삭제를 매번 묻지 않는 "전체 컴퓨터 접근" 권한을 본인이 만든 앱(Team·Enterprise는 조직 구성원이 만든 앱도)에 줄 수 있습니다. Claude Docs·Slides·Sheets 등 일부 아티팩트는 설치할 수 없고, HIPAA-ready 조직과 하이브리드 배포 환경에서는 쓸 수 없으며, Anthropic이 설치 전 앱을 검토하지 않으므로 전체 접근 권한은 신뢰하는 앱에만 줘야 한다고 안내합니다.

```text
1. Claude에 만들고 싶은 앱을 설명
2. 아티팩트로 실행해 확인
3. Share 메뉴 → "Install as app" 클릭
   → 별도 창·아이콘을 가진 독립 앱 생성, 원본 수정 시 자동 업데이트
```

**사내 도구나 개인 유틸리티를 아티팩트로 만들어 쓰고 있었다면, 이제 Claude 창을 계속 띄워두는 대신 독립 앱으로 설치해 메뉴 바·알림까지 활용해볼 만하며, 전체 컴퓨터 접근 권한만큼은 직접 만들었거나 신뢰하는 앱에만 켜두는 편이 안전합니다.** [Anthropic 공식 가이드](https://claude.com/resources/articles/install-as-app)

## 개발자 워크플로우 팁

### MCP 서버가 배포한 skill이 `/` 메뉴에 `server:skill`로 바로 표시됩니다 (베타, v2.1.332)

**11/24 브리핑에서 다룬 Skills over MCP 발표(서버가 다단계 작업 가이드를 skill로 함께 배포)가 하루 뒤 v2.1.332로 실제 클라이언트에 반영돼, MCP 서버가 배포한 skill이 `/` 메뉴에 `server:skill` 형태로 구분되어 뜨고 그 서버가 아닌 다른 skill은 원래 이름을 그대로 유지합니다.** 발표 다음 날 바로 동작으로 이어진 셈이라, 어떤 서버의 skill인지 이름만 보고도 구분할 수 있게 됐습니다.

**MCP 서버를 여러 개 연결해 쓰면서 서버마다 배포한 skill이 뒤섞여 어떤 게 어디서 왔는지 헷갈렸다면, v2.1.332로 올라간 뒤 `/` 메뉴에서 `server:skill` 접두사만 봐도 바로 구분할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 스킬·명령의 inline shell 명령을 가로채 거부할 수 있는 `PreSkillShellCommand` 훅이 추가됐습니다 (v2.1.332)

**지금까지 스킬이나 커스텀 명령 안에 박힌 inline shell 명령은 로드되는 순간 그대로 실행됐는데, 이번 릴리스부터 `PreSkillShellCommand` 훅 이벤트로 그 실행을 가로채 거부할 수 있습니다.** 참고로 2.1.331 이전 버전에서는 이 훅을 이름으로 등록한 설정 파일이 있으면 시작 시 대화상자가 뜹니다.

```json
// settings.json에 PreSkillShellCommand 훅을 등록해
// 스킬·명령이 로드될 때 inline shell 명령을 검사·거부
{
  "hooks": {
    "PreSkillShellCommand": [
      { "hooks": [{ "type": "command", "command": "/path/to/validator.sh" }] }
    ]
  }
}
```

**출처가 불분명한 스킬이나 플러그인을 조직에서 설치하도록 허용하고 있다면, `PreSkillShellCommand` 훅으로 로드 시점의 inline shell 명령을 먼저 검사하는 안전장치를 걸어둘 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.332**(11/25) 항목 중 위에서 다루지 않은 것들입니다.

- **`claude auth login`이 claude.ai 로그인을 저장하지 못했을 때 "Login successful."이라고 잘못 알리던 문제가 수정**돼, 이제 exit 1로 종료하며 잠긴 락 파일이나 디스크 용량 부족 같은 확인할 점을 알려줍니다.
- **아무도 쓰지 않는 named pipe(잠긴 비밀 관리자가 마운트한 `.env` 등)를 Read·@-mention·압축이 계속 기다리며 멈추던 문제가 수정**돼, 20초 뒤 실패하도록 바뀌었습니다.
- **이벤트 스트림이 끊긴 뒤 새 엔드포인트로 돌아오거나 끝내 돌아오지 않은 SSE MCP 서버가, 수동 재연결 전까지 모든 도구 호출을 멈추거나 거부하던 문제가 수정**됐습니다.
- **복사에 실패한 다운로드 플러그인 때문에 `~/.claude/plugins/cache`에 `temp_*` 폴더가 계속 쌓이던 문제가 수정**됐습니다.
- **탭 모드 음성 입력이 마이크를 켜 두는 시간이 무음 15초·최대 2분에서 무음 60초·최대 10분으로 늘었고**, 끝나도 전송되지 않은 텍스트는 남아 다음 탭에서 이어 쓸 수 있습니다.
