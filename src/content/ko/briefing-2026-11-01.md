## 주요 신규 기능 & 실전 활용

### `CLAUDE_CODE_SUBAGENT_EFFORT`로 서브에이전트의 기본 effort를 메인 세션과 따로 지정할 수 있습니다 (v2.1.316)

**지금까지 서브에이전트는 effort를 따로 지정하지 않으면 메인 세션의 effort를 그대로 물려받았는데, 이제는 이 환경변수로 서브에이전트 전용 기본값을 따로 둘 수 있습니다.** 다른 곳에서 effort를 지정하지 않은 서브에이전트에만 적용되며, 명시적으로 effort를 지정한 서브에이전트나 메인 세션에는 영향을 주지 않습니다.

```bash
# 메인 세션은 ultrathink로 올려 쓰되, 서브에이전트는 기본 effort로 묶어둠
export CLAUDE_CODE_SUBAGENT_EFFORT=medium
```

**메인 세션 effort를 xhigh나 ultrathink로 올려 복잡한 작업을 시키면서도, 그 아래에서 수십 개씩 뜨는 서브에이전트가 전부 같은 effort로 토큰을 쓰는 게 아깝다고 느꼈다면, 이 환경변수로 서브에이전트만 저렴한 effort에 묶어두는 것이 비용 관리에 효과적입니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### Claude apps gateway에 그룹이 함께 쓰는 월별 예산 풀이 추가됐습니다 (v2.1.316)

**각 구성원의 개별 한도 위에, 그룹 전체가 공유하는 월별 예산 하나를 추가로 둘 수 있게 됐습니다.** spend limits admin API의 `pooled_budget` 필드로 설정하며, 개인별로는 한도가 남아 있어도 그룹 전체 예산이 소진되면 추가 지출을 막는 식으로 동작합니다.

```json
// spend limits admin API 설정 예시
{
  "group_id": "eng-team",
  "pooled_budget": 5000
}
```

**팀 전체의 Claude 지출을 개인 한도만으로는 통제하기 어려웠던 조직이라면, 이번에 추가된 그룹 예산 풀로 팀 단위 상한선을 하나 더 둘 수 있다는 점을 admin 설정에서 확인해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 개발자 워크플로우 팁

### `CLAUDE_CODE_DISABLE_ULTRATHINK`로 `ultrathink` 키워드 자체를 끌 수 있습니다 (v2.1.316)

**`ultrathink`가 턴 중간에 입력해도 즉시 남은 턴의 effort를 끌어올리도록 범위가 넓어진 지 며칠 만에, 이 키워드를 조직 차원에서 통째로 끌 수 있는 스위치가 추가됐습니다.** 여러 사람이 같은 환경을 공유하거나, 문서·커밋 메시지에 우연히 이 단어가 들어가 effort가 예기치 않게 치솟는 상황을 막고 싶을 때 쓸 수 있습니다.

```bash
export CLAUDE_CODE_DISABLE_ULTRATHINK=1
```

**비용을 엄격히 관리해야 하는 공유 환경이나 CI에서 Claude Code를 돌리고 있다면, 누군가 습관적으로 `ultrathink`를 입력해 effort가 치솟는 상황을 이 환경변수로 원천 차단해둘 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `SHELLOPTS`가 export돼 있으면 Bash 도구로 실행한 스크립트가 첫 명령 뒤에 멈춰버리던 문제가 수정됐습니다 (v2.1.316)

**셸 설정이나 CI 환경에서 `set -o`로 켠 옵션들을 `SHELLOPTS`로 자식 프로세스에 물려주는 경우가 있는데, 이 환경변수가 export된 상태에서는 Bash 도구로 실행한 스크립트가 첫 번째 명령만 실행하고 멈춰버리는 문제가 있었습니다.** 원인을 모르면 스크립트 자체가 잘못됐다고 오해하기 쉬운 결함이었습니다.

**스크립트가 중간에서 이유 없이 멈추는 것을 겪었는데 원인을 못 찾았다면, `SHELLOPTS`를 export하는 셸 설정이 있었는지부터 의심해보고 v2.1.316으로 올려볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### 대형 저장소에서 `/diff`가 갱신될 때마다 돌리던 전체 저장소 git 명령이 하나 줄었습니다 (v2.1.316)

**`/diff`가 화면을 새로 그릴 때마다 저장소 전체를 훑는 git 명령을 보통 하나 덜 실행하게 됐고, git이 느리게 응답할 때는 갱신 간격을 자동으로 늘립니다.** 지금까지는 대형 모노레포에서 `/diff`를 열어두면 매 갱신마다 git 명령이 쌓여 체감 속도가 느려지는 경우가 있었습니다.

**수만 개 파일 규모의 모노레포에서 `/diff`를 자주 열어두고 작업한다면, v2.1.316부터 갱신이 눈에 띄게 가벼워졌는지 확인해볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.316**(10/31) 항목입니다.

- **`managed.policy_mode: layered`가 추가**돼, 개발자에게 매칭되는 정책 하나만 적용되던 기존 방식과 달리 매칭되는 모든 정책이 아래쪽부터 차례로 병합 적용됩니다.
- **Bedrock 업스트림에 `guardrail.input_tagging`이 추가**돼, Amazon Bedrock guardrail의 prompt attack 필터가 요구하는 입력 태그로 프롬프트를 감싸줍니다. `all_messages_and_system`을 쓰면 시스템 프롬프트에도 태그가 붙습니다.
- **`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`이 추가**돼, 서로를 인증하는 교차 인증서가 루프 형태인 사설 CA 환경에서 그 인증서들을 지우지 않고 유지할 수 있습니다.
