## 개발자 워크플로우 팁

### 에이전트 팀을 켠 상태에서도 Code Mode를 쓸 수 있게 됐습니다 (v2.1.326)

**지난 11/12 브리핑에서 다룬 실험 기능 Code Mode(여러 도구 호출을 JavaScript로 묶어 한 번에 실행하는 기능)가, 지금까지는 agent teams 기능과 함께 켤 수 없었는데 이번 릴리스부터 함께 쓸 수 있도록 통합됐습니다.** 이미 Code Mode를 켜둔 상태였다면, 팀 기능이 켜진 세션은 이제 시작할 때부터 자동으로 Code Mode로 시작됩니다.

**여러 서브에이전트를 팀으로 묶어 운영하면서 Code Mode의 왕복 지연 감소 효과도 함께 누리고 싶었다면, v2.1.326으로 올린 뒤 별도 설정 없이 두 기능을 동시에 켜볼 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### `--allowedTools`·`--disallowedTools`·`--tools`에 불완전한 규칙을 적으면 이제 시작할 때 경고가 뜹니다 (v2.1.326)

**권한 규칙을 완전한 형태로 적지 않으면(예: 도구 이름만 쓰고 괄호 안 패턴을 빠뜨리는 경우), 지금까지는 그대로 조용히 무시됐는데 이제는 Claude Code를 시작할 때 어떤 항목이 완전한 규칙처럼 보이지 않는지 경고로 알려줍니다.**

```bash
# 예: 괄호 안 패턴이 빠진 불완전한 규칙
claude --allowedTools "Bash" --disallowedTools "Read(./secrets"
```

**CI 스크립트나 셸 함수로 `--allowedTools`·`--disallowedTools` 값을 조립해 쓰고 있다면, v2.1.326부터 뜨는 이 시작 경고를 눈여겨볼 만합니다. 지금까지 규칙이 조용히 무시돼 의도한 대로 동작하지 않았던 경우를 바로 찾아낼 수 있습니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

### OpenTelemetry 리소스 속성에 호스트 정보를 넣는 `OTEL_RESOURCE_INCLUDE_HOST`가 추가됐습니다 (v2.1.326)

**이 환경변수를 켜면 OpenTelemetry로 내보내는 리소스 속성에 `host.name`과 `host.id`가 추가됩니다.** 기본값은 꺼짐입니다.

```bash
# OpenTelemetry 리소스 속성에 host.name, host.id를 포함하고 싶을 때
export OTEL_RESOURCE_INCLUDE_HOST=1
```

**여러 머신에서 Claude Code를 OpenTelemetry로 모니터링하면서 어느 호스트에서 난 이벤트인지 구분이 안 돼 불편했다면, v2.1.326부터 이 환경변수로 호스트 단위 구분을 바로 추가할 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 보안/제한 이슈

### Claude 서비스 현황 — Claude Meetings 참가 오류가 진행 중이고, iOS 앱 로그인 오류는 해결됐습니다

**공식 status.claude.com을 직접 확인한 결과, 오늘(11/17) 새로 보고된 인시던트는 없지만, 11/16 15:10 UTC부터 시작된 Claude Meetings(베타) 참가 오류가 아직 해결되지 않았습니다.** 새로운 통화에 Claude가 참가하지 못하는 문제로, 자동 참가(Auto-join) 기능은 일시 중단됐고 수동으로 추가하는 경우도 영향을 받습니다. 진행 중인 통화와 핵심 기능은 영향받지 않으며, 가장 최근 업데이트(11/16 18:10 UTC)에서는 일부 통화에서 여전히 참가가 안 될 수 있고 완전 해결까지 시간이 더 걸릴 것으로 안내하고 있습니다. 한편 지난 11/16 브리핑에서 진행 중으로 다룬 Claude iOS 앱의 Apple 로그인 가입 오류는 11/16 19:52 UTC에 해결 공지가 나와, 사흘 넘게 이어진 끝에 마무리됐습니다. 이 외에 11/16 07:32~08:45 UTC에는 Claude Sonnet 5.5·Fable 5.2 요청 오류가 잠시 늘어난 인시던트도 있었으나 빠르게 해결됐습니다. claude.ai는 이런 이력 때문에 여전히 Degraded Performance로 표시되고 있고, Claude API·Claude Code·Console·Cowork·Government는 모두 정상입니다.

**Claude Meetings로 회의에 Claude를 자동 참가시키는 워크플로를 쓰고 있다면, 당분간은 수동으로 참가 여부를 확인하는 편이 안전하며, Claude Code CLI 자체는 이번 인시던트와 무관하게 평소대로 쓸 수 있습니다.** [Claude Status](https://status.claude.com)

### bypass permissions 모드와 PowerShell 도구의 승인 요구 범위가 넓어졌습니다 (v2.1.326)

**지금까지는 승인을 모두 건너뛰는 bypass permissions 모드에서도 실행되던 일부 도구 호출이, 이번 릴리스부터는 그 모드에서도 승인을 요구하거나 아무도 답할 수 없는 상황에서는 거부되도록 바뀌었습니다.** PowerShell 도구도 더 많은 명령에 대해 먼저 승인을 묻게 됐고, 그중 일부는 bypass permissions 모드에서도 승인이 필요하며, 내장 명령과 같은 이름의 함수를 정의하는 일부 PowerShell 명령은 아예 거부됩니다.

**bypass permissions 모드로 무인 자동화를 돌리고 있었다면, v2.1.326 업그레이드 뒤 지금까지 그대로 통과되던 일부 명령이 갑자기 멈춰 승인을 기다리거나 거부될 수 있다는 점을 미리 감안해둘 만합니다.** [전체 릴리스 노트](https://github.com/anthropics/claude-code/releases)

## 생태계 & 플러그인

### Taskhand — Claude Code 사용량 탭과 로컬 AI를 내장한 무료 Windows 업무 자동화 도구 (11/17)

**작성자가 매일 반복하던 웹 로그인 확인, 엑셀·CSV 정리, 페이지 변경 감지, 폴더 백업 같은 작업을 자동화하려 만든 Windows 전용 도구입니다.** 웹 작업을 한 번 녹화하면 그대로 재현하는 "따라 하기" 기능, 예약·연결 실행, 사이트·서버 상태와 디스크 용량 감시, 슬랙·Teams·디스코드로의 알림, 메일로 요청하면 PC가 작업을 수행하는 원격 실행 기능을 제공합니다. "말로 부탁하기"에 할 일을 적으면 AI가 자동화 파일을 만들고 시험 실행까지 해주는데, 기본 AI는 내장된 로컬 모델(llama.cpp 기반 Gemma 4)이지만 이미 구독 중인 Claude Code·Codex·Gemini CLI 중에서 골라 쓸 수도 있고, Claude Code를 쓰는 경우에는 토큰 사용량을 보여주는 전용 탭도 있습니다. Windows 10/11 전용이며 관리자 권한 없이 설치되고, 코드 서명이 없어 첫 실행 시 SmartScreen 경고가 뜹니다.

**Claude Code 구독을 이미 쓰고 있으면서 반복적인 Windows 데스크톱 작업까지 AI에게 맡기고 싶었다면, 별도 요금 없이 기존 구독을 그대로 재사용하는 이 도구의 방식을 참고할 만합니다.** [프로젝트 페이지](https://swbins.github.io/taskhand/) · [GeekNews](https://news.hada.io/topic?id=37312)

## 알아두면 좋은 소소한 변경사항

아래는 모두 **v2.1.326**(11/16) 항목입니다.

- **Ctrl+O로 숨겨진 시작 알림(startup notices)을 다시 볼 수 있게 추가**됐습니다.
- **`/status`에 공급자나 `DISABLE_TELEMETRY` 같은 환경변수가 기능을 꺼둔 시점을 알려주는 줄이 추가**됐습니다.

- **서브에이전트 화면에서 Esc로 멈출 수 있을 때 그 사실을 알려주는 `esc to stop` 힌트가 하단에 추가**됐습니다.
